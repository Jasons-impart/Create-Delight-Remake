# 使用方式

在本目录操作。`config.toml` 和 `cdr-updater.jar` 放在一起，Go 程序才能找到这个 jar。

## 1. 准备配置

把下面保存为 `config.toml`，至少改 `public_url` 和 `version`。

```toml
[server]
listen = "0.0.0.0"
port = 8765
data_dir = "./data"
# 玩家实际连的地址。外网填公网 IP 或域名，例如 http://203.0.113.10:8765
public_url = "http://127.0.0.1:8765"
# 可选。填写后客户端和服务端同步要带同一个令牌
# access_token = ""
# 网页登录密码。不能和 access_token 相同。未设置时管理页只能本机打开
# admin_token = ""

[official]
github_repo = "Jasons-impart/Create-Delight-Remake"
version = "v0.5.0.15"
minecraft = "1.20.1"
forge = "47.4.16"
pack_name = "Create-Delight-Remake"

[private]
overlay_dir = "./private"

[repos]
unified = "./data/repos/unified"
client = "./data/repos/client"
server = "./data/repos/server"
objects = "./data/objects"
```

- `listen`：只给本机用填 `127.0.0.1`，局域网或外网填 `0.0.0.0`
- `port`：默认 `8765`
- `public_url`：写进导出包里的地址，玩家必须能访问
- 私货放到 `private/files/`，路径与游戏目录一致。需要强制端侧时放到 `private/files/client/`、`server/` 或 `both/`

路由器后面要把外网 TCP `8765` 转到这台机器。

## 2. 启动更新服务器

需要 Java 17 和 Go 1.23。在 `server/` 里编译：

```powershell
cd server
go build -o cdr-updater-server.exe .
.\cdr-updater-server.exe serve --config ..\config.toml
```

Linux：

```sh
cd server
go build -o cdr-updater-server .
./cdr-updater-server serve --config ../config.toml
```

看到 `Go 更新服务器已启动` 后，用浏览器打开：

`http://127.0.0.1:8765/admin/ifgfsgfbijuzoxzq`

第一次打开后在网页里构建仓库。构建会从 GitHub 拉官方包，时间较长。未设置 `admin_token` 时，这个页面只能在服务器本机打开。

也可以不编译 Go，直接用 jar 起带本机窗口的服务器：

```powershell
java -jar cdr-updater.jar serve --config config.toml
```

`java -version` 必须是 17。系统默认是 Java 8 时，请换成 Java 17 的 `java.exe` 完整路径。

## 3. 导出给玩家

先保证更新服务器已经构建完仓库，并且 `public_url` 是玩家能访问的地址。

客户端（PCL2）：

```powershell
java -jar cdr-updater.jar export-pcl2 --config config.toml
```

玩家在 PCL2 里选择 **下载 → 整合包 → 安装整合包**。不要改启动器，不要填启动前执行命令。

服务端：

```powershell
java -jar cdr-updater.jar export-server --config config.toml
```

解压后先开着更新服务器，再启动游戏服务端。Windows 运行 `启动游戏服务端.bat`，Linux 运行 `sh start.sh`（需要 Java 17）。

改了 `public_url` 或 `access_token` 之后要重新导出。已经装好的实例改游戏目录里的 `cdr-updater.toml`：

```toml
update_server = "http://203.0.113.10:8765"
update_token = ""
side = "client"
instance_dir = "."
```

服务端还要改 `user_jvm_args.txt` 里 javaagent 后面的地址。令牌要和服务器 `access_token` 一致；服务器没设令牌就留空。

## 4. 玩家自己打开客户端

整合包里已经带了更新器。单独打开本目录的客户端：

```powershell
java -jar cdr-updater.jar
```

客户端按更新服务器上的清单同步。玩家自己加的文件不会被删。`options.txt`、已有的 `config/`、`saves/`、截图等受保护路径不会被覆盖。

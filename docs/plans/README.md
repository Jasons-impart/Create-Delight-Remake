# Plans

This directory stores proposals, migration notes, and not-yet-landed design plans.

Move a plan's durable facts into `docs/systems/` after the implementation lands. Keep only historical or superseded planning context here when it is still useful.

## Routing

- Use `docs/plans/` for future work, alternatives, and open design questions.
- Use `docs/systems/` for current behavior and maintenance entry points.
- Use `.agents/skills/` for repeatable implementation workflows.
- Use `docs/lessons-learned.md` for bugs and pitfalls that future agents should not rediscover.

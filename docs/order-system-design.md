# 订单系统设计说明

本文是 Create-Delight Remake 订单系统的当前权威说明。订单系统只保留一条清晰主循环：

`公告板选单 -> 草稿写入印章/条款 -> 开封 -> 请求器备货 -> 交付 -> 金币/声望/凭证 -> 委托补缺`

## 设计目标

- 订单把玩家已有产线转化为明确需求，而不是再造一套无边界商店。
- 公告板减少纯随机带来的挫败，但不能让玩家永久锁死单一货物。
- 声望逐步开放便利工具；凭证只限制制造资格，不限制团队使用机器。
- 出货箱继续承担普通食物换金币的稳定出口；订单提供方向选择、声望、商会凭证、主题回礼和市场机会。
- 主动供货只补临时缺口与低频复杂材料，长期高频需求仍应鼓励自建产线。

## 订单获取与定向

商会暂时继续出售普通草稿，避免公告板每日候选不足时卡住吞吐。声望 2 级开放订单公告板，每日生成三种候选：

| 候选 | 约束 | 目的 |
|---|---|---|
| 适配单 | 最终全部条目都来自公告板列出的仓库小类 | 消化现有库存与产线 |
| 拓展单 | 必定包含列出的相邻小类，可补入兼容条目 | 鼓励建设新支线 |
| 机会单 | 保留其他菜单方向的随机性，并锁定领取时展示的市场倍率下限 | 鼓励根据行情换线 |

公告板定向的是蛋糕、曲奇、茶等小类，不是固定物品 ID。若公告板列出多个适配小类，适配单的每个最终条目都必须落在这些小类中；不能只保证其中一个条目命中。

草稿 tooltip 只显示已经写入的等级、顾客方向、菜单方向、公告板小类和条款，不显示精确顾客、条目、数量或品质。玩家右击开封时，服务端忽略旧预览并生成正式订单，同时开始计算时效收益。玩家潜行且副手为空时右击草稿，可清除顾客、菜单、公告板小类和机会锁价方向；普通重签章已删除。

## 条款

当前新产出条款只保留有明确决策价值的集合：

- 新手上路、小单试做、宽松验收。
- 专品专供、宴席拼盘。
- 小而精、大宗采购、品质抽检。
- 口碑优先、现款结算。
- 加急配送。

普通履约回流仍可返还至多一枚条款：单品偏向专品专供，多条目偏向宴席拼盘，大货量偏向大宗采购，高品质偏向品质抽检；时效回流只生成加急配送。

## 时间、市场与结算

- 普通订单没有硬过期；三游戏日内时效金币从 125% 线性回落到 100%，之后保持基础收益。
- 加急配送使用两游戏日 135%-100% 的线性曲线，逾期只失去额外金币，不会导致订单失败。
- 市场机会按小类和顾客方向记录近期供货；重复方向逐渐回落到基础收益，长期未供货方向最高获得 35% 机会加成，并随游戏日恢复。
- 机会单把领取时展示的市场倍率写入草稿，作为正式订单结算下限。
- 金币倍率不因本轮精简而整体下调。

订单按批量、品类价值、品质、时效和市场计算金币，并固定给予订单商会凭证；声望、主题回礼和条款回流构成非金币反馈。四种顾客关系已删除，顾客种族只保留主题与供货目录分组意义。

## 声望凭证与机器软解锁

玩家升级时不必随身携带声望凭证。凭证右键时按玩家当前声望补齐许可印记，合成时凭证不消耗；借来的高级凭证可用于团队制造，但只有原持证人能重新验印。

| 声望 | 制造许可 | 作用 |
|---:|---|---|
| 2 | 订单公告板 | 从适配、拓展、机会候选中选单 |
| 4 | 供货委托台 | 付凭证、金币和时间补临时缺口 |
| 5 | 订单请求器 | 把正式订单转换成 Create 仓库请求 |
| 6 | 订单提交口 | 自动验收并把奖励输出回包裹网络 |

订单解析器和订单构筑台不再提供新配方或新许可。旧注册仍用于存档兼容；旧构筑台仅作为迁移壳，允许玩家打开界面取回槽内物品，不再写入、重掷或开封订单。

## 主动供货委托

供货目录权威数据位于 `kubejs/data/createdelightcore/createdelightcore_order/supply_catalog.json`。每项只配置：物品、供应主题、固定批量、商会凭证、钱包金币和工期。

玩家流程：

1. 目录物品首次进入玩家物品栏后，永久解锁对应供货委托；打开委托台可浏览已发现目录。
2. 选择目标并放入严格 NBT 匹配的 LC 订单商会凭证。
3. 界面显示固定批量、费用和工期；确认后从 LC 钱包扣款并消耗凭证。
4. 委托进入无限分页队列；未完成委托可撤销并退款。
5. 到期后生成带所有者地址的 Create 包裹，输出槽堵塞时在台内等待，可由底部物流自动抽取。

系统不再包含专用样品槽、种族关系、七日常规批次、超额倍率、供应压力、自动目标、安全水位或预存预算。旧存档中的样品槽只取不放；旧预存预算在原所有者打开机器时退回；已经支付并排队的旧委托继续按原记录到货。

创造模式是测试旁路，不消耗凭证或钱包金币。生存模式金币通过 Lightman's Currency 钱包 API 扣除，不读取普通背包散币。

## 自动化边界

- 请求器负责从玩家自己的仓库备货，提交口负责验收结算。
- 供货委托台允许侧面/顶部输入凭证、底部抽取包裹，因此到货物流可自动化。
- 不提供“自动补货到安全水位”，避免委托系统在玩家不注意时持续消费并替代产线建设。

## 获取渠道保留与删除

保留：商会普通草稿、公告板候选、基础印章、声望分层普通条款、履约回流条款、订单主题回礼、LC 商会凭证。

删除：拍卖行自动投放普通订单和重签材料、普通重签章、供货委托书、解析器/构筑台新配方、合同复制订单路线、四种顾客关系及供货自动补货页。

# v0.5.0.15 更新摘要

自 v0.4.8.18 以来，本版本是 0.5.0 系列的首个正式版，共包含约 460 项提交。以下为面向玩家的主要更新内容概览。

## 模组框架与分发

- 整合包模组管理迁移至 Packwiz，安装、更新与同步流程全面重建（#1664、#1762、#1937、#2158）
- 客户端安装包体积大幅压缩：CurseForge 模组改为元数据引用而非打包 JAR（#2333、#2190）
- 新增 Crash Assistant 启动环境自检，模组不匹配或 Java 版本异常时给出警告（#2085、#1998、#2033、#2338）
- 默认启用配方书，新增 Fast Recipe Search、SaveMyRecipeBook、JEI++ 等配方检索优化（#2029、#2031、#2167）

## 冒险与探索

- 重构难度系统，任务书描述改为指引查看界面左侧难度等级（#1606、#2213）
- 新增 Northstar 木卫二维度与月背探索内容，迁移外星结构（#1898、#2002、#2077、#8134da34）
- 新增以灾变模组为主题的传送门试炼、新的 gateway 任务与任务章节（#2182）
- 加入虚拟卫星导航与实体火箭航点（#2048、#ee37b80d）
- 调整月球与金星 Alex 洞穴生成、木卫二渊海陷窟刷怪密度等星球环境（#2260、#2049、#2112）

## Tetra 与装备体系

- 完成 Tetra 6.16 迁移与 Tetrawear 集成，重构黑骑士材料（#2148、#2001、#1993）
- 重做 MMT 泰坦火种体系，MMT 暴击改为 AttributesLib 属性（#2008、#1719）
- 移除 Art of Forging、Iron 法术模组、三头末影龙模组，加入黑骑士铠甲与神化刷怪笼模块（#1695、#1694、#1780、#1631）

## 机械动力与物流

- 新增机械动力：流体包裹及配套任务与配方（#1747、#2236、#2244）
- 用 Create Mob Spawners 重做动力刷怪体系（#2010）
- 新增集成农业（Create Integrated Farming）及鸡舍植物油喂食等配套内容（#1951、#1966、#2330）
- 新增序列组装样板供应器、Create: Redstone Link GUI、Create: Solar Powered 等模组（#2069、#1833、#1831）
- 移除机械动力：流体、机械动力：渔业、Create: Interiors、Create Wizardry 等模组（#1662、#1658、#2229）

## TaCZ 枪械

- 大幅简化枪械与子弹合成：合并激发器、统一打包弹药再拆分（#2207、#2214、#2217）
- TaCZ 枪包改用 CurseForge 官方版本，本地魔改迁移至 KubeJS（#2194、#2201）
- 新增 TaCZ:Accel 及 Quantified API 前置（#2315）

## 订单与经济系统

- 重构订单系统与供货流程，完善订单草稿封印、投递器结算与自动化提交口（#2169、#1925、#1909、#1981）
- 修复出售箱价值为 1 的物品售出未消耗、多出货箱结算汇总等问题（#2257、#1949）

## 食物与烹饪

- 接入品质生命质收割闭环与品质食物兼容体系（#1946、#2013、#2232、#2233）
- 新增大量烘焙食物、冰淇淋系列、曲奇面团、蛋糕糊等新配方（#1669、#1841、#1915、#1922、#2254）
- 完成 CavesDelight 大量内容更新与重构（#ad6f3aff）

## 升级须知

- 本版本移除了多个模组（机械动力：流体/渔业、Art of Forging、Iron 法术、Create: Interiors、Tetra Immersion、Create Wizardry、三头末影龙、General Feedback、One Enough Damage、YUNG's Better End Island、Create More Recipes 等），升级前请备份存档，相关方块与物品在旧存档中可能消失或需替换。
- 模组管理已切换为 Packwiz，推荐使用支持 Packwiz 的启动器导入新包；从旧版覆盖升级时请以新包为准重新安装。
- TaCZ 枪械配方体系大幅简化，旧有子弹与激发器物品可能需要转换，请参考任务书最新说明。
- Forge 版本为 47.4.16，请确认启动器使用正确的 Java 与 Forge 版本。

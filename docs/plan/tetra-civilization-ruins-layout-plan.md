# Tetra 先民文明与遗迹两段式布局规划

状态：方向已定（主世界哨站 + 末地故都），细节可继续深化；实现未开始。叙事背景与挑战线见 `docs/plan/cataclysm-boss-challenge-line-tetra-mod-plan.md`，阶段总表见 `docs/plan/adventure-progression-overhaul-plan.md`，Tetra 图鉴结构见 `docs/plan/tetra-compendium-quest-rebuild-plan.md`。

## 已定方向

Tetra 定位为「上古先民文明」的遗留技术。遗迹拆成两段，不整体搬迁：

- **主世界**：基础 Tetra 遗迹 = 先民的**边陲哨站**，维持锻造入门与遗迹前原版 Boss 教学期，不动现有早期骨架。
- **末地**：真正的**文明故都**、深层遗迹与「Those Who Came Before」高潮内容；考古远征线的终点和文明真相都在末地。

这样故事感最强：玩家从哨站学会锻造，沿各维度异常点远征讨伐，最终抵达故都理解先民。

## 文明设定（分层揭示）

| 层级 | 玩家认知 | 载体 |
|---|---|---|
| 1. 技术层 | Tetra 是好用的锻造体系 | 主世界哨站操作教学（现有基础工艺章） |
| 2. 遗迹层 | 哨站是某个古文明的前线驻点，他们在研究/封印各处灾变 | 哨站出土物、碑文、任务短句、召唤物配方 |
| 3. 远征层 | 哨站网络遍布各维度，每处对应一个「远古灾变异常点」 | 挑战线任务节点、召唤媒介 |
| 4. 真相层 | 故都在末地；先民的兴衰、灾变的来源、技术的代价 | 末地故都深层遗迹、「Those Who Came Before」高潮章 |

要点：

- 先民与灾变异常点的关系保持**薄设定**：他们曾研究/封印这些灾害，不给每个 Boss 编造与先民的具体恩怨。
- 「Those Who Came Before」沿用现有 Tetra 基础工艺章名，并升格为考据起点；真相高潮放在末地内容（可续用该章延伸，或新增「故都」章，后续定）。
- 文明真相服务玩法与远征叙事，不写成长篇编年史；任务文案仍遵守只写「要做什么、怎么做、会得到什么」的约定，叙事感靠出土物名称、碑文短句和结构氛围承担。

## 主世界：边陲哨站

- 保留现有 Tetra 遗迹群与「基础工艺」教学路径：加工台、全息球、工具架、模块化物品、锤级、镶缀。
- 遗迹前阶段（教学期）：简单原版 Boss（女巫、守卫者、凋灵等轻量目标）作为战斗小门槛，不进灾变挑战线。
- 哨站新增叙事/功能增量：
  - 出土物分层：普通考古杂物（氛围/小额材料）→ 关键遗物（Boss 召唤物核心输入、图纸残页）。
  - 线索物：指向「故都在虚空彼端/群星尽头」的碑文或残页，供后续任务节点引用。
  - 召唤物制作：翻出的关键遗物 + 本地材料 → 灾变异常点召唤媒介（见挑战线规划）。
- 定位句：哨站是「学会锻造的地方」，不是文明真相所在。

## 末地：文明故都

- **故都遗址群**：新的末地结构/群系级遗迹（外岛或独立群系），规模与氛围对标「一个文明的首都」，与末地城（原版冒险资产）并存或部分融合，后续定。
- **深层遗迹**：高阶 Tetra 内容的终点——高锤级材料与图纸、改装高级 schematic、完整度/精力上限相关材料、高阶出土遗物（终局改装与召唤媒介）。
- **高潮内容**：先民真相（兴衰、与灾变的关系、技术代价）；可与末影守卫、星系终局的资格线衔接。
- **与现有末地支线合并节奏**：末影龙（中期支线入口）→ 末地城（原版探索）→ 故都（考古线高潮）→ 末影守卫（后期门槛）。末地「易于到达」的分层原则不变：普通龙材料仍可中期使用，故都深层内容属于后期。

## 考古远征线（完整弧线）

```text
遗迹前原版 Boss 教学
  → 主世界哨站（学会锻造、翻出土物）
  → 各维度远古灾变异常点（召唤物讨伐 → 改装变强）
  → 末地故都（深层遗迹、先民真相、高阶改装毕业）
  → 星系终局（挑战线收束）
```

- 起点教技术，中途教「世界有灾变、先民有网络」，终点给真相与最高阶成长。
- 与「变强」驱动咬合：哨站提供基础改装，异常点提供主题改装，故都提供终局改装与上限。

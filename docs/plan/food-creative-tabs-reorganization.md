# 食品、厨具与加工设备的创造栏重组

状态：规划已确认，待后续实施。当前仅保存计划，不启动功能开发。

规划日期：2026-11-15。

## 目标与目录

建立跨模组的两级分类：一级为独立页签，页签内部用类似 FluidLogistics 的标题横幅划分小类。同一套分类数据供新增模组兼容、任务选物和内容统计使用。

首版设置 **27 个页签**：

| 类别 | 独立页签 |
|---|---|
| 原料 | 食材、加工原料、调味与酱料 |
| 主食 | 面包、米饭料理、面条、饺子与包点、夹馅主食、披萨 |
| 菜肴 | 肉类料理、水产料理、蔬菜料理、汤羹与炖菜 |
| 甜食 | 蛋糕、派与挞、饼干、糖果与甜品、冰品 |
| 饮料 | 茶、奶茶、咖啡、果汁、奶昔、酒类、其他饮品 |
| 工具与设备 | 厨具、食品加工 |

饮料拆分依据：现有清单归并明显的效力、时长及容器变体后，茶约有 36—39 类、奶茶 50 类、咖啡 31 类、果汁至少 25 类、奶昔 22 类，均值得独立展示。统计来自现有订单标签，实施时继续补齐遗漏。

## 分类与展示规则

- 食物、食品原料及半成品各有一个主展示位置，从原模组页签移出。整份、切片和不同容器形态保持相邻，不因此拆成独立页签。
- 食品内部按菜品、原料或风味家族分区，例如奶茶分原味、果味和甜点风味，咖啡分黑咖啡、奶咖和风味咖啡。效力变体跟随基础品种排列。
- 手持操作工具、模具及功能性盛装器具归入“厨具”；放置后执行加工的工作站和机器归入“食品加工”。多用途条目指定唯一主分区，同时允许拥有多个工艺标签。
- 料理专用工具和设备移入新页签；通用加工机器增加食品页签入口，并保留原入口。
- 以当前有效内容为准，尊重既有禁用和替代规则；纯装饰家具不纳入。

厨具与设备使用统一的工艺分区顺序，仅显示非空分区：

**通用与盛装 → 切配 → 研磨筛粉 → 混合搅拌 → 压制榨取 → 成型组装与脱模 → 蒸制 → 煮炖 → 煎炸 → 烘焙 → 冲泡 → 发酵陈化 → 晾晒烟熏 → 冷冻保鲜 → 灌装分装 → 炉灶热源。**

机械搅拌器、磨石、粉碎轮、压机、机械锯、部署器和喷口等，按已有食品加工用途收录。

## 实现与公共接口

- **KubeJS 维护唯一分类清单**：记录物品 ID、所属页签、内部小类、排序、工艺标签及是否保留原入口。页签编排、分类标签和检查报告均从此清单生成。
- 导出 `createdelight:catalog/<分类>` 和 `createdelight:process/<工艺>` 标签，方便兼容脚本及任务编写引用；现有订单分类与权重继续独立维护。
- **CDC 提供通用分区接口**：接受目标页签 ID 和有序分区列表，每个分区包含标题翻译键及物品列表。客户端负责整行对齐、标题横幅和滚动位置计算。
- 使用统一静态横幅样式和代表性物品图标；标题采用玩家可理解的食品与工艺名称。分类配置随启动载入，修改后重启生效。
- 增加接入检查流程：新模组先核对食品、原料、工具和设备，再补分类清单；输出漏分、重复归属和失效 ID 报告。

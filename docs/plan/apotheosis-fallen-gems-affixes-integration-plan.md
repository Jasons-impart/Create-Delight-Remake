# Apotheosis 与 Fallen Gems & Affixes 整合规划

> 状态：规划中，尚未按本文完成数据接管与数值实装。
>
> 适用版本：Minecraft 1.20.1、Forge 47.4.16、Apotheosis 7.4.8、Fallen Gems & Affixes 2.1.2、Fallen Lib 1.4.4。
>
> 总体冒险阶段、Northstar 星球分配和首领定位仍以 [冒险流程与配方魔改规划](./adventure-progression-overhaul-plan.md) 为上层设计；本文集中规定 Apotheosis 与 Fallen Gems & Affixes 的模块取舍、装备分工、投放、数值和实施边界。

## 结论

Apotheosis 不应作为一套按默认配置独立运行的装备成长线。它与 Fallen Gems & Affixes 应共同改造成 CDR 的“装备后处理与高难奖励层”：

- Tetra 决定装备本体、材料、部件、锤级、打磨和基础流派。
- Apotheosis 决定基础词缀、重铸、插槽、宝石和回收循环。
- Fallen Gems & Affixes 提供终局词缀、分级插槽、强化组件、传奇重铸、套装词缀、法术兼容和首领专属宝石。
- 流程阶段决定“允许出现什么内容”，CDR 难度档位决定“允许出现多高品质”。
- 首领、星球、地牢和任务提供确定来源；不恢复两个模组的默认全局随机投放。

设计目标不是让玩家持续丢弃旧装备，而是让玩家在 Tetra 成型装备上继续投入资源并形成构筑。

## 模块取舍

| Apotheosis 模块 | 建议 | 设计理由 |
|---|---|---|
| 冒险模块 | 开启，但全面接管默认投放 | 保留词缀、宝石、重铸、插槽、回收等核心玩法。 |
| 附魔模块 | 开启，但压低附魔上限并重做设施配方 | 作为后期经验、建筑和材料消耗线，不能直接使用默认超高等级。 |
| 刷怪笼模块 | 关闭 | 会绕过现有动力刷怪笼、刷怪液、基因种子和 Create 化生产。 |
| 药水模块 | 首期关闭 | 永久药水护符会侵蚀料理、品质食物和饰品价值。 |
| 村庄模块 | 关闭 | 避免交易绕过附魔和流程门槛。 |
| 种植模块 | 关闭 | 与当前主流程关系弱，且会稀释既有农场设计。 |
| 初始指南书 | 关闭 | 使用 FTB Quests 统一引导。 |

若后续开放药水模块，药水护符必须限制在 Curios 槽，并优先只保留夜视、水下呼吸等工具型效果；力量、抗性、生命提升、生命恢复、吸收等战斗型永久效果应禁用。

刷怪笼模块如因兼容性原因必须保持加载，至少需要设置 `Spawner Silk Level=-1`，移除全部刷怪笼升级配方并禁止刷怪蛋修改刷怪笼。

## 装备体系分工

### 第一层：Tetra 装备骨架

Tetra 负责可规划成长：

- 材料与部件选择。
- 锤级、遗迹和锻造设施。
- 改装、打磨、卷轴和模块效果。
- 武器类型、基础面板和稳定成长。

### 第二层：Apotheosis 后处理

Apotheosis 负责装备成型后的长期投入：

- 基础词缀和稀有度。
- 普通插槽和宝石。
- 回收与重铸材料循环。
- 中后期可控的随机差异。

### 第三层：附属终局构筑

Fallen Gems & Affixes 只承担中后期和终局扩展：

- 分级插槽和催化插槽。
- 词缀卷轴与词缀转移。
- 强化组件槽和构筑强化。
- 传奇稀有度、传奇重铸台和套装词缀。
- 铁魔法法术词缀和法术宝石。
- Cataclysm、Ice and Fire 等首领专属宝石。
- 受控的精英怪词缀，而不是新的独立难度系统。

### 装备准入原则

- 优先让 Tetra 成型装备成为神化重铸和插槽的主要承载物。
- Cataclysm 神器、黑骑士盔甲等固有神器和其他自带复杂机制的首领装备默认禁止重铸，避免重复乘区。
- 固定套装可进入附属套装系统，但必须通过任务或传奇终局流程定向获取，不能作为普通箱子随机毕业装。
- 在正式开放 Tetra 重铸前，必须验证再次改装、打磨和更换部件不会清除或重复词缀、插槽、宝石与强化组件 NBT。

### 新增传奇稀有度

附属新增 `fallen_gems_affixes:fabled`：

- 对应材料为 `fallen_gems_affixes:fabled_material`。
- 通过 `fallen_gems_affixes:fabled_reforging_table` 重铸。
- 传奇重铸会将装备设为传奇，并强制加入一个套装词缀。
- 默认传奇重铸消耗 5 个材料、10 个符印、50 级经验。

默认配方只使用下界之星、下界合金块、深板岩砖、普通重铸台和传奇遗物，不能满足 CDR 终局门槛，必须重做。

### 当前默认传奇获取链

当前工作区尚未覆盖 Fallen 的默认传奇获取数据，实际规则如下：

- 通用首领只在敌对生物自然生成的 `FinalizeSpawn` 阶段判定；末地允许史诗、神话、远古和传奇，传奇基础概率为 `0.5%`。
- 检查生成点 64 格内最近玩家的六个原版装备槽；每装备一件对应品质装备，就把该品质生成概率增加配置中的 `gear_bonus`。传奇装备每件增加 `2%`，六槽传奇时传奇概率理论上为 `12.5%`。
- 传奇通用首领死亡时，独立 `15%` 概率掉落 `1～2` 个 `fallen_gems_affixes:fabled_material`，独立 `5%` 概率掉落一个随机强化组件。
- 所有品质的通用首领均有独立 `5%` 概率掉落词缀卷轴；卷轴品质与首领一致，词缀从该品质可用词缀中随机选择，内部强度随机。
- 当前 `maxScrollSlots = 2`、`affixScrollXpCost = 15`：每件装备最多追加两个卷轴词缀，且只能把卷轴应用到同品质、兼容战利品类别的装备。
- 普通至远古卷轴可以分解为对应品质材料 `1～2` 个；模组未提供传奇卷轴的分解配方。
- 传奇重铸台本体消耗两个传奇遗物；每次重铸另消耗五个传奇遗物、十个再生符石和 50 级经验，将装备设为传奇并加入一个套装词缀。

规划上保留“每件最多两个卷轴词缀”的上限；它足以支持定向毕业，又不会让卷轴无限突破重铸词缀数量。默认自然传奇首领和装备反向提高生成概率的滚雪球机制仍需在正式数据接管时改为阶段受控来源。

### 分级插槽与催化插槽

附属默认启用普通、罕见、稀有、史诗、神话、远古六档插槽，其基础生成概率分别为 40%、30%、20%、15%、10%、5%。

分级插槽限制宝石品质，是值得保留的纵向成长机制；但不能随普通装备和宝石全局随机生成。建议：

- 普通/罕见插槽：末影龙后或 Tetra 基础锻造后开放。
- 稀有插槽：月球后开放。
- 史诗插槽：火星或水星后开放。
- 神话插槽：金星或土卫二后开放。
- 远古插槽：星系终局开放。
- 催化插槽：只通过终局符印将多个空插槽合并获得，每消耗一个插槽增加约 10% 宝石强度的默认机制可保留，但总增幅必须设置上限。

### 词缀卷轴与符印

附属新增可通过铁砧写入装备的词缀卷轴，以及一组改变装备长期状态的符印：

| 物品 | 默认功能 | CDR 定位 |
|---|---|---|
| 词缀卷轴 | 向同稀有度装备追加指定词缀 | 地牢、首领或任务奖励；不允许普通量产。 |
| 升华符印 | 将普通插槽转为强化组件槽 | 土卫二或终局。 |
| 晋阶符印 | 将所有分级插槽提升一档 | 高阶星球材料消耗，不能只吃神化通用材料。 |
| 嬗变符印 | 在同战利品类别装备间转移词缀、插槽和宝石 | 月球后到金星阶段的装备继承工具。 |
| 汇流符印 | 合并两件相同装备的词缀和唯一宝石 | 终局定向毕业工具；必须防止复制和低成本堆叠。 |
| 棱彩转化符印 | 将空插槽合并为催化插槽 | 星系终局。 |
| 剥离符印 | 移除所有强化组件 | 允许纠错，但材料成本应明显低于重新制作装备。 |
| 抹除符印 | 移除卷轴追加的词缀 | 允许洗点和构筑调整。 |

嬗变和汇流对 Tetra 装备风险最高。Tetra 同一物品 ID 可以承载完全不同的部件组合，不能只依赖“相同物品”或战利品类别判断兼容；需要实测并考虑禁止 Tetra 使用汇流，或额外校验模块结构。

### 强化组件

| 强化组件 | 默认效果 | 设计判断 |
|---|---|---|
| 连锁 | 超过 100% 暴击率后，有概率造成额外伤害 | 只适合终局；必须限制过量暴击收益。 |
| 汇流 | 每条词缀提高宝石强度，每颗宝石提高词缀强度 | 极易形成自增闭环，建议显著削弱或禁用。 |
| 二元 | 暴击率翻倍、降低暴击伤害，并把暴击拆为物理/魔法伤害 | 可作为明确流派选择，不能与无条件高暴击装备同时开放。 |
| 宝石增幅 | 默认提供 `+0.5` 宝石强度，使单颗宝石数值线性放大至 `1.5×` | 公式本身不是额外指数层，但重复宝石会放大原始数值设计问题；只作为高阶宝石专精，并按填满插槽的组合审核。 |
| 创生 | 初始降低词缀与宝石强度，每次击杀首领增长 | 很适合 CDR 长期培养，但必须只统计阶段首领，禁止机械刷取和重复召唤无限成长。 |
| 恶意 | 50/50 选择词缀或宝石一侧 +100%，另一侧 -50% | 可保留为高风险偏科构筑。 |
| 至高 | 默认把词缀强度提高到 1.5 倍 | 终局限定，并排除百分比生命伤害、斩杀等敏感词缀。 |

强化组件不应在普通掉落中出现。建议由阶段首领首杀、星球终局任务或高成本制造提供，并限制每件装备最多一个强化组件槽。

### 三套传奇套装

| 套装 | 核心玩法 | 推荐阶段与处理 |
|---|---|---|
| 巨像 | 受击、格挡积累壁垒宝珠，换取生命、冲击波、反伤和控制免疫 | 火星重装线开始铺垫，土卫二或终局完成；需要限制对首领的眩晕和反伤。 |
| 鹰眼 | 远程命中积累专注，强化箭伤、暴击、定身和斩杀 | 月球/末地远程线铺垫，终局完成；默认低血量斩杀不能对首领生效。 |
| 诡术师 | 受击生成暗影分身，分摊伤害、换位并协同攻击 | 月背异寂空谷或末地虚空支线；需要验证克隆实体性能和多人同步。 |

传奇套装不应通过任意装备随机重铸直接完成。推荐把三套套装词缀分别绑定对应主题任务、首领记录或专属传奇材料。

### 铁魔法联动

附属为法杖新增约 47 个词缀，并加入火焰、冰霜、雷电、自然、神圣、鲜血、末影、唤魔、邪术和通用法术宝石。主要效果包括：

- 法术强度、法力消耗、法力回复、法力吸取和法力护盾。
- 连锁施法、法术回响、冷却重置和专注施法。
- 武器攻击触发火焰、鲜血、神圣、雷电等法术。
- 对不同法术学派提供专精等级。

这些效果与现有铁魔法卷轴、Tetra 法杖改装和星球元素材料高度契合，但也最容易形成多重乘区。建议：

- 法术学派宝石最低从史诗开始是合理方向，但其种类仍须受流程阶段限制。
- 冷却重置、连锁施法和法术回响不能同时无条件叠加。
- 法术强度、词缀强度和宝石强度使用统一总上限。
- 自动施法词缀应设置内部冷却，并检查多人服务器的实体与粒子负载。

### 首领专属宝石

附属已经为八个 Cataclysm 首领注册专属宝石和全局掉落修改器：

| 首领 | 宝石 | CDR 阶段 |
|---|---|---|
| 斯库拉 | `boss_gems/howling_storm` | 主世界雷系首领。 |
| 先驱者 | `boss_gems/withered_sentinel` | 月球机械/虚空阶段。 |
| 下界合金巨兽 | `boss_gems/guardian_of_hell` | 火星重型金属阶段。 |
| 焰魔 | `boss_gems/infernal_overlord` | 水星高温阶段。 |
| 远古遗魂 | `boss_gems/blood_tyrant` | 金星远古阶段。 |
| 咒翼灵骸 | `boss_gems/fallen_warrior` | 土卫二地表诅咒阶段。 |
| 利维坦 | `boss_gems/ruler_of_abyss` | 土卫二地下深渊阶段。 |
| 末影守卫 | `boss_gems/void_guardian` | 末地后期或星系终局。 |

这组对应关系与现有冒险规划高度一致，可以保留主题，但必须替换默认掉落率。模组文件默认对每个首领分别配置 50% 史诗、25% 神话、5% 远古，可能在一次击杀中分别结算；这会绕过难度品质上限，也会被 CDR 现有实体掉落倍率再次放大。

建议改为：

- 首杀任务奖励一颗固定阶段品质宝石，保证推进体验。
- 重复击杀只按“流程阶段上限与难度品质上限的交集”抽取一个品质。
- 低于品质要求时改掉宝石粉或阶段碎片，不直接跳到高阶宝石。
- 远古只在有效难度档位 6 且已解锁终局阶段时进入奖池。
- 首领专属宝石不受全局实体掉落倍率复制。

| `yggdrasil` | 对龙增伤/减伤，远古武器默认可达 +90% 龙伤 | Ice and Fire 龙猎支线；必须削弱并限制同类叠加。 |

## 双轴投放规则

所有神化与附属奖励都采用同一判定：

```text
有效品质上限 = 流程阶段品质上限与 CDR 难度档位品质上限中的较低值
最终奖励池 = 同时满足已解锁内容种类、有效品质范围与当前来源专属池的内容
```

### 难度品质轴

| CDR 档位 | 允许品质上限 |
|---:|---|
| 0 风平浪静 | 不投放进阶词缀装备和高风险宝石。 |
| 1 暗流涌动 | 普通 / 罕见。 |
| 2 危机四伏 | 稀有。 |
| 3 险象环生 | 史诗。 |
| 4 生灵涂炭 | 神话入门。 |
| 5 末日降临 | 神话稳定。 |
| 6 诸神黄昏 | 远古；传奇仍需终局流程解锁。 |

### 流程内容轴

| 流程阶段 | 开放内容 |
|---|---|
| 末影龙前 | Tetra 装备骨架；不开放随机词缀装备、分级插槽和附属通用首领。 |
| 末影龙后 | 基础回收、简单重铸、普通/罕见宝石和普通插槽。 |
| 月球/先驱者后 | 稀有、基础词缀卷轴、末影/虚空/法术宝石、装备转移的受控版本。 |
| 火星/水星后 | 史诗、首领专属宝石、元素法术宝石和第一批构筑型词缀。 |
| 金星后 | 神话、插槽提升、强法术构筑和高级重铸。 |
| 土卫二后 | 远古前置、强化组件、套装材料和终局符印。 |
| 星系终局 | 远古稳定来源、传奇、传奇套装、催化插槽和最终构筑。 |

## 通用首领系统风险

附属默认 `universal_boss` 配置允许：

- 主世界出现普通至稀有。
- 下界出现稀有至史诗。
- 末地出现史诗、神话、远古甚至传奇。
- 装备会额外提高成为通用首领的概率。

默认怪物属性增长严重超过 CDR 现有难度系统需求：

- 普通已可能获得约 +25% 基础生命和 +10% 基础攻击。
- 史诗可获得约 +120% 基础生命、+50% 基础攻击，并可能附带抗性与火焰抗性。
- 远古可获得约 +250% 基础生命、+100% 基础攻击、百分比生命伤害、吸血、闪避和多种穿透。
- 传奇可从约 +500% 基础生命、+250% 基础攻击起步，并固定获得抗性、火焰抗性、力量，且可能获得速度和生命恢复。

这套系统不能与 CDR 难度值直接叠加。建议首期完全禁用默认通用首领，后续仅选择少量可读性强的怪物词缀：

- 可优先保留：狼群领袖、激怒、再生、奥术之盾、巨像。
- 谨慎启用：相位、暗影步、恐惧光环，需验证战斗可读性和寻路。
- 默认禁用或重做：刽子手、不朽、灵魂汲取、百分比生命伤害和高额反伤。

精英怪必须满足以下规则：

- 不作用于剧情首领、非玩家角色、友方实体、召唤物和可自动量产实体。
- 不在末影龙前保护期生成高阶词缀。
- 词缀数量、属性倍率和奖励品质由 CDR 有效难度统一决定。
- 视觉提示必须明确，避免玩家在大型混战中无法识别机制。

## 玩家词缀数值边界

以下内容需要覆盖默认数值或限制叠加：

| 属性/机制 | 建议边界 |
|---|---|
| 吸血 | 全身或单武器总量约 3%–5%，首领战可进一步衰减。 |
| 当前生命值伤害 | 普通怪可保留低值，对首领无效。 |
| 最大生命值伤害 | 默认禁用，或仅作为终局主动效果并设置硬上限。 |
| 斩杀 | 对首领、剧情怪和玩家无效。 |
| 护甲穿透/撕裂 | 总量控制在约 20%–30%，不能同时无限堆叠。 |
| 闪避 | 总量设置硬上限，避免 Tetra、饰品、宝石和词缀多层相乘。 |
| 首领/龙增伤 | 单颗终局宝石建议不超过 20%–30%，同类唯一。 |
| 首领/龙减伤 | 单颗建议不超过 5%–10%，同类唯一。 |
| 攻击距离 | 总额外距离约 1–1.5 格。 |
| 法术回响/连锁施法 | 必须有内部冷却，不能互相递归触发。 |
| 插槽数 | 稀有以上才稳定出现；普通装备不应轻易获得多槽。 |
| 强化组件槽 | 每件装备最多 1 个。 |
| 词缀强度/宝石强度 | 统一设置总上限，防止汇流、至高、催化自增。 |

## 附魔模块上限

Apotheosis 默认存在保护 VIII、锋利 IX、摔落保护 XI 等数值，不适合直接进入 CDR。第一版建议温和扩展：

- 保护 V。
- 锋利 VI–VII。
- 效率 VI–VII。
- 耐久 IV。
- 时运 IV。
- 抢夺 IV。
- 移动类附魔最多比原版高一级。

高阶附魔设施按流程换配方：普通神化书架接 Tetra 基础阶段，下界书架接下界，深暗书架接月背异常区，末地书架和附魔图书馆接末影龙后，最高灌注设施接星球首领材料。

## 配方与经济循环

### 可自动化部分

- 宝石粉、低阶神化材料和基础石板可通过 Create 加工线生产。
- 回收普通词缀装备提供可预测的低阶材料。
- 低阶重铸消耗经验流体、锻造钢、精密构件和基础神化材料。

### 不可完全自动化部分

- 首领专属宝石。
- 远古与传奇核心材料。
- 强化组件。
- 套装词缀授权材料。
- 高阶符印的关键阶段材料。

### 推荐阶段配方方向

| 目标 | 推荐关键材料 |
|---|---|
| 宝石切割台 | Tetra 加工设施、锻造钢、无瑕紫水晶。 |
| 简易重铸台 | 精密构件、锻造钢、经验流体。 |
| 重铸台 | 末影龙材料、Northstar 电路、阶段宝石粉。 |
| 词缀增幅台 | 远古材料、一个土卫二或同阶段冒险证明、神话材料和附魔台；作为首次接触远古后的永久设施，不绑定传奇遗物。 |
| 强化宝石石板 | 高阶宝石粉、下界合金材料、星球金属板。 |
| 晋阶符印 | 当前阶段首领战利品和下一阶段星球材料。 |
| 嬗变符印 | 月球电路、末影材料、Tetra 锻造件。 |
| 汇流符印 | 终局首领材料、星系结晶、远古材料。 |
| 升华符印 | 土卫二首领材料、远古宝石和强化石板。 |
| 传奇重铸台 | 星系结晶、终极龙心、AE2 奇点和传奇遗物。 |

### 词缀增幅台配方取舍

Apotheosis 7.4.8 的默认 `apotheosis:augmenting_table` 只消耗一个下界之星、两个神话材料、一个附魔台和三个磨制黑石。该设施能用一个强化符石定向替换同类型词缀，并用每次两个强化符石、每次 `+0.25 level` 的方式在最多四次内把指定词缀稳定拉满，因此默认配方相对于能力过轻。

建议修改，但不把它推迟到传奇阶段：

- 增幅台属于 Apotheosis 基础后处理层，应在首次取得远古材料、土卫二或同等级冒险证明后开放；传奇遗物仍留给 Fallen 的传奇重铸和高级符印。
- 一次性设施配方负责阶段门槛，可把两个神话材料中的至少一个替换为远古材料，并用可替换的同阶段首领、星球或遗物证明替代普通磨制黑石。
- 强化符石负责长期经济。默认配方一次产四个，而满一个词缀最多需要八个；建议先把产量降为两个，使满一个词缀需要四次配方、四个神话材料。不要加入失败率或强化次数上限，保留确定培养体验。
- 若实测四个神话材料仍过轻，再提高宝石粉与宝石融合石板消耗；不建议给每次强化强行加入传奇遗物，否则会让基础词缀培养与 Fallen 终局材料争抢同一稀缺来源。

## 数据接管路径

后续实施时优先使用同路径数据覆盖，不修改模组文件：

- `kubejs/data/apotheosis/loot_modifiers/**`：继续禁用 Apotheosis 默认全局投放。
- `kubejs/data/fallen_gems_affixes/loot_modifiers/**`：覆盖附属的首领宝石、通用首领奖励、九头蛇和插槽注入修改器。
- `kubejs/data/fallen_gems_affixes/universal_boss/universal_boss.json`：禁用或重做默认通用首领概率和属性。
- `kubejs/data/fallen_gems_affixes/gems/**`：调整唯一宝石、首领/龙增伤和法术宝石数值。
- `kubejs/data/fallen_gems_affixes/affixes/**`：调整危险词缀、最低稀有度、类型和强度。
- `kubejs/data/fallen_gems_affixes/socket_tiers/**`：调整分级插槽生成概率与催化强度。
- `kubejs/data/fallen_gems_affixes/recipes/**`：重做传奇、符印、宝石匣和强化石板配方。
- `kubejs/server_scripts/Improved Mobs/**`：统一接入 CDR 难度、保护期和精英怪奖励。
- `kubejs/startup_scripts/custom/loot_data.js`：维护阶段与难度对应的额外掉落数据。

不要直接替换 `data/forge/loot_modifiers/global_loot_modifiers.json` 的全部列表，否则可能误伤其他模组的全局战利品修改器。应覆盖附属已注册的各个具体修改器 ID，使其条件不可能满足，再由 CDR 自定义逻辑重新投放。

## 实施顺序

1. 保持 Apotheosis 默认全局词缀、宝石和转换修改器禁用。
2. 覆盖并禁用附属的 11 个默认全局战利品修改器和通用首领配置。
3. 关闭 Apotheosis 刷怪笼模块、药水模块、村庄模块、种植模块，仅开放冒险模块与受控附魔模块。
4. 实测 Tetra 装备在重铸、插槽、宝石、词缀卷轴、嬗变后的 NBT 稳定性。
5. 先实现末影龙后至月球阶段：基础宝石、普通插槽、回收和简单重铸。
6. 按首领阶段表实现八颗 Cataclysm 专属宝石，首杀保底、重复击杀按双轴抽取。
7. 接入铁魔法元素宝石和法杖词缀，验证法术回响、冷却和法力乘区。
8. 实现稀有至神话的分级插槽、词缀卷轴和受控装备转移。
9. 在土卫二后开放强化组件前置，逐个验证七种强化组件的强度和递归风险。
10. 星系终局最后开放远古、传奇、三套套装词缀和催化插槽。

## 验证清单

### 数据与启动

- 客户端和服务端均能加载 Apotheosis、Fallen Lib 与 Fallen Gems & Affixes。
- 数据包覆盖没有“注册项缺失”（missing registry）、“未知序列化器”（unknown serializer）或重复 ID 错误。
- JEI 中只显示当前设计允许获取的配方和处理方式。

### Tetra 与 Better Combat

- Tetra 重铸后部件、改装、打磨、附魔和耐久 NBT 不丢失。
- 再次修改 Tetra 部件后词缀、插槽、宝石和强化组件不丢失、不复制。
- Better Combat 正确读取攻击伤害、攻速、攻击距离和武器类别。
- 汇流与嬗变不会把不同 Tetra 构型错误合并。

### 掉落与难度

- 末影龙前不会出现稀有及以上神化或附属奖励。
- 首领宝石品质同时受流程阶段和难度上限限制。
- 八个 Cataclysm 首领不再使用默认 50%/25%/5% 三档掉落。
- 首领宝石、词缀卷轴、强化组件和传奇遗物不受全局实体掉落倍率复制。
- 动力刷怪笼、召唤物和机械量产生物不能刷取创生成长或高阶奖励。

### 战斗与性能

- 百分比生命伤害、斩杀、反伤和控制对剧情首领的免疫正确。
- 法术回响和连锁施法不会递归触发。
- 诡术师暗影分身在多人环境下不会造成实体泄漏或同步异常。
- 高难精英怪具备可识别的名称、粒子或界面提示。
- 传奇怪物与装备不会在未解锁终局时自然出现。

## 最终定位

Apotheosis 提供“装备可以继续打磨”的基础循环，Fallen Gems & Affixes 提供“终局构筑可以产生玩法变化”的高级层。两者都不能取代 Tetra，也不能另建一套脱离任务、星球和首领的随机毕业路线。

正确的玩家体验应当是：

1. 先通过 Tetra 打造可信赖的装备本体。
2. 在冒险和难度提升后获得匹配阶段的宝石与词缀资源。
3. 使用重铸、插槽和转移长期培养原有装备。
4. 在土卫二和星系终局通过强化组件、传奇与套装词缀完成流派构筑。

只要默认通用首领、默认全局掉落和默认百分比数值被接管，这两个模组能够很好地补足 CDR 后期装备追求；若直接按模组文件默认数据运行，则会同时冲垮现有难度系统、Tetra 成长、首领阶段和料理/饰品价值。

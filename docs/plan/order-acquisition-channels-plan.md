# 订单获取渠道计划

状态：渠道已收束；详细行为见 `docs/order-system-design.md`。

## 当前渠道

| 渠道 | 内容 | 定位 |
|---|---|---|
| 商会固定交易 | 普通草稿、基础印章、声望分层普通条款 | 保证基础吞吐与可预测补充 |
| 订单公告板 | 每日适配、拓展、机会候选 | 核心选单入口 |
| 履约回函 | 主题回礼、商会凭证、至多一枚条款 | 完成订单后的下一步动力 |
| 任务奖励 | 首张草稿、新手条款、声望凭证 | 教程与保底 |
| 供货委托台 | 目录物品的延迟批量补缺 | 后期临时缺口，不生成订单 |

## 公告板规则

- 声望 2 级开放。
- 适配单列出一个或多个仓库小类，最终所有条目都必须来自这些小类。
- 拓展单保证至少一个相邻小类，允许补入兼容条目。
- 机会单引导其他菜单方向，并锁定展示的市场倍率下限。
- 候选指定小类而非物品 ID；玩家仍要决定生产该小类中的哪些具体食物。

## 草稿与材料

- 草稿 tooltip 显示服务端锁定的精确结果。
- 顾客印章、菜单印章和条款仍可直接写入草稿。
- 潜行且副手为空时右击草稿清除方向。
- 普通重签章、供货委托书、解析器和构筑台配方已移除。

## 条款获取

- 普通条款由 LC 商会按声望开放。
- 加急配送只从履约回流。
- 大货量履约提高大宗采购回流权重。
- 薄利多销与特急救场旧物使用别名兼容，不再新产出。
- 反季采购只保留旧订单兼容。

## 已删除渠道

- 拍卖行定时投放普通草稿和稀有重签材料。
- 合同复制订单与自动签发。
- 通过样品登记解锁供货目录。
- 依靠顾客关系逐层开放供货目录。

## 平衡观察

商会直接出售普通草稿暂时保留，因为公告板仍是按日候选，单独承担全部订单吞吐会过慢。后续若公告板刷新频率或候选数量提高，再评估收紧商会草稿供应。

# 异彩材料双路线与后续分支设计

本文记录重新启用 `create:chromatic_compound`（异彩化合物）完整材料链的设计方向。异彩化合物不是终盘成品，而是由重科技和轻科技两种方式获得的共同中间体；重科技路线使用工业、能源、AE2 和航天体系，轻科技路线以料理生产为重复成本，以现有冒险、Iron's Spells、T.O Magic 'n Extras、Apotheosis 与 Fallen Gems & Affixes 内容作为解锁条件。异彩化合物继续转化为 `create:refined_radiance`（光辉石）和 `create:shadow_steel`（暗影钢），再由这两种分支材料制作真正的后续物品。

本文仅记录前瞻设计，尚未确定最终物品 ID、数值、配方和实现阶段，也不代表相关机制已经完成。

## 设计目标

- 让异彩化合物成为光辉石和暗影钢路线的共同中间体，而不是直接承担终盘奖励身份。
- 为重工业玩家和料理/魔法玩家提供体验不同、结果等价的获取路线。
- 让整合包中大量食品、食材、流体和加工设备在终盘重新获得价值。
- 首次制作强调探索、收集、搭建和仪式感，后续制作允许建设可审阅、可自动化的大型产线。
- 允许无尽奶酪、油奇点等终盘资源源解放基础生产，但不让它们反向摧毁生命质、订单、货币和奇点体系。
- 让光辉石、暗影钢及其共同衍生物分别拥有清晰的主题和下游用途。

## 非目标

- 不要求所有玩家同时完成重科技线和轻科技线才能推进主线。
- 不把异彩化合物本身视为材料树的终点。
- 不把“扫描注册表中的全部食物”作为长期规则；实际材料应使用人工维护的代表性清单或标签。
- 不让无限资源直接兑换生命质、订单高额奖励、稀有 Boss 材料或新的奇点。
- 不以真实执行 1024 次高频加工制造单纯等待和服务器负担；次数可以通过进度、层数或较少循环表达。
- 不在本设计阶段确定最终平衡数值和具体实现载体。

## 核心框架

异彩材料树分为“共同输入、光暗分流、后续制品”三层：

```text
重科技路线：工业、能源、AE2、航天 ───────────────┐
                                                   ├─> 异彩化合物 ─┬─> 光辉石 ──> 光辉系物品 ─┐
轻科技路线：料理生产 + 可选冒险巡礼 ─────────────┘                └─> 暗影钢 ──> 暗影系物品 ─┴─> 双极复合物品
```

其中只有异彩化合物拥有两条平行获取路线：

| 路线 | 核心体验 | 首次获取 | 后续生产 |
|---|---|---|---|
| 重科技路线 | 大型工厂、物质压缩、精密制造、高能加工和空间计算 | 建设工业色谱装置或完成复杂工艺链 | 高吞吐、高能耗的稳定量产 |
| 轻科技路线 | 终盘料理、可选支线、遗迹探索和流派养成 | 达到固定主线阶段后，从横向冒险篇章中任选若干完成 | 奇点与任选悖论食品的一步式低能耗生产 |

两条路线产出相同的异彩化合物，之后使用同一套光辉石、暗影钢转化和下游配方。首次同时完成两条异彩化合物路线可以提供成就、称号、装饰或纪念物，但不应成为主线硬门槛。

材料层级应保持明确：

| 材料 | 定位 |
|---|---|
| 异彩化合物 | 可量产的共同中间体，承接重科技和轻科技两种生产方式 |
| 光辉石 | 光、秩序、显现、稳定和能量方向的分支材料 |
| 暗影钢 | 暗、虚空、隐藏、侵蚀和空间方向的分支材料 |
| 双极复合物 | 同时消耗光辉石和暗影钢的更高阶制品，用于表达平衡、相位或现实重构 |

## 轻科技料理支线：七种食之悖论

食物线不只是把大量食材压在一起，而是让七件终盘食品分别代表一种概念：

| 概念 | 终盘食品 | 证明内容 |
|---|---|---|
| 光谱 | 炫彩冰淇淋 | 掌握全部主要冰淇淋风味和冷冻加工 |
| 血肉 | 怪异肉团 | 掌握动物、海产、异界生物等蛋白来源 |
| 谷物 | 异彩面团 | 掌握不同文明和食品体系的主食基底 |
| 时间 | 无尽奶酪 | 以奇点承载熟成、发酵和反复加工 |
| 流动 | 油奇点 | 将多种油脂与流体加工汇聚成持续资源源 |
| 生态 | `BIO·寿司` | 将多种水域、生物和寿司体系聚合为生态食品 |
| 因果 | 彭罗斯曲奇 | 以不可能结构表现效果等级与持续时间的交换 |

七件食品构成轻科技路线的料理候选池，但不要求全部制作。每次生产异彩化合物时从中选择三种不同食品即可，让玩家按已有农场、偏好和自动化条件决定路线。

## 炫彩冰淇淋

### 首次制作

首次制作采用世界结构仪式：

- 使用人工维护清单中的全部冰淇淋方块搭建色环、色带或向中心汇聚的图案。
- 每一条色带由同一种冰淇淋方块组成，长度可以等于当前采用的冰淇淋种类数。
- 中央放置白色基底，例如香草冰淇淋块、空盆或专用核心方块。
- 玩家手持指定催化物点击中心方块，验证结构后消耗冰淇淋方块并生成炫彩冰淇淋。
- 首次完成给予进度，并解锁可自动化的动力合成配方。

实际清单应从现有冰淇淋体系中人工选取，避免新增联动模组后仪式尺寸和材料无条件膨胀。当前 `kubejs/server_scripts/Custom/food/icecream.js` 已维护约 17 种成体系的冰淇淋路线，可作为第一版清单基础。

### 后续生产

后续动力合成可以消耗：

- 各种代表性冰淇淋球各一个。
- 奶油和基础糖浆。
- 华夫筒、碗或其他统一容器材料。
- 炫彩冰淇淋母种作为可选的不消耗模板。

炫彩冰淇淋的效果可以按风味轮转，或根据环境温度、生物群系和食用时段产生不同增益。

## 怪异肉团

怪异肉团代表对血肉与蛋白来源的聚合。材料采用代表性类别，而不是无条件包含所有肉类：

- 家畜：牛、猪、羊、鸡。
- 猎物：兔、鹿、野猪等。
- 飞禽。
- 鱼类和甲壳类。
- 洞穴或深海生物。
- 异界生物。
- 怪物肉或特殊可食用组织。

首次通过长序列组装完成，每轮部署一种类别的尸体、胴体或肉类，最后压块塑形成怪异肉团。

怪异肉团可以作为终盘肉类资源源：

- 砧板切割：随机产出一种基础肉类并返还怪异肉团。
- 动力锯切割：按照固定序列产出不同肉类并返还怪异肉团，便于自动化分配。
- 料理锅加工：制作效果随调味料变化的无名炖肉。

Boss 战利品、任务物品、不可再生生物材料和具有独立进度价值的稀有组织不得进入可复制清单。

## 异彩面团

异彩面团代表不同食品文化的主食基底，并作为轻科技料理候选之一。

代表性材料可以包括：

- 普通小麦面团。
- 全麦面团。
- 米制或糯米面团。
- 玉米面团。
- 油酥面团。
- 曲奇面团。
- 披萨面团。
- 面条或意面面团。
- 异界谷物、魔法谷物或特殊地区面团。

推荐序列组装表现：

```text
基础面团
-> 压制
-> 涂油
-> 部署米粉或玉米粉
-> 涂奶油
-> 切割
-> 注入糖浆
-> 再次压制
-> 异彩面团
```

异彩面团除作为七种悖论之一外，还可以用于制作异彩糕点基底和其他终盘食品，避免成为一次性任务零件。

## 无尽奶酪

无尽奶酪以 AE2 奇点为输入，表现“将漫长熟成时间压缩进一个物品”。概念上经过 1024 次奶酪序列组装，但实现上不要求机器真实执行 1024 次：

- 可以使用 32 或 64 轮加工，每轮写入 16 或 32 层熟成进度。
- 也可以使用专用中间物品 NBT 记录 `AgingLayers`，在达到 1024 层时完成。
- 加工步骤由注入牛奶、涂盐、压制、熏制、涂蜡和切割检查组成。

产出的无尽奶酪本体作为不被消耗的资源源：

- 砧板：返还无尽奶酪并产出少量普通奶酪片。
- 动力锯：返还无尽奶酪并产出更多普通奶酪片。
- 加工速度可以随转速提高，但单次配方产量保持固定。

无尽奶酪本体不得进入物质聚合器、生命质回收和订单交付；它切出的普通奶酪是否允许进入普通配方，需要在平衡阶段单独确认。

## 油奇点

油奇点以 AE2 奇点为基底，通过多种食用油、动物油、种子油和特殊油脂的连续注液形成。概念上可以表现为 1024 次注液，但实现时采用进度层数或缩减循环。

建议让油奇点记忆或切换输出模式：

- 分液池：产出定量食用油流体并返还油奇点。
- 砧板：刮取动物油脂、黄油或固态油脂物品。
- 动力锯：产出结晶油或其他适合物流运输的固态油品。
- 额外加工：切换种子油、动物油、橄榄油等输出类型。

第一版应优先输出食用油。柴油、原油等能源流体如果会破坏现有能源进度，应继续要求额外转化，不能由油奇点直接无成本生成。

油奇点及其专用复制产物不能作为生命质来源，也不能直接完成高价值订单。普通烹饪和食品工厂可以正常使用其产物。

## `BIO·寿司`

`BIO` 暂定解释为 `Biodiversity Integrated Omnivorous Sushi`，中文概念为“生物多样性集成杂食寿司”。

### 首次制作

- 使用料理台或专用摆盘结构完成，不采用普通无序合成。
- 米饭作为中央核心，海苔作为边界。
- 按海域、鱼类或食材类别摆放代表性寿司。
- 最后加入生命质、钻石品质稻米或其他食物线催化物完成。
- 后续改为大型动力合成配方。

当前 `kubejs/server_scripts/Custom/food/roll.js` 已维护约 10 种基础寿司组装路线，可作为第一版代表性清单基础。

### 食用效果

食用后不采用完全无规则的药水效果抽取，而是在若干生态状态中随机：

| 状态 | 推荐表现 |
|---|---|
| 共生 | 同时获得多种较弱正面效果 |
| 捕食 | 获得力量和速度，但加快饥饿消耗 |
| 深海 | 获得水下呼吸和夜视，但在陆地受到缓慢 |
| 河豚 | 获得较强幸运，同时中毒 |
| 腐食 | 清除一个负面效果，但增加另一个负面效果 |
| 生态崩溃 | 先承受短时强负面效果，结束后获得长时高阶增益 |

具体效果池需要排除瞬时效果、系统隐藏效果和容易导致死亡循环的组合。

## 彭罗斯曲奇

### 首次制作候选

候选一：使用全部代表性曲奇进行动力合成。

候选二：使用曲奇块搭建向上的不可能阶梯，玩家从最高处向下依次点击完成。每点击一层，该层可以消失并在另一侧重新出现，营造阶梯循环的视觉错觉；完成后产出彭罗斯曲奇，并解锁后续动力合成配方。

优先推荐候选二，因为它与普通全品类动力合成区分明显。实际曲奇清单从 `kubejs/server_scripts/Custom/food/cookie.js` 和相关标签中人工维护。

### 食用效果

彭罗斯曲奇重构玩家当前所有具有持续时间的药水效果。每个效果独立进行一次判定：

- 一种结果：效果等级增加 1，剩余持续时间减半。
- 另一种结果：效果等级降低 1，剩余持续时间翻倍。
- 降级后低于 0 级的效果直接移除。
- 正面和负面效果均参与重构。
- 瞬时效果、隐藏系统效果和特殊不可变效果不参与。
- 建议设置效果等级和持续时间上限，避免与其他模组组合后无限增长。
- 可以加入极低概率的“闭合回路”：等级不变，持续时间重新刷新。

## 轻科技料理支线扩展候选

以下内容可以作为七种悖论的替代项、前置材料或后续扩展，不要求第一阶段全部实现。

### 万酿之母

聚合酒、茶、咖啡、果汁、乳饮和药饮，经多阶段发酵形成。它作为不消耗的发酵催化剂，提高发酵产量或缩短时间，代表“发酵”。

### 原初高汤

将肉汤、鱼汤、骨汤、菌汤、蔬菜汤和异界汤反复浓缩，形成“所有菜肴开始之前的汤”。它可以作为料理锅催化剂，但不能通过静态配方直接赋予钻石品质。

### 四季沙拉

要求四个季节成熟的代表性作物，并要求一定品质。食用效果随当前季节变化；集齐四种季节状态后获得“轮回之味”进度。

### 末餐

由下界、末地、深海、洞穴、蜂巢、星球和终局冒险阶段分别贡献一种可再生食材，作为食之悖论候选与冒险内容之间的轻量汇合点。

### 薛定谔便当

制作后保持封闭，第一次打开或食用时才揭示内部结果。结果应在制作时写入 NBT，避免通过重进、转移容器或重复交互刷新结果。

## 轻科技总线：异彩巡礼

轻科技路线不再设置万味宴席核心、十相回响核心、法术织构核心、神化棱彩核心和秘法光谱核心。料理、魔法与冒险不需要分别做成一棵材料树，而是共同服务于一次“异彩巡礼”解锁：玩家先游玩自己喜欢的若干支线，再用很短的料理配方重复生产异彩化合物。

### 设计原则

- 选择发生在冒险路线，不发生在层层中间材料合成中。
- 候选池应明显大于必选数量，允许玩家避开不喜欢的支线、结构、武器或法术流派。
- 不要求收齐全部十种元素回响、十种法术织锭、全部法术、全部武器、全部护甲或全部宝石。
- 异彩巡礼在星系后期任务节点才开放；纵向 Boss 链只控制开放时间，不作为“任选若干”的独立计数项。
- 冒险完成度负责一次性解锁，料理和奇点负责后续重复成本。

### 固定主线锚点

Northstar 与 Cataclysm 的星球 Boss 严格意义上是纵向推进链：先驱者、下界合金巨兽、炎魔、远古遗魂、咒翼灵骸与利维坦分别控制后续星球或材料阶段，彼此并不平行。如果把它们逐个放入候选池，玩家沿主线前进时会自然取得大部分计数，“任选五项”就会退化成没有选择的主线清单。

因此异彩巡礼先要求一个固定主线锚点。当前优先建议使用“完成金星主线并取得土卫二航线”：它足够靠后，又不会强迫玩家先击败咒翼灵骸与利维坦，从而把土卫二地表和渊海深窟继续留作可选择的冒险内容。最终节点仍需随任务总线确认，但应遵守：

- 主线 Boss 只负责解锁异彩巡礼，不逐个提供巡礼点数。
- 更晚的主线 Boss 不重复计算此前 Boss 的价值。
- 可选 Boss 只有在自身属于独立支线时，才可以作为对应篇章的内部目标；同一条前后置 Boss 链不能拆成多个候选。

### 横向冒险篇章

达到固定主线锚点后，玩家或队伍从九个篇章中完成任意四个。篇章代表可互相替代的游玩方向，而不是单件战利品；正式落地时由 FTB Quests、进度或队伍持久数据记录：

| 横向篇章 | 完成条件方向 |
|---|---|
| 蜂域圣所 | 获取 `the_bumblezone:essence_of_the_bees`，并完成红、紫、蓝、绿、黄、白六色永恒圣所中的任意一座竞技场，取得一个 `#the_bumblezone:ability_essence_items` 能力精华 |
| 夜巡者讨伐 | 访问 Void Cathedral 并击败 Nightwarden；原“末地远征”删除，夜巡者作为一条明确的 T.O 独立挑战线 |
| 异常生态图鉴 | 月背异寂空谷、水星磁场洞穴、金星辐射洞穴、金星原始洞穴、土卫二渊海深窟五个区域中任选三个，各取得一种人工指定的代表性遗物；不要求击败对应主线 Boss |
| 武器博览 | T.O 实际存在 15 条 mastery 进度，从人工平衡后的候选中任选四条完成，不再以单把三级武器作为整个篇章 |
| 护甲博览 | T.O 实际存在六套护甲收集进度，任选三套完成；套装必须来自同阶段白名单，并结合任务链防止临时借用触发 |
| 四系宗师 | Iron's Spells / T.O Magic 的人工学派池中任选四个学派，各获得并成功施放一个代表性的传奇或满级法术；不要求全法术收集 |
| 远古武装 | 获取一件受本包阶段投放控制的 Apotheosis `ancient` 品质装备；Fallen 宝石、符印和插槽可以用于强化，但不额外要求做成复杂构筑 |
| 泰坦编年史 | 获取完整 13 张泰坦卷轴；对应灾变 Boss 击杀只作为卷轴配方前置和任务过程展示，不再另设“击杀若干灾变 Boss”篇章 |
| 诸神黄昏 | 末影龙后个人难度进入第六档，即按当前代码原始值 `> 600`，并在保持诸神黄昏档位时击败任意一个可重复挑战的 Cataclysm Boss；允许通过现有任务投入资源调整难度，但只达到数值不算完成 |

候选篇章保持“九选四”。一个篇章内部可以继续使用“多个里面选择几个”，但不能把同一纵向任务链的每一步分别计数。泰坦编年史的实际工作量显著高于普通篇章，可提供额外纪念物、称号或创造路线进度，但为保持巡礼规则直观，仍只计算一个篇章。

### 巡礼凭证

完成任意四个横向篇章后，任务奖励一个“异彩巡礼凭证”：

- 凭证按队伍解锁，避免多人服务器重复跑同一套一次性进度。
- 凭证在轻科技异彩配方中只参与校验并返还，不作为持续消耗品。
- 凭证只证明冒险资格，不复制 Boss 掉落，也不替代各模组原本的装备成长。
- 若不希望新增实体物品，也可直接用队伍阶段数据控制配方可用性；新增凭证的主要价值是给玩家明确反馈和 JEI 展示入口。

### 轻科技异彩化合物

推荐最终结构：

```text
达到固定主线锚点 + 横向篇章九选四 ─> 可返还的异彩巡礼凭证 ─┐
七种食之悖论中任选 3 种不同食品 ─────────────────┼─> 一次料理仪式或短动力合成 ─> 异彩化合物
AE2 奇点 ─────────────────────────────────────────┘
```

实际合成只包含一个奇点、三种不同的悖论食品和一个返还的巡礼凭证。首次可在餐桌、料理台或小型宴席结构中点击中央奇点完成，之后解锁一条短动力合成或工作盆配方；不再经过任何中间核心。

“三种不同食品”必须校验不同物品 ID，不能用三份同类食品占满。七种食品只需任选三种，因此玩家可以建设三条喜欢的产线，也可以为了换线、展示或全收集继续制作其余食品。

轻科技路线仍可使用工作盆、动力合成、料理台和少量 AE2 物流，但不要求核能、Northstar 高阶电路、工业色谱仪或持续高吞吐运行。它的主要门槛是玩家已经完成足够多的冒险内容；获得资格后，重复生产应保持直观，不再用复杂合成树重新征税。

## 重科技路线

科技线由若干工业证明组成，避免退化为昂贵锭的无序混合：

| 工业证明 | 代表系统和材料 |
|---|---|
| 物质压缩 | AE2 奇点、物质聚合器、大规模原料吞吐 |
| 精密制造 | 精密构件、序列组装、多阶段机械加工 |
| 极端能量 | 高应力动力网络、电力、高温或超热加工 |
| 光暗前体控制 | 信标光、发光材料、黑曜石、虚空或空间材料，不直接消耗下游的光辉石和暗影钢 |
| 空间计算 | 量子缠绕态奇点、AE 网络和跨维度设施 |
| 流体工程 | 多种高阶流体的精确连续注液 |

这些工业证明最终聚合为“工业色谱核心”，再经过压块塑形或专用终盘工艺形成异彩化合物。光暗分流发生在异彩化合物形成之后，避免配方材料层级循环。

科技线的平衡定位：

- 建设成本和持续能耗较高。
- 配方稳定、吞吐量高，适合批量制造。
- 主要考验大型自动化、物流调度和多机器协作。
- 不要求收集全品类食物或进行世界结构料理仪式。

### 无限供料前提

科技线不能把奇点和普通可存储材料的数量当作主要成本：

- 当前已有 `create:crushing_wheel -> ae2:singularity` 的悖论奇点配方。
- ME 无限元件可以持续供应已解锁的物品或流体。
- 无限流体元件清单已经覆盖多种熔融金属，包括耐久合金、钛和火星钢等后期材料。

因此奇点应作为异彩化合物的语义基底和持续物质流，而不是稀有门票。科技线真正考验的是工业色谱设施、同时输入能力、FE 和 Create 动力吞吐、冷热/真空条件以及长时间稳定运行。单纯把每批奇点数量从 1 提高到 64 只能增加等待时间，不能形成新的工程挑战。

## 光辉石与暗影钢分流

异彩化合物形成后继续沿 Create 原有主题分流：

### 光辉石

光辉石通过让异彩化合物吸收光源或进入信标光柱形成，主题是“将一切可能性显现并稳定为光”。

光辉石负责显现、输出、观测、加速和稳定，不负责凭空复制。现有 Vintage Improvements 已提供光辉石杆、线、弹簧和板，可以直接作为统一加工件。

推荐具体部件：

| 部件 | 主要材料 | 用途 |
|---|---|---|
| 光谱透镜 | 光辉石板、光辉石线、月球蓝宝石或高阶光学晶体、Northstar 高级电路 | 升级轨道遥测、卫星扫描、隐藏航点发现和高级激光加工 |
| 显化线圈 | 光辉石线、弹簧、充能晶体和高级电路 | 提高 AE2 输出、装配矩阵速度和高吞吐接口能力 |
| 光辉能源核心 | 显化线圈、高阶电容和持续充能产物 | 稳定、缓存和分配已有能源，不提供无条件创造能源 |
| 光辉机壳 | 光辉石与基础机壳 | 搭建显化室、光学设备和高阶精密机器 |

推荐接入现有但已禁用配方的 ExtendedAE Plus 内容：

- `extendedae_plus:assembler_matrix_upload_core`
- `extendedae_plus:assembler_matrix_speed_plus`
- `extendedae_plus:energy_storage_core`

光辉路线的代表机器可以是“显化室”：

- 使用光辉机壳搭建。
- 把已有扫描、计算或网络状态显化为可输出的结果。
- 制作光谱透镜、显化线圈和光辉能源核心。
- 可以承担食品恒温、保鲜和品质识别，但不能直接制造品质。

### 暗影钢

暗影钢通过让异彩化合物坠入世界底部以下的虚空区域形成，主题是“将一切可能性压入不可见的空间”。

暗影钢负责隐藏、吸收、压缩、隔离和湮灭，不负责凭空生产。现有 Vintage Improvements 已提供暗影钢杆、线、弹簧和板，可以直接作为统一加工件。

推荐具体部件：

| 部件 | 主要材料 | 用途 |
|---|---|---|
| 湮灭奇点 | 奇点簇、暗影钢板、虚空钢、空间组件，经真空和虚空处理 | 暗影机器、光暗共同制品和空间压缩的核心 |
| 暗影存储核心 | 暗影钢加工件、空间存储组件和高级处理器 | 提供高类型容量、现场缓存和特殊状态隔离 |
| 熵汇 | 暗影线圈、湮灭奇点和过滤组件 | 按规则接收并销毁产线溢出，可低效率回收物质球但禁止形成正收益闭环 |
| 相位仓 | 暗影机壳、暗影存储核心和多类型接口 | 暂存大型机器输入、危险流体、特殊 NBT 物品和未完成加工状态 |

推荐重新启用或重写配方的 ExtendedAE Plus 内容：

- `extendedae_plus:oblivion_singularity`
- `extendedae_plus:storage_core`
- `extendedae_plus:spatial_core`

暗影路线不应只做更大的 ME 磁盘：

- ME 磁盘负责长期网络存储，相位仓负责机器现场和异常状态缓冲。
- 熵汇负责可控溢出治理，不允许把无限元件输出高效率回收为新的高价值资源。
- 食物侧可以使用暗影容器封存随机结果、药水效果或特殊料理状态。

### 光暗共同制品

光辉石负责把东西送出和显现，暗影钢负责把东西收入和隐藏；两者合用后，才允许获得相位传输、双向接口和现实重构能力。

#### 相位稳定核心

相位稳定核心由光谱透镜、湮灭奇点、光辉能源核心、暗影存储核心和一对量子缠绕态奇点组成，是光暗共同设备的基础部件。

#### 相位物流端口

两个端口成对绑定：

- 一端把物品、流体或 FE 收入暗影空间，另一端从光辉侧显化。
- 支持远距离和跨维度，但必须有明确吞吐量。
- 两端需要加载，或依赖已部署的卫星/空间站中继。
- 可以连接 Create 传送带、流体管道和 AE2 网络。
- 尚未探索或未写入星图的星球不能远程连接。

#### 双向现实接口

- 输出模式承担强化成型面板能力。
- 输入模式承担强化湮灭面板能力。
- 根据过滤器、红石或网络状态切换方向。
- 用于动态结构停靠站、装配矩阵和大型多方块机器。

#### 超级装配矩阵核心

ExtendedAE Plus 现有但被禁用的装配矩阵内容可以按材料身份重新分配：

| 物品 | 材料归属 |
|---|---|
| 装配矩阵上传核心 | 光辉石 |
| 超级装配矩阵速度核心 | 光辉石 |
| 超级装配矩阵样板核心 | 暗影钢 |
| 超级装配矩阵合成核心 | 光辉石 + 暗影钢 |
| 存储核心、空间核心 | 暗影钢 |

#### 星间物流中继

- 安装在卫星或空间站上，为相位物流端口提供跨星球中继。
- 仍受星图科研点、目的地解锁、能源和吞吐量限制。
- 只减少后期基础物资搬运，不替代首次登陆、探索和Boss挑战。

第一版优先控制在以下八件内容：

| 分支 | 第一批内容 |
|---|---|
| 光辉石 | 光谱透镜、显化线圈、超级装配矩阵速度核心 |
| 暗影钢 | 湮灭奇点、暗影存储核心、熵汇 |
| 光暗共同 | 相位稳定核心、相位物流端口 |

后续再扩展双向现实接口、超级装配矩阵、星间物流中继和食物侧悖论容器。异彩化合物只负责供应两种分支原料，不应跳过光辉石和暗影钢直接制作这些下游成品。

## 创造级物品设计

创造级物品应作为玩家已经解决某个系统后的基础设施压缩和纪念性奖励，而不是新的主线门槛。任何普通进度物品都不应强制要求先拥有创造级物品。

### 三档能力

| 档位 | 定位 | 示例 |
|---|---|---|
| 准创造设备 | 能力极强，但仍受 FE、应力、吞吐、范围或中继限制 | 相位物流端口、光辉能源核心、相位仓 |
| 专用创造设备 | 只替代一个已经彻底解决的系统，允许生存制作 | ME 创造能源元件、创造马达、创造烈焰蛋糕等候选 |
| 万能创造物品 | 可以复制任意资源或彻底绕过多条进度，只作为全包完成奖励或保持不可合成 | 创造板条箱、创造流体储罐、通用创造发电机 |

### 推荐允许生存制作的候选

| 物品 | 建议 | 原因 |
|---|---|---|
| `ae2:creative_energy_cell` | 可以较早进入创造级阶段 | 只解决 AE 网络供能，不直接为全部 FE 机器提供无限能源 |
| `create:creative_motor` | 可以作为光暗下游较晚奖励 | 只解决 Create 动力源，但会压缩应力与发电建设，不能过早开放 |
| `create:creative_blaze_cake` | 可以开放 | 玩家已完成高级热力设施后，适合锁定燃烧室热量并压缩燃料补给 |
| `createaddition:creative_energy` | 只在更晚阶段开放 | 通用无限 FE 会让核能、发电和储能设施失去持续价值 |

### 不宜普通开放的物品

| 物品 | 建议 | 风险 |
|---|---|---|
| `create:creative_crate` | 全包完成奖励或保持不可合成 | 可以复制任意物品，绕过食品、Boss战利品、订单和特殊 NBT 边界 |
| `create:creative_fluid_tank` | 全包完成奖励或保持不可合成 | 可以指定任意流体，绕过无限元件白名单、品质流体和能源流体边界 |
| Northstar 创造星图 | 保持创造模式专用 | 会跳过科研点、隐藏目的地和首次探索 |
| 世界塑造、管理员和生成类工具 | 保持创造模式专用 | 属于地图维护和测试工具，不是生存奖励 |

### 创造胚胎

如果开放多个创造级配方，可以制作统一中间物“创造胚胎”或“现实种子”：

- 由相位稳定核心、光辉石、暗影钢和对应系统的终结证明组成。
- 每件创造级物品消耗一个创造胚胎，再追加该系统的专属证明。
- 创造马达追加完整动力系统证明。
- 创造能源设备追加核能、储能和高功率设施证明。
- 万能物品复制和流体复制能力必须追加全包完成证明，而不能只靠异彩材料量产。

创造胚胎只统一配方结构，不作为普通终盘物品的必需材料。

### 配方与奖励方式

- 专用创造设备允许重复制作，因为玩家可能需要多个创造马达、ME 创造能源元件或永久燃烧室建设大型基地。
- 通用创造发电机可以限制为每队首次任务奖励，后续是否允许复制取决于能源阶段是否仍有建设价值。
- 创造板条箱和创造流体储罐更适合作为一次性队伍任务奖励，而不是普通 JEI 配方。
- 如果创造板条箱能够复制 Boss 战利品和任务物品，其奖励条件必须位于科技、食物、冒险和星系主要内容全部完成之后。
- 普通光辉石、暗影钢和相位设备不要求同时完成重科技与轻科技两条异彩化合物来源；只有可绕过全包内容的万能创造物品可以要求两条路线和其他章节全部完成。

### 创造级硬边界

- 创造级物品不进入订单、生命质、物质聚合和普通回收系统。
- 创造板条箱和创造流体储罐若可在生存获得，必须确认其过滤、NBT 和流体品质行为；无法限制时保持不可合成。
- 无限元件已经负责受控的单资源无限供应，不再用普通光暗设备重复奖励同一种能力。
- 创造级物品属于完成后的减负，不用于解锁仍未游玩的星球、Boss、食品收集或任务章节。

## 当前 Create 运行时基础

本地 `mods/create-1.20.1-6.0.8.jar` 中仍保留以下旧内容：

- `ChromaticCompoundItem`、`RefinedRadianceItem` 和 `ShadowSteelItem` 实现类。
- 异彩化合物吸收光源并转化为光辉石的逻辑。
- 异彩化合物坠入世界底部以下并转化为暗影钢的逻辑。
- 光辉机壳、暗影机壳及相关模型和纹理。

`defaultconfigs/create-server.toml` 当前设置为：

- `enableRefinedRadianceRecipe = true`
- `enableShadowSteelRecipe = true`
- `lightSourceCountForRefinedRadiance = 10`

因此当前规划的“重新启用”重点不是重新编写光暗转化逻辑，而是：

1. 恢复异彩化合物的科技和食物获取路线。
2. 确认旧光暗转化在实际游戏中的表现、批量处理和物品损失风险。
3. 为光辉石和暗影钢设计足够明确的下游物品树。
4. 补齐 JEI、任务和 Ponder 引导，让玩家知道异彩化合物只是中间体。

## 无限资源边界

无尽奶酪、油奇点和怪异肉团等资源源允许玩家解放基础食品生产，但应遵守以下边界：

- 资源源本体不得被物质聚合、销毁换取奇点或复制自身。
- 资源源本体和专用衍生产物不得转化为生命质。
- 不允许用资源源直接完成高价值订单或无限刷取订单声望与货币。
- 不输出 Boss 战利品、任务物品和不可再生材料。
- 不直接输出会跳过能源进度的燃料流体。
- 每次加工仍需要机器时间、转速、应力、容器或其他明确操作成本。
- 普通食品配方可以使用其基础产物，让终盘玩家真正感受到资源自由。

如果普通产物仍能通过现有系统间接转化为高价值资源，应优先在订单、生命质或物质聚合入口排除对应来源，而不是让所有终盘无限食品都失去普通配方兼容性。

## 实现方向

可能需要的实现能力包括：

- KubeJS 注册终盘食品、中间物和配方。
- `BlockEvents.rightClicked` 或 CDC 代码验证冰淇淋色环、曲奇阶梯和宴席结构。
- 玩家或队伍进度记录首次仪式，并在 FTB Quests 中引导后续自动化配方。
- NBT 记录奶酪熟成层数、油奇点模式和薛定谔便当结果。
- CDC 处理返回原物品的砧板、动力锯和分液池加工，或验证静态配方是否能安全表达容器返还。
- 专用标签维护悖论食品清单、禁止聚合物品、禁止生命质回收物品和禁止订单物品。
- 对药水效果重构、随机生态状态和无限资源出口进行服务端逻辑控制。
- 维护异彩巡礼候选进度、悖论食品和 T.O Magic 敏感法术的人工清单，不按注册表自动扩张。
- 通过数据包或兼容代码控制 Apotheosis/Fallen 宝石、词缀、符印和品质上限，继续禁止默认全局投放。
- 对百分比伤害、伤害上限绕过、复活、禁用物品、地形破坏和大型召唤法术设置配方、自动施法和任务边界。

首次仪式和后续配方解锁应按玩家还是队伍记录，需要与现有 FTB Quests 队伍进度和服务器游玩方式一起确定。

## 分阶段建议

### 第一阶段：路线骨架

- 确认异彩化合物作为共同中间体的需求量。
- 确认重科技线、轻科技线产出完全相同的物品。
- 确认光辉石、暗影钢和双极共同制品的第一批下游物品。
- 确认七种食之悖论的最终名单。
- 确认异彩巡礼固定主线锚点、“横向篇章九选四”和悖论食品“七选三”的正式名单。
- 为冒险里程碑、悖论食品和敏感能力维护明确的人工清单与排除项。

### 第二阶段：轻科技单件原型

- 优先实现炫彩冰淇淋首次结构与后续动力合成。
- 实现彭罗斯曲奇效果重构，验证与现有药水效果模组兼容性。
- 实现无尽奶酪或油奇点中的一个，验证返回原物品和经济排除规则。
- 恢复 Iron's Spells 与 T.O Magic 运行时依赖，验证候选遗迹、武器 mastery、护甲套装和关键 Boss 进度。
- 制作固定主线锚点、“横向篇章九选四”队伍进度与可返还巡礼凭证原型，不要求全部法术和武器收藏。

### 第三阶段：双路线闭环

- 完成七种悖论食品候选池和“三种不同食品”校验。
- 完成异彩巡礼候选池、队伍解锁和凭证返还逻辑。
- 完成工业证明和工业色谱核心。
- 分别完成轻科技与重科技异彩化合物配方。
- 验证异彩化合物到光辉石、暗影钢的旧 Create 转化。
- 接入任务章节、JEI、Ponder、语言和进度。
- 对比两条路线的建设成本、持续成本和单位产量。

### 第四阶段：光暗下游物品

- 分别实现光辉石系、暗影钢系和光暗共同制品。
- 下游配方优先消耗光辉石或暗影钢，不直接绕回异彩化合物。
- 增加纪念性建筑或收集目标。
- 根据实际游玩数据调整无限资源、生命质、订单和能源边界。

## 待定问题

- 七种悖论是否全部保留，还是让万酿之母、原初高汤等替换其中一项。
- 首次世界结构按玩家解锁还是按队伍解锁。
- 首次仪式是否消耗全部结构方块，或只消耗中央材料并保留展示建筑。
- 后续炫彩冰淇淋是否要求不消耗的母种。
- 怪异肉团切出的肉类采用随机、固定轮换还是可配置模式。
- 无尽奶酪和油奇点真实加工轮数、表现层数与机器时间。
- 油奇点是否只覆盖食用油，还是允许通过额外工艺转化为工业油。
- 彭罗斯曲奇对正面、负面、环境和模组自定义效果的具体排除表。
- 轻科技料理是否必须消耗钻石品质食品，以及如何避免静态配方伪造品质。
- 异彩巡礼固定主线锚点是否最终采用当前推荐的“完成金星主线并取得土卫二航线”。
- 横向篇章是否保持九选四，以及未来新增篇章时是否维持接近一半的选择比例。
- 巡礼凭证采用实体可返还物品，还是只用 FTB Quests 队伍数据控制配方解锁。
- 异常生态图鉴五个区域各自采用哪一种不可由普通生产线伪造的代表性遗物。
- 武器博览是否正式采用十五选四，以及应排除哪些成本明显偏低或依赖敏感能力的武器。
- 护甲博览是否正式采用六选三，以及如何记录队伍实际完成而不是临时借用成品。
- 四系宗师的人工学派池、代表法术与“成功施放”记录方式。
- 远古武装从哪些受控 Boss、地牢或任务奖励池投放，继续禁止 Apotheosis 默认全局生成。
- 泰坦编年史按队伍收集 13 张卷轴还是要求同一玩家持有完整套；灾变 Boss 击杀不再另算篇章。
- 诸神黄昏篇章采用哪些可重复挑战的 Cataclysm Boss 白名单，以及任务如何在击杀瞬间校验个人难度仍处于第六档（当前实现为原始值 `> 600`）。
- T.O Magic 四组六档 Skilltree 宝石是否随 Skilltree 一并加入；若加入，只作为可选构筑内容，不成为异彩合成硬材料。
- 哪些 T.O Magic 法术必须禁止自动施法、降低效果或从轻科技候选目标排除。
- T.O Magic 分级武器 mastery 是否需要按武器大类合并进度，避免某些武器过易或过难。
- 光辉石、暗影钢分别优先服务哪些下游系统。
- 哪些更高阶物品必须同时消耗光辉石和暗影钢。
- 是否保留 Create 原有的吸光和坠入虚空转化方式，还是增加可自动化但更昂贵的机器配方。
- 原有吸光转化会消耗附近光源，是否需要限制可吸收方块或提供专用光源阵列。
- 暗影钢的虚空转化如何提供安全回收和自动化，避免成品继续坠入虚空丢失。
- 科技线最终由普通 Create 工艺、MBD2 机器还是 CDC 专用多方块结构承载。
- 终盘无限食品的普通产物是否允许进入 AE2 物质聚合器。

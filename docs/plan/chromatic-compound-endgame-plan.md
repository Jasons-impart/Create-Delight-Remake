# 异彩材料双路线与后续分支设计

本文规划 `create:chromatic_compound`（异彩化合物）的两种生产路线，以及它向 `create:refined_radiance`（光辉石）和 `create:shadow_steel`（暗影钢）分流后的终盘用途。

异彩化合物的定位是**可量产的共同中间体**，不是终盘成品。重科技路线与轻科技路线只负责提供两种体验不同、结果等价的异彩化合物来源；真正的功能型终盘物品由光辉石、暗影钢或两者共同制作。

本文是前瞻设计，不表示相关物品、配方、任务或机制已经实现。未明确标为“确定”的物品名、数量、配方和实现载体仍可在落地阶段调整。

## 一、完整玩家流程

异彩材料链按“路线资格与生产 → 共同中间体 → 光暗分流 → 功能制品”推进：

```text
重科技路线
工业设施 + 持续能耗 + 多系统协作 ────────────────┐
                                                  ├─> 异彩化合物
轻科技路线                                      │
主线阶段 + 横向冒险资格 + 三种悖论食品 ──────────┘

异彩化合物 ─┬─> 光辉石 ──> 显现、观测、输出、稳定类制品 ─┐
            └─> 暗影钢 ──> 隐藏、吸收、压缩、隔离类制品 ─┴─> 相位与现实重构类制品
```

两条异彩路线共享以下规则：

- 产出相同的异彩化合物，不设置路线专属版本。
- 玩家完成任意一条路线即可继续制作光辉石、暗影钢和普通光暗下游物品。
- 同时完成两条路线只提供成就、称号、装饰或纪念物，不作为普通主线硬门槛。
- 异彩化合物不直接制作高级功能物品，避免绕过光辉石与暗影钢的材料身份。

### 两条路线的职责差异

| 路线 | 一次性门槛 | 每批生产成本 | 主要体验 |
|---|---|---|---|
| 重科技路线 | 建成工业异彩分相阵列，并具备合金、离心、核能、航天材料和 AE2 量子物流能力 | 多路熔融金属与工艺流体、持续 FE、Create 动力和机器时间 | 把现有工程章节汇入一座终端工厂，以线性并行稳定量产 |
| 轻科技路线 | 达到固定主线阶段，并完成横向冒险篇章九选四 | 1 个 AE2 奇点、七种悖论食品中任意 3 种不同食品 | 料理产线、收集展示、遗迹探索和流派养成 |

“轻科技”只表示异彩化合物的复产设施较轻，不表示冒险内容简单。魔法、装备、Boss 和遗迹负责取得一次性资格，料理负责后续每一批异彩化合物的实际消耗；两者不是两套互不相关的支线。

## 二、材料层级与设计边界

| 层级 | 材料 | 定位 |
|---|---|---|
| 共同中间体 | 异彩化合物 | 承接重科技和轻科技两种生产方式，可稳定量产 |
| 单极分支 | 光辉石 | 光、秩序、显现、稳定、观测和输出 |
| 单极分支 | 暗影钢 | 暗、虚空、隐藏、侵蚀、压缩和隔离 |
| 双极分支 | 光暗共同制品 | 同时消耗光辉石和暗影钢，表达相位、平衡和现实重构 |
| 完成奖励 | 专用或万能创造物品 | 压缩已经解决的系统，不参与解锁尚未完成的内容 |

设计需要遵守以下边界：

- 不要求所有玩家同时完成重科技线与轻科技线。
- 不扫描注册表中的全部食物、法术、装备或战利品；候选内容使用人工维护的清单和标签。
- 不以真实执行 1024 次高频加工制造等待和服务器负担；大数量用较少循环、进度层数或 NBT 表达。
- 不让无限资源直接兑换生命质、高价值订单、Boss 材料、任务物品或新的奇点。
- 不把已有无限供料能力伪装成科技线的稀缺材料门槛。
- 不在本规划中锁死最终数值、物品 ID 和普通 Create、MBD2、CDC 多方块等实现载体。

## 三、轻科技路线

轻科技路线由两层组成：

1. **异彩巡礼**：主线阶段与横向冒险共同提供一次性生产资格。
2. **食之悖论**：七种终盘食品构成重复生产材料池，每批任选三种不同食品。

因此，冒险、魔法、Apotheosis、Fallen 与料理的关系是“先取得资格，再选择料理成本”，而不是把所有系统的材料堆进同一条配方。

### 3.1 异彩巡礼：一次性资格

#### 固定主线锚点

Northstar 与 Cataclysm 的星球 Boss 构成纵向推进链。纵向 Boss 只负责决定异彩巡礼何时开放，不逐个计入横向选择数量，否则玩家沿主线推进时会自然获得大部分计数，使“任选”失去意义。

当前优先候选是“完成金星主线并取得土卫二航线”。这个节点足够靠后，同时仍能把土卫二地表、渊海深窟、咒翼灵骸和利维坦等内容留给后续选择。最终锚点需要结合正式任务总线确认。

固定锚点遵守以下规则：

- 前后置关系明确的 Boss 链只作为一个纵向阶段，不拆成多个横向篇章。
- 更晚的主线 Boss 不重复计算已经完成的主线阶段。
- 独立支线 Boss 可以作为某个横向篇章的内部目标，但不能与其前置发现任务分别计数。

#### 横向冒险篇章：九选四

达到固定主线锚点后，玩家或队伍从九个篇章中完成任意四个。每个篇章代表一种完整游玩方向，而不是一件可以临时借来的成品。

| 横向篇章 | 完成条件方向 | 在轻科技路线中的作用 |
|---|---|---|
| 蜂域圣所 | 获取 `the_bumblezone:essence_of_the_bees`，并完成六色永恒圣所中的任意一座竞技场，取得一个 `#the_bumblezone:ability_essence_items` 能力精华 | 证明蜂域探索与竞技完成度 |
| 夜巡者讨伐 | 访问 Void Cathedral 并击败 Nightwarden | 作为一条完整的 T.O 独立挑战线 |
| 异常生态图鉴 | 月背异寂空谷、水星磁场洞穴、金星辐射洞穴、金星原始洞穴、土卫二渊海深窟中任选三个，各取得一种人工指定的代表性遗物 | 证明跨星球生态探索，不依赖生产线伪造 |
| 武器博览 | 从人工平衡后的 T.O mastery 候选中完成四条 | 证明武器流派投入，不以持有一把成品代替 |
| 护甲博览 | 从六套候选护甲中完成三套，并结合任务链记录制作或升级过程 | 证明装备体系投入，避免借用成品触发 |
| 四系宗师 | 从 Iron's Spells / T.O Magic 人工学派池中任选四系，各获得并成功施放一个代表性的传奇或满级法术 | 证明法术流派投入，不要求全法术收集 |
| 远古武装 | 获取一件由本包阶段投放控制的 Apotheosis `ancient` 品质装备 | 证明高阶装备养成；Fallen 宝石与符印只作为强化手段 |
| 泰坦编年史 | 获取完整 13 张泰坦卷轴 | 汇总泰坦卷轴与相关灾变 Boss 过程，不重复拆分计数 |
| 诸神黄昏 | 个人难度进入第六档，并在保持该档位时击败一个白名单内的可重复 Cataclysm Boss | 同时证明高难度状态和实际战斗完成度 |

篇章内部可以继续使用“多个目标中选择若干”的结构，但同一条纵向任务链不能拆成多个篇章。工作量明显较高的篇章可以提供额外纪念物或创造路线进度，九选四的基本计数仍保持直观一致。

#### 资格记录

完成任意四个横向篇章后，队伍获得异彩巡礼资格。实现可以采用可返还的“异彩巡礼凭证”，也可以直接记录为队伍阶段数据。

- 资格按队伍记录，适配多人服务器的一次性进度。
- 凭证若作为实体物品，只参与配方校验并返还，不作为每批消耗。
- 资格只证明玩家完成了足够的冒险内容，不复制 Boss 掉落，也不替代原模组的装备成长。
- 实体凭证的主要价值是提供明确反馈和 JEI 展示入口；若队伍数据能完成同等引导，可以不新增物品。

### 3.2 食之悖论：重复生产材料

七种悖论食品分别证明一种料理生产能力。它们不是冒险资格，也不是只做一次的任务纪念物；每批轻科技异彩化合物会消耗其中三种不同食品。

| 概念 | 悖论食品 | 主要生产证明 | 独立用途 |
|---|---|---|---|
| 光谱 | 炫彩冰淇淋 | 主要冰淇淋风味与冷冻加工 | 环境或风味相关增益食品 |
| 血肉 | 怪异肉团 | 多类蛋白来源与长序列组装 | 可返还本体的基础肉类资源源 |
| 谷物 | 异彩面团 | 多种主食基底与面点加工 | 终盘糕点和复合面食基底 |
| 时间 | 无尽奶酪 | 熟成、发酵与层数加工 | 可返还本体的奶酪资源源 |
| 流动 | 油奇点 | 多种油脂与流体注液 | 可返还本体的食用油资源源 |
| 生态 | `BIO·寿司` | 水域、生物与寿司体系聚合 | 具有可控生态状态的高阶食品 |
| 因果 | 彭罗斯曲奇 | 曲奇体系与不可能结构仪式 | 重构药水效果等级与持续时间 |

怪异肉团、无尽奶酪和油奇点在各自的资源提取配方中返还原物；这不代表它们投入异彩化合物时也返还。轻科技异彩配方会消耗所选的三件悖论食品，确保料理产线仍承担重复成本。

#### 炫彩冰淇淋

**定位**：用完整风味谱和冷冻加工表现“光谱”。

**首次制作候选**：使用人工维护清单中的冰淇淋方块搭建色环、色带或向中心汇聚的结构。玩家用催化物点击中央白色基底，结构验证成功后生成炫彩冰淇淋，并解锁后续自动化配方。

**后续生产**：动力合成消耗代表性冰淇淋球、奶油、基础糖浆和统一容器；是否需要不消耗的母种仍待确认。

**独立用途**：效果可以按风味轮转，或根据环境温度、生物群系与食用时段产生不同增益。

实际风味从现有冰淇淋体系人工选取。`kubejs/server_scripts/Custom/food/icecream.js` 维护的成体系路线可作为首版清单基础，新增联动模组不自动扩大仪式规模。

#### 怪异肉团

**定位**：用家畜、猎物、飞禽、鱼类、甲壳类、洞穴或深海生物、异界生物和特殊可食用组织表现“血肉”。

**生产方式**：长序列组装逐轮部署不同蛋白类别，最后压块塑形。材料使用代表性类别，不要求无条件收集全部肉类。

**独立用途**：

- 砧板切割随机产出一种基础肉类并返还怪异肉团。
- 动力锯按固定序列产出不同肉类并返还怪异肉团，便于自动化分配。
- 料理锅可以制作效果随调味料变化的无名炖肉。

Boss 战利品、任务物品、不可再生材料和具有独立进度价值的稀有组织不进入可复制清单。

#### 异彩面团

**定位**：用不同食品文化的主食基底表现“谷物”。

代表性材料可以覆盖普通小麦、全麦、米或糯米、玉米、油酥、曲奇、披萨、面条或意面，以及少量异界或魔法谷物面团。

推荐加工表现：

```text
基础面团
-> 压制
-> 涂油
-> 部署米粉或玉米粉
-> 涂奶油
-> 切割
-> 注入糖浆
-> 再次压制
-> 异彩面团
```

**独立用途**：作为异彩糕点、终盘面食和其他复合食品的共同基底，避免只在异彩配方中出现。

#### 无尽奶酪

**定位**：以 AE2 奇点承载被压缩的漫长熟成时间，表现“时间”。

**生产方式**：概念上记录 1024 层熟成，但只执行 32 或 64 轮实际加工；每轮通过 NBT 或中间物进度写入多层熟成。加工动作由注入牛奶、涂盐、压制、熏制、涂蜡和切割检查组成。

**独立用途**：

- 砧板返还无尽奶酪并产出少量普通奶酪片。
- 动力锯返还无尽奶酪并产出更多普通奶酪片。
- 转速影响加工速度，单次产量保持固定。

无尽奶酪本体不进入物质聚合、生命质回收和订单交付。普通奶酪片能否进入这些系统，需要在经济平衡阶段单独确认。

#### 油奇点

**定位**：以 AE2 奇点汇聚食用油、动物油、种子油和特殊油脂，表现“流动”。

**生产方式**：连续注液写入油脂层数，以缩减循环或 NBT 进度表达大规模聚合，不真实执行 1024 次高频注液。

**独立用途**：

- 分液池返还油奇点并输出定量食用油流体。
- 砧板返还油奇点并刮取动物油脂、黄油或固态油脂。
- 动力锯返还油奇点并产出适合物流运输的结晶油。
- 额外加工可以切换种子油、动物油、橄榄油等输出模式。

首版只直接输出食用油。柴油、原油等能源流体必须保留额外转化和阶段门槛。

#### `BIO·寿司`

`BIO` 暂定解释为 `Biodiversity Integrated Omnivorous Sushi`，中文概念为“生物多样性集成杂食寿司”。

**首次制作候选**：在料理台或专用摆盘结构中，以米饭为核心、海苔为边界，按海域、鱼类或食材类别摆放代表性寿司，最后加入食物线催化物完成。后续生产改为大型动力合成。

`kubejs/server_scripts/Custom/food/roll.js` 的基础寿司路线可作为首版代表性清单来源。

**独立用途**：食用后从人工维护的生态状态中抽取结果，例如共生、捕食、深海、河豚、腐食或生态崩溃。效果池排除瞬时效果、系统隐藏效果和容易导致死亡循环的组合。

#### 彭罗斯曲奇

**定位**：用不可能结构和效果交换表现“因果”。

**首次制作候选**：使用曲奇块搭建不可能阶梯，玩家按指定顺序交互，使阶梯在两侧循环重构；完成后产出彭罗斯曲奇并解锁自动化配方。普通全品类动力合成可以作为实现成本较低的备用方案。

实际曲奇清单由 `kubejs/server_scripts/Custom/food/cookie.js` 和专用标签人工维护。

**独立用途**：对玩家当前具有持续时间的效果逐个判定：

- 等级增加 1、剩余时间减半；或等级降低 1、剩余时间翻倍。
- 降级后低于 0 级的效果移除。
- 正面和负面效果都可参与。
- 瞬时、隐藏、系统和特殊不可变效果排除。
- 设置等级与持续时间上限，防止跨模组组合无限增长。

### 3.3 料理扩展候选

以下内容属于候选池，不是当前七种悖论的组成部分。它们可以在后续替换某一项、成为前置材料，或扩展为独立终盘食品：

| 候选 | 概念与用途 |
|---|---|
| 万酿之母 | 聚合酒、茶、咖啡、果汁、乳饮和药饮，作为不消耗的发酵催化剂 |
| 原初高汤 | 浓缩肉汤、鱼汤、骨汤、菌汤、蔬菜汤与异界汤，作为料理锅催化剂 |
| 四季沙拉 | 使用四季代表作物和品质条件，效果随季节变化 |
| 末餐 | 由下界、末地、深海、洞穴、蜂巢、星球和终局冒险各贡献一种可再生食材 |
| 薛定谔便当 | 制作时写入 NBT，首次打开或食用时揭示不可刷新的结果 |

### 3.4 轻科技异彩化合物配方

```text
固定主线锚点 + 横向篇章九选四 ─> 队伍异彩巡礼资格 ──────────┐
七种食之悖论中任意 3 种不同食品 ────────────────────────────┼─> 料理仪式或短动力合成 ─> 异彩化合物
AE2 奇点 ───────────────────────────────────────────────────┘
```

推荐配方结构为：

- 1 个 AE2 奇点。
- 3 种物品 ID 不同的悖论食品，各 1 件并全部消耗。
- 1 个可返还的巡礼凭证，或等价的队伍资格校验。

首次制作可以通过餐桌、料理台或小型宴席结构点击中央奇点完成；首次成功后解锁短动力合成或工作盆配方。获得冒险资格后，复产重点是选择和建设三条料理产线，配方结构不设置多层魔法核心或装备核心。

## 四、重科技路线：工业异彩分相工程

现有任务书中的科技内容不是若干平行收藏项，而是一条逐步形成完整工业体系的纵向路线：玩家先掌握 Create 标准机器与物流，再进入冶金、石油与电力，随后取得航天材料、AE2 自动化和超级多方块能力。因此，重科技异彩路线不使用“制作六种工业证明，再把证明合成一个核心”的结构，也不把每个任务章节各抽出一件物品塞进配方。

推荐方案是建设一座新的终端多方块——**工业异彩分相阵列**。它只负责把已经建成的工业体系汇入异彩化合物生产；前置机器、能源网络和物流设施继续承担实际工作，而不是退化成一次性消耗材料。

### 4.1 全任务书审计与职责映射

当前 `config/ftbquests/quests/chapters/` 下共有 39 个章节文件。重科技设计不是只看“伟大工程师”组，也不能把其余章节全部折算成配方材料；审计后的处理方式如下：

| 任务范围 | 代表章节 | 与异彩路线的关系 |
|---|---|---|
| 伟大工程师 | `Junior_Engineer`、`Alloy_Innovation`、`Oil_fired_Power`、`Mineral_Regeneration`、`Super_Multiblock`、`Voyage_of_Stars` | 构成重科技路线的纵向主体，分别提供基础机械、冶金、电力、再生资源、多方块和航天工业 |
| 外星工程师 | `AE2_Basics`、`AE2_Storage`、`AE2_Production_Amplification` | 提供奇点、自动合成、存储、P2P、量子网络和连续供料，是工厂基础设施而非一次性证明 |
| 伟大工程师中的战斗工业 | `Masterful_Machinery` | 保留为枪械与弹药的独立量产线，不为了覆盖章节而强塞进异彩配方 |
| 超级大厨 | `Feast_Afoot`、`Ingredient_Essence`、`Mouse_Chef`、`Youkais_Homecoming` | 主要服务轻科技的悖论食品与料理复产，不与重科技重复收税 |
| 世界之旅 | `Beginning_of_Journey` 至各维度、Boss 与生态章节 | 主要服务轻科技的一次性冒险资格；其纵向星球开放也是重科技取得行星资源的世界前置，但每批材料由 `Voyage_of_Stars` 工业链承接 |
| Tetra 模块化工具 | `the_schematic`、`Those_Who_Came_Before`、`Forge_Heritage`、`Materials` | 是装备锻造与材料运用分支，不作为工业分相阵列的固定输入 |
| 生活技巧与经济辅助 | `Classic_Storage`、`Economic_Playground`、`Production_Amplification`、`Unlock_Trade` 等 | 可改善仓储、产能、移动和经济体验，但不承担异彩主线资格 |
| 引导与配置 | `Introduction`、`Settings`、`Acknowledgement` | 不属于可用于配方设计的进度内容 |

真正进入重科技异彩工程的，是能够形成持续生产约束的系统能力：

| 现有章节或规划 | 已有能力 | 在异彩工程中的职责 |
|---|---|---|
| `Junior_Engineer` | Create 基础机器、传动、流体、真空/压力与标准机器组件原型 | 提供阵列控制器、结构、传动、流体、密封和逻辑部件的基础语言 |
| `Alloy_Innovation` | 工业坩埚、坚钢、虚空钢、真空传输、超级加热与合金电炉前置 | 提供锻造钢/虚空钢结构、熔融金属体系和高温加工能力 |
| `Oil_fired_Power` | 原油开采、分馏、柴油动力、电力、超导连接器和裂变反应堆 | 提供持续高功率、寒冰润滑油以及大型设备的电力输送能力 |
| `Voyage_of_Stars` | 月球蓝宝石、钛、火星钢、Northstar 高级电路、激光加工和行星气体采集 | 提供光学定谱、耐热结构、控制电路和低温/气氛工艺 |
| `Mineral_Regeneration` | 主世界与各行星矿簇、钻井和流体井 | 提供可长期运行的大宗原料，不作为一次性解锁证明 |
| AE2 三章 | 自动合成、奇点、量子缠绕态奇点、量子网桥、P2P 与多类型存储 | 提供物质种子、多路物流、跨区块调度与连续配方供给 |
| `Super_Multiblock` | 合金电炉、大型离心机、裂变反应堆和分级输入输出总线 | 作为工业异彩分相阵列的直接设施基础 |
| `create-processing-multiblock-plan.md` | 工业压力反应室、精密加工中心、机械装配线和通用结构单元规划 | 为阵列的真空、压力、激光和模块化结构提供后续实现参考 |

这套取舍的判断标准是“是否形成持续运行约束”，而不是“章节里是否存在昂贵物品”。任务书负责告诉玩家需要建立哪些能力，阵列配方只持续消耗真正参与生产的物质、流体、能源和机器时间。

### 4.2 推荐终端设施：工业异彩分相阵列

工业异彩分相阵列建议使用 MBD2 实现，并遵守现有多方块规划中的“控制器昂贵、通用部件复用、性能由实际结构决定”原则。

现有体系与阵列的运行关系如下：

```text
矿物再生 / 无限元件 ─> 四路熔融相 ────────────────┐
石油炼化 / Northstar ─> 凛冰燃料、寒冰润滑油 ────┤
AE2 自动化与量子物流 ─> 奇点、过滤、连续补料 ─────┼─> 工业异彩分相阵列 ─> 异彩化合物
裂变反应堆与电网 ─────> 持续 FE ──────────────────┤
Create 动力网络 ───────> 转速与应力 ───────────────┘
```

阵列尽量复用现有内容：

- 外壳使用锻造钢机壳、对应玻璃机壳和现有锻造钢输入输出总线。
- 物品与流体物流使用现有总线；每个总线只代理一种物品或流体，使多路同时进料成为真实结构要求。
- 应力输入继续使用 `createdelight:create_in`。
- 分相柱复用 `createdelight:centrifuge_rotor`，由有效转子段数决定并行批次数。
- 光学段使用月球蓝宝石、Northstar 高级电路和激光加工件表达定谱能力。
- 控制器或定谱模块的配方可以吸收大型离心机、强化充能器、量子链接仓等既有机器价值，但这些机器不作为每批消耗品，也不直接作为可能冲突的活动方块塞进结构。
- 当前标准组件原型中的传动、铜质流体、黄铜控制、密封接头和逻辑组件适合进入控制器与结构模块配方；在组件方案正式冻结前，文档只记录职责，不锁定用量。

阵列至少需要同时接入：

| 接口 | 用途 |
|---|---|
| 物品输入 | 接收 AE2 奇点和必要的加工载体 |
| 多个独立流体输入 | 同时接收结构相、导电相、星际相、虚空相及工艺流体 |
| Create 应力输入 | 驱动分相转子，RPM 与有效转子段共同决定是否能够运行 |
| FE 输入 | 驱动真空、激光定谱和最终高能烧结 |
| 物品输出 | 输出异彩化合物；输出堵塞时整批不得提前消耗 |

这座阵列是重科技路线唯一新增的终端设备。合金电炉、大型离心机、裂变反应堆、矿物再生和 AE2 网络仍保持各自用途，不为异彩路线再复制一套同功能机器。

### 4.3 每批进料

第一版进料应使用整合包已经存在且具有明确工业身份的材料，不新增五六种只服务本配方的“工业核心”。推荐的材料类别如下：

| 进料类别 | 推荐内容 | 表达含义 |
|---|---|---|
| 物质种子 | 1 个 `ae2:singularity` | 为多种相态提供可压缩的共同基底 |
| 结构相 | `createdelightcore:molten_forged_steel` | 表达大型工业结构和耐压外壳 |
| 导电相 | `createmetallurgy:molten_electrum` | 表达能量传输与电磁响应 |
| 星际相 | `createdelightcore:molten_titanium` 或 `createdelightcore:molten_martian_steel` | 表达航天材料、耐热和行星工业 |
| 虚空相 | `createmetallurgy:molten_void_steel` | 表达相位隔离和光暗分流前体 |
| 低温工艺流体 | `createdelight:cryo_fuel` | 在真空与激光阶段稳定尚未定型的相态 |
| 转子维护流体 | `createdelight:ice_lubricating_oil` | 维持长时间高转速分相，不承担材料稀缺性 |

这些熔融金属大多已经能够通过无限元件持续供应，所以它们的价值不在“每桶很贵”，而在机器需要多个独立流体口、持续吞吐、正确过滤和稳定供给。凛冰燃料与寒冰润滑油则把 Northstar 气体、灵质、石油炼化和冷却工艺接入同一条工程链。

具体流体量、是否允许钛与火星钢二选一，以及凛冰燃料与寒冰润滑油的每批消耗仍需平衡测试；材料类别和系统职责可以先固定。

### 4.4 单次生产循环

阵列内部使用一件持续变换状态的异彩胚料完成全部阶段，不为每一步注册一个可库存、可绕过的中间核心。UI、Ponder 或控制器状态应显示当前阶段：

| 阶段 | 阵列动作 | 主要系统来源 |
|---|---|---|
| 质密进料 | 让奇点吸收四路熔融相，形成未定谱的异彩胚料 | AE2、多流体总线、冶金体系 |
| 压力与真空净化 | 交替加压和抽真空，排除不能稳定共存的杂相 | Vintage Improvements、工业压力反应室规划 |
| 高速离心分相 | 在寒冰润滑油维持下将胚料分成可控制的光谱层 | 大型离心机、Create 应力网络 |
| 激光定谱 | 使用月球蓝宝石光学件和 Northstar 高级电路对光谱层进行校准 | 航天材料、精密加工、高压充能 |
| 高能烧结 | 在持续 FE 和凛冰燃料稳定下重新合并各相，输出异彩化合物 | 裂变反应堆、电力网络、低温工艺 |

五个阶段属于一座机器的一个生产循环，不要求玩家在五台机器之间手工搬运五种半成品。这样既能表现复杂工业过程，也不会重现轻科技方案曾经出现的层层核心合成问题。

阵列中的压力与真空步骤只属于这条专用异彩流程，不接管普通 `vintageimprovements:pressurizing` 与 `vintageimprovements:vacuumizing` 配方；通用压力加工仍由规划中的工业压力反应室负责，避免终端阵列变成万能机器。

### 4.5 并行与量产规则

重科技路线的优势应来自大型设施的线性并行，而不是降低材料消耗：

```text
有效批次数 = 符合结构要求的分相柱段数
总输入、总 FE 与总应力需求 = 单批需求 × 有效批次数
总输出 = 单批异彩化合物产量 × 有效批次数
```

- 分相柱设置明确的最少与最多段数，第一版不提供无限扩展。
- 增加柱段只增加并行，不提高单批材料产率。
- FE、流体与应力按批次数同比增加，机器时间保持稳定，便于玩家直接计算扩建收益。
- 任一输入不足、转速下降、FE 断供、输出堵塞或结构失效时暂停当前循环，不吞掉部分原料。
- 裂变反应堆是当前最合适的持续高功率来源，但阵列检查实际供电能力，不把“持有一个反应堆方块”当作伪证明。

### 4.6 与其他方案的比较

| 方案 | 评价 |
|---|---|
| 终端分相阵列 + 外部基础设施 | **推荐**。现有机器继续生产材料、能源和物流，终端阵列只承担异彩循环，任务书关系最清楚 |
| 合金电炉 → 真空室 → 大型离心机 → 激光机的分布式链 | 可以作为低开发成本备选，但跨四种配方系统搬运中间状态，自动化、失败恢复和任务引导更割裂 |
| 六种工业证明 → 工业核心 → 异彩化合物 | 不推荐。它把任务章节压缩成一次性物品清单，设施建成后也没有持续运行价值 |

### 4.7 量产定位与无限供料边界

- 建设成本和持续能耗显著高于轻科技复产设施。
- 配方固定、吞吐稳定，适合长期批量制造。
- 主要考验多路流体、AE2 调度、Create 应力、FE 和输出缓存的协同运行。
- 矿物再生和无限元件负责消除重复挖掘，不负责跳过阵列建设与运行。
- 奇点是物质种子，不通过堆叠 64 个奇点制造虚假的稀缺门槛。
- 枪械、料理、装备、Boss 和经济内容不作为重科技配方输入。
- 阵列只输出异彩化合物，光辉石与暗影钢仍在后续阶段完成分流。

### 4.8 任务书叙事与节点建议

重科技章节应把终点描述成“让既有工厂协同稳定运行”，而不是“再收集一组最贵的物品”。可以使用以下玩家可见引导作为基调：

> 你已经能够再生矿物、熔炼行星金属、驾驭裂变能量，也能让 AE2 网络跨越空间持续调度物质。异彩化合物的最后难题不再是寻找一种更稀有的矿物，而是让结构、导电、星际与虚空四种互不相容的相态，在高压、真空、离心与激光定谱中保持同一条稳定生产节拍。建造工业异彩分相阵列，把整座工厂真正连接起来。

推荐将任务节点拆成五步：

1. **工业汇流**：说明合金电炉、大型离心机、裂变反应堆、矿物再生、AE2 与航天工业各自提供什么，不重复要求提交已经完成过的机器。
2. **建造分相阵列**：制作控制器与关键模块，使用任务蓝图或 Ponder 完成最小结构。
3. **六路稳定供给**：接通四路熔融相、凛冰燃料与寒冰润滑油，并分别建立过滤和缓存；奇点走独立物品输入。
4. **第一次定谱**：在 FE、应力和输出空间全部满足时完成首批异彩化合物，任务检测产物或专用进度。
5. **工业量产**：扩建分相柱、提高线性并行，并用统计界面或限时任务验证连续运行，而不是再次收取一套证明物品。

任务说明要明确区分“前置能力”和“每批消耗”：反应堆、量子网桥、大型离心机等是需要建成并持续发挥作用的基础设施；奇点、熔融相和工艺流体才进入每批配方。这样玩家能理解此前数章科技内容为何存在，也不会误以为终点只是把旧机器拆下来合成新核心。

## 五、光辉石与暗影钢分流

异彩化合物形成后，沿 Create 原有主题向光辉石和暗影钢分流。两种材料承担不同功能，避免都退化为“更高级的合金”。

### 5.1 光辉石：显现与输出

光辉石通过让异彩化合物吸收光源或进入信标光柱形成，主题是“将可能性显现并稳定为光”。它负责显现、观测、输出、加速和稳定，不负责凭空复制资源。

Vintage Improvements 已提供光辉石杆、线、弹簧和板，可作为统一加工件。

| 部件 | 主要材料方向 | 用途 |
|---|---|---|
| 光谱透镜 | 光辉石板/线、高阶光学晶体、Northstar 高级电路 | 轨道遥测、卫星扫描、隐藏航点发现和高级激光加工 |
| 显化线圈 | 光辉石线/弹簧、充能晶体和高级电路 | 提高 AE2 输出、装配矩阵速度与高吞吐接口能力 |
| 光辉能源核心 | 显化线圈、高阶电容和持续充能产物 | 稳定、缓存和分配已有能源，不创造无条件能源 |
| 光辉机壳 | 光辉石与基础机壳 | 搭建显化室、光学设备和高阶精密机器 |

代表机器“显化室”可以制作上述部件，并承担扫描、网络状态显化、食品恒温、保鲜和品质识别；它只能识别和维持品质，不能直接制造品质。

可优先接入 ExtendedAE Plus 的装配矩阵上传核心、超级速度核心和能源存储核心。

### 5.2 暗影钢：隐藏与吸收

暗影钢通过让异彩化合物坠入世界底部以下的虚空区域形成，主题是“将可能性压入不可见空间”。它负责隐藏、吸收、压缩、隔离和湮灭，不负责凭空生产资源。

Vintage Improvements 已提供暗影钢杆、线、弹簧和板，可作为统一加工件。

| 部件 | 主要材料方向 | 用途 |
|---|---|---|
| 湮灭奇点 | 奇点簇、暗影钢板、虚空钢和空间组件 | 暗影机器、空间压缩与光暗共同制品核心 |
| 暗影存储核心 | 暗影钢加工件、空间存储组件和高级处理器 | 高类型容量、现场缓存与特殊状态隔离 |
| 熵汇 | 暗影线圈、湮灭奇点和过滤组件 | 按规则销毁产线溢出，可低效率回收但不得形成正收益闭环 |
| 相位仓 | 暗影机壳、暗影存储核心和多类型接口 | 暂存大型机器输入、危险流体、特殊 NBT 与未完成加工状态 |

暗影路线不只提供更大的 ME 磁盘：ME 磁盘负责长期网络存储，相位仓负责机器现场与异常状态缓冲，熵汇负责可控的溢出治理。

可优先接入 ExtendedAE Plus 的湮灭奇点、存储核心和空间核心。

### 5.3 光暗共同制品：相位与现实重构

光辉石负责显现和送出，暗影钢负责隐藏和收入。只有同时消耗两者，才进入相位传输、双向接口和现实重构层级。

| 制品 | 作用 |
|---|---|
| 相位稳定核心 | 由光谱透镜、湮灭奇点、光辉能源核心、暗影存储核心和量子缠绕态奇点组成，作为光暗共同设备的基础部件 |
| 相位物流端口 | 成对绑定，在明确吞吐、能源、区块加载和星图解锁限制下传输物品、流体或 FE |
| 双向现实接口 | 根据过滤器、红石或网络状态切换输入/输出，用于动态结构、装配矩阵和大型多方块机器 |
| 超级装配矩阵核心 | 上传与速度偏光辉，样板与存储偏暗影，合成核心同时消耗两者 |
| 星间物流中继 | 安装在卫星或空间站，为已探索星球间的相位物流提供中继 |

第一批实现控制在八件内容：

| 分支 | 第一批内容 |
|---|---|
| 光辉石 | 光谱透镜、显化线圈、超级装配矩阵速度核心 |
| 暗影钢 | 湮灭奇点、暗影存储核心、熵汇 |
| 光暗共同 | 相位稳定核心、相位物流端口 |

双向现实接口、完整超级装配矩阵、星间物流中继和食物侧悖论容器放在后续阶段。

## 六、创造级奖励的关系

创造级物品是光暗路线更远期的完成奖励，不是异彩材料链的直接目标。它们只压缩玩家已经解决的系统，不能用于跳过尚未完成的星球、Boss、料理收集或任务章节。

| 档位 | 定位 | 示例 |
|---|---|---|
| 准创造设备 | 能力强，但仍受 FE、应力、吞吐、范围或中继限制 | 相位物流端口、光辉能源核心、相位仓 |
| 专用创造设备 | 只替代一个已经解决的系统，可考虑允许生存重复制作 | ME 创造能源元件、创造马达、创造烈焰蛋糕 |
| 万能创造物品 | 可复制任意资源或绕过多条进度，只作为全包完成奖励或保持不可合成 | 创造板条箱、创造流体储罐、通用创造发电机 |

若多个专用创造配方需要统一结构，可以使用“创造胚胎”或“现实种子”：由相位稳定核心、光辉石、暗影钢和对应系统的终结证明组成，再由各系统追加专属证明。

创造级奖励遵守以下规则：

- 专用创造设备可以重复制作，但开放时间取决于该系统是否已经失去继续建设的价值。
- 创造板条箱和创造流体储罐更适合作为全包完成后的队伍奖励，而不是普通 JEI 配方。
- 万能复制能力必须要求科技、食物、冒险和星系主要内容全部完成，不能只靠异彩材料量产。
- 创造物品不进入订单、生命质、物质聚合和普通回收系统。

## 七、经济与系统边界

### 7.1 悖论资源源

无尽奶酪、油奇点和怪异肉团允许终盘玩家解放基础食品生产，但必须保留以下边界：

- 资源源本体不得被物质聚合、销毁换取奇点或复制自身。
- 资源源本体和专用复制产物不得转化为生命质。
- 资源源不得直接完成高价值订单或无限刷取声望与货币。
- 不输出 Boss 战利品、任务物品、不可再生材料和跳过能源进度的燃料流体。
- 每次提取仍消耗机器时间、转速、应力、容器或其他明确操作成本。
- 基础产物可以进入普通食品配方，使终盘资源自由具有实际价值。

如果基础产物仍能通过现有系统间接兑换高价值资源，应优先在订单、生命质或物质聚合入口排除对应来源，而不是全面禁止其参与普通料理。

### 7.2 魔法与装备候选

- T.O Magic、Iron's Spells、Apotheosis 和 Fallen 只提供横向篇章候选，不成为每批异彩配方的硬材料。
- 百分比伤害、伤害上限绕过、复活、禁止施法/使用物品、地形破坏和大型召唤等敏感能力不作为巡礼必选目标。
- T.O 的 mastery 与护甲进度主要依赖 `inventory_changed`，正式任务需要结合制作、升级或队伍记录，避免借用成品完成。
- Apotheosis `ancient` 装备需要由本包控制投放阶段；Fallen 宝石、符印和词缀负责构筑，不承担新的全局随机投放门槛。

## 八、实现与引导方向

可能需要的实现能力包括：

- KubeJS 注册悖论食品、中间物、短动力合成和相关标签。
- `BlockEvents.rightClicked` 或 CDC 验证冰淇淋色环、彭罗斯阶梯和首次宴席结构。
- FTB Quests 或队伍持久数据记录固定主线锚点、横向篇章与异彩巡礼资格。
- NBT 记录奶酪熟成层数、油奇点模式和封闭料理结果。
- CDC 或可靠的静态配方表达可返还本体的砧板、动力锯和分液池加工。
- 专用标签维护悖论食品、禁止聚合、禁止生命质回收和禁止订单物品。
- 服务端逻辑控制药水效果重构、生态状态和资源源出口。
- 人工维护 T.O mastery、护甲、学派、敏感法术与 Apotheosis/Fallen 投放清单。
- JEI、任务、Ponder 和语言文件明确展示“资格不消耗、食品会消耗、异彩只是中间体”。

首次仪式和后续配方按玩家还是队伍记录，需要结合现有 FTB Quests 队伍进度和服务器游玩方式确定。

## 九、分阶段落地建议

### 第一阶段：冻结路线骨架

- 确认异彩化合物作为共同中间体的目标产量与需求量。
- 确认两条路线产出相同物品，普通下游只要求完成其中一条。
- 冻结七种悖论、固定主线锚点、横向篇章九选四和食品七选三的正式名单。
- 冻结第一批光辉石、暗影钢和光暗共同制品。
- 建立冒险里程碑、悖论食品和敏感能力的人工清单与排除项。

### 第二阶段：轻科技单件原型

- 实现炫彩冰淇淋首次结构与后续自动化配方。
- 实现彭罗斯曲奇效果重构并验证跨模组效果兼容。
- 实现无尽奶酪或油奇点中的一个，验证返还本体与经济排除规则。
- 验证 T.O / Iron's Spells 候选遗迹、mastery、护甲、法术和关键 Boss 记录方式。
- 制作固定主线锚点、横向篇章和队伍资格原型。

### 第三阶段：双路线闭环

- 完成三种不同悖论食品的 ID 校验与消耗逻辑。
- 完成异彩巡礼资格校验和凭证返还逻辑。
- 实现工业异彩分相阵列的控制器、结构、独立流体口、应力口、FE 口与内部阶段状态。
- 接入单批配方、分相柱线性并行、暂停续作与输出堵塞保护，并完成重科技配方平衡。
- 验证异彩化合物向光辉石、暗影钢的现有 Create 转化。
- 接入任务、JEI、Ponder、语言和进度。
- 对比两条路线的建设成本、持续成本和单位产量。

### 第四阶段：光暗下游

- 实现首批八件光辉、暗影与光暗共同制品。
- 确保下游优先消耗光辉石或暗影钢，不绕回异彩化合物。
- 根据实际游玩数据调整资源源、生命质、订单、能源和创造级奖励边界。

## 十、待定问题

### 轻科技资格

- 固定主线锚点是否采用“完成金星主线并取得土卫二航线”。
- 横向篇章是否保持九选四，新增篇章后是否维持接近一半的选择比例。
- 巡礼资格使用实体可返还凭证，还是只使用 FTB Quests 队伍数据。
- 异常生态图鉴五个区域各自使用哪一种不可由生产线伪造的遗物。
- 武器博览与护甲博览的正式白名单及制作记录方式。
- 四系宗师的学派池、代表法术和“成功施放”记录方式。
- 诸神黄昏的 Cataclysm Boss 白名单与击杀瞬间难度校验方式。

### 悖论食品

- 七种悖论是否全部保留，还是由万酿之母、原初高汤等替换其中一项。
- 首次世界结构按玩家还是队伍解锁，结构是否完全消耗。
- 炫彩冰淇淋后续配方是否需要不消耗的母种。
- 怪异肉团输出采用随机、固定轮换还是可配置模式。
- 无尽奶酪和油奇点的实际循环数、表现层数与机器时间。
- 油奇点是否只覆盖食用油，或允许通过额外工艺转化工业油。
- 彭罗斯曲奇的效果排除表与等级、持续时间上限。
- 钻石品质食品是否参与轻科技路线，以及如何防止静态配方伪造品质。

### 重科技与光暗下游

- 分相柱第一版允许的最少与最多段数、单批产量、周期、FE 和应力需求。
- 星际相固定使用钛、固定使用火星钢，还是允许两者以不同成本提供等价配方。
- 压力与真空阶段只用阵列内部专用过程表达，还是要求未来工业压力反应室提供预处理流体。
- 控制器与定谱模块最终消耗哪些标准组件；在标准组件原型冻结前不锁定具体数量。
- 断电、失速、缺液、结构失效和输出堵塞时，阶段进度与已锁定输入如何保存和恢复。
- 裂变反应堆的推荐规模与阵列峰值功率如何匹配，同时继续只校验实际 FE 而不校验反应堆方块。
- 光辉石与暗影钢分别优先服务哪些现有系统。
- 哪些更高阶物品必须同时消耗光辉石和暗影钢。
- 是否保留 Create 原有吸光与坠入虚空转化，或增加更昂贵的自动化配方。
- 吸光转化的光源白名单、批量处理和光源消耗方式。
- 暗影钢虚空转化的安全回收方式，避免成品继续坠落丢失。
- 终盘无限食品的基础产物是否允许进入 AE2 物质聚合器。

# MMT 饰品阶段成长设计

> 上层冒险顺序以 [冒险流程与配方魔改规划](./adventure-progression-overhaul-plan.md) 为准。本文只处理 More Mod Tetra（MMT）模块化饰品的获取、解锁、流派分工和重复制作，不改动独立的 Tetra Insight 项目。

## 实施记录

九张阶段卷轴和主要战斗饰品模块锁已经落地：

- `雷鸣战技卷轴` 锁定暴击戒指、暴击/疾风手镯、戒指/手镯宝石镶嵌和两种战斗手套，共 7 个模块。
- `蜂巢守护卷轴` 锁定抗性手镯、生命/护盾项链和守卫戒指，共 4 个模块。
- `流派徽记卷轴` 锁定战士、游侠、巫师和骑士徽章，共 4 个模块。
- `月相奥术卷轴` 锁定施法时间、冷却、奥术项链、巫师王冠和王冠宝石，共 5 个模块。
- `重装守御卷轴` 锁定护心镜基底、生命核心和尖牙穿甲坠饰，共 4 个模块。
- `磁场精密卷轴` 锁定磁力戒指和弹射物追迹核心，共 2 个模块。
- `远古净化卷轴` 锁定神威十字坠饰，以及纯白容器、剑鞘、箭袋、书袋四套光谱系统的 32 个图纸，共 33 个模块。
- `深渊遗物卷轴` 锁定模块化不死图腾核心与外壳，共 2 个模块。
- `星界统御卷轴` 锁定复仇者徽章与王者之冠，共 2 个模块。
- 九张卷轴分别消耗斯库拉、蜜蜂领域、末影龙/月球、火星、磁场/水星、金星、土卫二和终局的 Boss 战利品、洞穴遗物与魔法材料制作，不使用电路、钢板、氧气罐或 AE2 奇点等科技组件；卷轴通过 `schematics` 提供共享解锁键。
- 九张卷轴配方由 `kubejs/server_scripts/Tetra/mmt_curios_scrolls.js` 统一注册并保留 `createdelight:mmt_curios_scrolls/*` 配方 ID；九种带 NBT 的卷轴同时显式加入 Tetra 创造标签页和 JEI 物品列表。
- 卷轴成本按阶段和解锁规模递增；不消耗蜜蜂精华等永久奖励、完整装备、Boss 召唤物或可孵化的唯一掉落，两侧重复槽只使用可重复获取的材料。
- Black Knight Armor 的六种主题锭和终结龙锭都是悚怖钢二次处理材料，只用于悚怖钢阶段后的远古净化、深渊遗物与星界统御；火星阶段的重装守御改用 IAF 龙骨，不提前套入悚怖钢门槛。
- 63 个图纸覆盖均使用 `tetra:locked` requirement 与 `replace: true`；中英文卷轴名称和锁定提示已经补齐。
- 12 个 MMT 首次转换 replacement 已覆盖：所有必需结构槽都会装入低收益初始模块或默认开放结构模块；手套由普通手套本体与坚硬腕带组成，项链由简单挂坠与基础链条组成，避免空槽导致饰品本体模型消失，同时防止 replacement 绕过卷轴锁直接发放高阶模块。
- 当前启用的饰品图纸已按对应模块 `variants[0].extract` 校正材料影响显示，修复疾风手镯显示幸运、徽章显示暴击、守卫戒指显示错误防御/移速等错位。
- 63 个阶段模块与 12 个低收益初始模块均补充中英文说明，直接写明模块能力、硬度/密度/韧性的实际作用及所需卷轴。
- 图纸审计以 KubeJS module 覆盖优先、MMT JAR 兜底：暴击相关模块统一使用 `attributeslib:crit_chance`/`crit_damage`，尖牙坠饰的固定穿甲统一为 `attributeslib:armor_pierce`；两类属性均有对应 Tetra stat bar/sorter，schematic 与 module 两层说明保持一致。

当前已完成 JSON、锁键对应、两次 `/reload`、卷轴 NBT 读取和九张卷轴中文名验证；真实 Tetra 工作台中的初始模块 replacement 转换、图纸显隐、已制成饰品保持有效、卷轴作用范围和多人共享由人工继续回归。

## 问题与结论

当前 MMT 的主要问题不是单纯“配方便宜”，而是：

- 戒指、手镯、徽章、护符、项链、王冠、手套、护心镜、鞋和不死图腾等基底大多在普通工作台直接制作。
- 玩家开局获得基底后，绝大多数成长只剩替换 Tetra 材料；饰品模块图纸默认全部可见，冒险内容没有解锁新的结构或流派能力。
- 徽章的近战、远程、魔法、全伤害增幅属于独立乘区；手镯、护心镜和项链还提供减伤、穿甲、生命与特殊效果，不能与普通便利饰品按同一阶段投放。
- 当前部分图纸允许木、石、骨、金属和宝石同时作为强饰品材料，低阶段材料也能直接进入高价值模块。

推荐采用“基底早开放、模块靠卷轴推进”的三层门槛：

1. **基础饰品层**：完成 Tetra 基础流程后即可制作大部分普通基底，但默认只能选择弱模块和结构模块。
2. **卷轴解锁层**：Boss、维度、遗迹或任务提供实体卷轴；卷轴通过 `schematics` 解锁一组新的饰品模块。
3. **材料强度上限**：Tetra 材料仍决定数值，但只能在已经解锁的类型和路线内优化。

这样，材料替换仍保留 Tetra 的核心乐趣，但不再承担全部进度。

## 设计原则

### 解锁物与量产物分离

- Boss 首杀、圣所挑战和星球任务给**路线解锁物**，用于永久开放图纸或制作可重复使用的模具。
- 普通结构、洞穴、星球矿物和可自动化材料给**批量生产物**，用于制造更多基底和更换材料。
- 不让每一枚戒指都消耗一次低掉率 Boss 奖杯；Boss 控制“能不能做”，常规冒险与生产控制“能做多少”。
- 每条主路线的第一件关键饰品由任务或首杀奖励保底，避免多人服、低掉率和遗失导致流程卡死。

### 基底开放早于强模块

- 玩家可以较早制作戒指、手镯、徽章等可改造基底，但首次制作时只有空白、便利性或低倍率模块。
- 强独立乘区、追踪、复活、全能属性和高减伤必须由后续卷轴解锁。
- 不用单纯把整个饰品种类推到终局；每个阶段至少获得一张能明显改变工作台模块池的新卷轴。

### 流派横向分工

- 同阶段的饰品应当提供近战、远程、魔法、防御或支援方向的选择，而不是全部叠成通用增伤。
- 徽章用于确定主要战斗流派；戒指和手镯负责微调；项链、护符和护心镜负责生存或环境适应；王冠和不死图腾属于后期核心。
- 同类独立乘区需要总量上限。尤其要检查徽章、Apotheosis 宝石、Fallen 词缀和料理 Buff 的叠乘。

## 卷轴体系

卷轴是本方案的主要进度载体，不再额外新增饰品模具或隐藏阶段 improvement。

MMT 已经使用原生 Tetra 卷轴结构：`tetra:scroll_rolled` 的 `BlockEntityTag.data[].schematics` 可以携带一个或多个图纸解锁键；对应图纸使用 `tetra:locked` requirement 检查该键。现有 `mmt_katana_scroll` 与太刀图纸已经证明这条链路可用。

推荐投放规则：

- 首张阶段卷轴由 Boss 首杀、维度主任务或圣所挑战保底。
- 卷轴是实体知识物品，放置在 Tetra 锻造区附近后为工作台提供图纸；不在每次改装时消耗。
- 遗失后可由已完成任务低成本补领；多人队伍可以共享锻造区的卷轴知识。
- 结构宝箱可以低概率提供同阶段卷轴副本，但不得越过流程阶段投放。
- 单张卷轴应成组开放 3～8 个同主题模块，避免“一模块一卷轴”造成仓库和工作台周边堆满卷轴。
- Tetra 单个卷轴方块可保存的卷轴条目有限，实际布置范围、多个卷轴方块叠加和多人同步必须在游戏内验证。

## 原生锁定实现

强模块图纸覆盖到 `kubejs/data/tetra/schematics/mmt_*/**`，增加：

```json
"requirement": {
  "type": "tetra:locked",
  "key": "createdelight:mmt_curios/magnetic_precision"
}
```

对应卷轴的 NBT 提供相同解锁键：

```json
"schematics": [
  "createdelight:mmt_curios/magnetic_precision"
]
```

也可以让卷轴直接携带多个独立图纸 ID；但按主题使用共享解锁键更便于未来增删模块。所有覆盖现有 MMT 图纸的 JSON 必须保留 `replace: true`，避免 Tetra 的 merging store 将原版无锁 requirement 与新数据合并后继续放行。

图纸锁不会约束 `data/tetra/replacements/*.json` 中预装的模块。Tetra 在解析 replacement 时会直接把声明的 module 写入目标物品，因此任何被卷轴锁定的模块都不能继续作为普通基底的默认预装项；首次转换只能保留默认开放的结构模块，或安装不提供独立乘区、减伤、追踪、神威、复活与状态触发的低收益初始模块。

默认弱模块无需 `tetra:locked` requirement；中后期模块必须有且只有一个清晰的主卷轴入口。卷轴负责“能否看见和安装”，材料负责“安装后有多强”，两者不要合并成一种高价材料。

图纸的 `translation` 只负责把材料三值映射到工作台预览，必须与实际模块 JSON 的 `variants[0].extract.{primary,secondary,tertiary}{Attributes,Effects}` 对齐；不能根据模块中文名猜属性，也不能把 MMT 复合效果机械改写成其他模组的暴击属性。固定材料且无三值成长的图纸可以保留用于展示固定效果的 translation，但说明必须明确其数值不随材料成长。

对照模块时必须先读取 `kubejs/data/tetra/modules/<moduleKey>.json`；只有工作区不存在覆盖时才回退到 MMT JAR。当前可无损归并到 AttributesLib 的饰品效果只有暴击率/暴击伤害与固定护甲穿透：`arrow_damage` 仅覆盖箭和三叉戟，不等价于 MMT 的全部弹射物增幅；近战、魔法、全伤害、减伤、追踪、磁力、神威、图腾和纯白触发继续保留原效果。

## 配方与材料方向

现有冒险规划只列出了戒指、手镯和徽章三个基底，实施时应扩展到全部战斗饰品：

| 基底 | 当前低成本方向 | 推荐生产材料 |
|---|---|---|
| 戒指 | 铁锭 + 紫水晶 | 锻造钢板、Tetra 无瑕紫水晶、精密构件；斯库拉后使用冒险者模具。 |
| 手镯 | 铁锭 + 紫水晶 | 初版用锻造钢/钛板，强版本追加斯库拉材料；不建议基础手镯直接要求月球钛板，否则第一轮构筑过晚。 |
| 徽章 | 铁锭/铁粒/圆石 | 锻造钢、无瑕宝石、Northstar 电路；专精类型由路线调律决定。 |
| 护符 | 皮革 + 纸 + 钻石 | 耐久织物、蜂蜡/蜂蜜材料或环境样本；不同净化能力消耗对应异常来源物。 |
| 项链 | 铁锭 + 金锭 | 金属链、阶段宝石、路线坠饰；强穿甲与神威坠饰需要 Boss/星球调律。 |
| 手套/鞋 | 铁锭 + 皮革 | 耐久织物、锻造件和橡胶/皮革；作为基础探索装备保持可重复生产。 |
| 护心镜 | 铁锭 + 紫水晶 + 金锭 | 火星钢板、生命材料、重型锻造件；土卫二版本加入深渊材料。 |
| 王冠 | 铁锭 + 紫水晶 | 星球金属、专精宝石和 Boss 印记；王者之冠使用星系结晶。 |
| 不死图腾 | 金锭 + 绿宝石 + 下界之星 + 废金属 | 不死图腾、土卫二 Boss 材料、Tetra 锻造外壳；下界之星只能作为辅料，不能单独代表阶段。 |

材料白名单至少应做到：

- 戒指、手镯和徽章主体移除木、石、骨路线，只保留合格金属和宝石。
- 支援护符可以保留织物、皮革和特殊填充物，避免所有饰品都变成金属制品。
- 高阶镶嵌不直接接受任意 `tetra:gem/`；先要求对应调律，再允许阶段内宝石作为数值选择。
- Apotheosis/Fallen 宝石属于后处理或高阶消耗，不替代 MMT 的图纸解锁。

## 任务与战利品投放

每个阶段建议使用同一套四步任务结构：

1. **发现**：抵达维度、找到遗迹或首次遇见 Boss，展示该阶段新增的饰品剪影与用途。
2. **证明**：完成 Boss 首杀、圣所挑战或科研任务，奖励对应阶段卷轴。
3. **制作**：制作第一件该阶段饰品，返还部分批量材料并讲解材料三值。
4. **专精**：在两到三张路线卷轴中先取得一张；其他路线可通过后续探索补齐，不做不可逆职业锁。

结构宝箱只投放以下内容：

- 可补充的批量材料。
- 卷轴抄录材料或同阶段卷轴副本。
- 已解锁阶段内的成品侧升饰品。

不直接在早期结构箱投放终局王冠、复仇者徽章或完整不死图腾，以免绕过任务与图纸。

## 数值边界

- 四个专精徽章的独立伤害增幅应作为主要乘区之一；建议基础值控制在约 3%～5%，高阶总收益不超过约 10%～12%。
- 复仇者徽章的全伤害不应与专精徽章无代价叠加；可设置同组唯一、槽位互斥或明显降低单项收益。
- 饰品减伤需要与护甲、料理、Apotheosis/Fallen 词缀共同设置总上限，建议先以全身 15%～20% 的饰品减伤预算做实战测试。
- `tracking` 同时提供暴击和弹射物追踪，属于水星后的构筑核心，不作为普通宝石镶嵌。
- 不死图腾首先开放“可复活但冷却较长”，终局升级再改善冷却和回复；不要一次性同时给满复活频率与高回复。
- 王者之冠的多属性加成应采用小幅全能值，不替代专精徽章和流派装备。

具体数值在实施前应对 MMT、Apotheosis、Fallen、料理和 Black Knight Armor 做一次全身构筑表，按加法区和独立乘区分别计算。

## 推荐实施顺序

1. 先列出全部饰品图纸，并按“默认弱模块 / 阶段卷轴模块 / 终局模块”完成审阅表。
2. 为强模块图纸增加 `tetra:locked` requirement 和 `replace: true`，确认没有原版无锁图纸漏网。
3. 制作雷鸣战技、蜂巢守护、流派徽记三张第一批卷轴，先验证完整的解锁链路。
4. 收紧戒指、手镯、徽章图纸的材料白名单，解决木石骨制作强饰品的问题。
5. 再制作月球、火星、水星、金星、土卫二和终局卷轴，并接入对应任务与 Boss 保底。
6. 最后调整基底配方：普通基底保持早期可生产，王冠、不死图腾等遗物基底单独加阶段成本。
7. 接入 Apotheosis/Fallen 宝石和高阶词缀，统一检查乘区与减伤上限。

## 验证清单

- 新存档即使能制作普通基底，也只能看到默认弱模块，无法安装主要独立增伤、追踪、复活和王者之冠。
- 完成一个阶段时，玩家明确获得一张新卷轴，放入锻造区后工作台出现对应的新模块组。
- 移除卷轴后，锁定图纸不再可用；已经完成的饰品不应被破坏或失效。
- 未获得对应卷轴时，追踪、复仇者、王者之冠和不死图腾等高阶图纸不可安装。
- 多人队伍可以共享放置在公共锻造区的卷轴，卷轴补领不会只绑定首次拾取者。
- 卷轴同时携带多个图纸时，所有图纸均能正常出现；不同卷轴的解锁键不会串线。
- JEI、Tetra 工作台和 FTB Quests 对下一阶段来源有一致说明。
- 木、石、骨材料不能进入戒指、手镯和徽章的强战斗模块。
- MMT 独立伤害乘区、饰品减伤、暴击与追踪效果和 Apotheosis/Fallen 组合后没有明显越级。
- 数据层修改只位于当前整合包仓库，不修改 `D:\learnmod\TetraInsight`。

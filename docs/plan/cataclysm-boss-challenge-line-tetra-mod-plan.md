# 灾变 Boss 挑战线与 Tetra 改装成长规划

状态：前瞻想法阶段，尚未实现；后续可继续补充细节。相关总流程见 `docs/plan/adventure-progression-overhaul-plan.md`，Tetra 护甲机制见 `docs/dev-knowledge/tetrawear/README.md`，削弱版本改良的既有先例见 `docs/plan/black-knight-armor-integration-plan.md`。

## 核心想法

把各灾变（Cataclysm）Boss 做成一条明确的「挑战线」，并用这条挑战线串联起所有维度旅行。玩家推进的动力来自「变强」：每击败一个 Boss，就能用其掉落合成对应的 Tetra 改装材料，把这些材料改装到武器或盔甲上获得新的战斗能力，再用变强后的装备去挑战下一个 Boss / 下一个维度。

一句话循环：

```text
维度探索 → 挑战灾变 Boss → 掉落核心材料 → 合成 Tetra 改装材料
    → 武器/盔甲改装获得新能力（削弱版 Boss 技 / 特殊抗性 / Buff）
    → 变强 → 解锁并前往下一维度、挑战下一个 Boss
```

## 叙事框架：远古灾变异常点

已定方向：不给各灾变 Boss 编造彼此因果（他们之间没有必然联系），而是采用薄考古框架——

- 各维度的灾变 Boss 统一设定为「远古灾变异常点」：独立的远古灾害/封印节点，沉睡在各世界深处。
- 串起挑战线的是玩家的远征本身：跟随着 Tetra 遗迹与「Those Who Came Before」的考古线索，一颗星一颗星地发现并讨伐这些异常点，形如怪物猎人式图鉴讨伐，而非幕后阴谋叙事。
- Tetra 遗迹按「先民边陲哨站 / 末地文明故都」两段式布局，考古远征线的终点与文明真相在末地；详见 `docs/plan/tetra-civilization-ruins-layout-plan.md`。故事底稿见 `docs/plan/expedition-narrative-storyline.md`。
- 可选留白：终章可再引入一条淡暗线（如异彩 / T.O / 虚空的共鸣），但框架主体仍是考古远征，不把暗线写进日常任务文本。

### 阶段定位

- **Tetra 遗迹探索之后**才开启灾变挑战线；Tetra 遗迹之前属于早期生存与锻造入门，只安排简单的原版 Boss（如女巫、守卫者、凋灵等原版/轻量目标）作为战斗教学和小门槛。
- Tetra 遗迹是进入「远古灾变」认知的分界：完成遗迹探索、具备基础锻造能力后，任务线才引出第一处灾变异常点（斯库拉 / 主世界）。
- 与 `adventure-progression-overhaul-plan.md` 的阶段表对齐时，「主世界基础」内部再细分：Tetra 遗迹 + 原版 Boss 为前段，斯库拉等灾变 Boss 为遗迹后段。

### 解锁方式：召唤媒介，不用挑战凭证

- 不采用抽象的「挑战凭证」硬锁（偏打卡、不符合本包「世界内门槛」风格）。
- 每个异常点对应召唤媒介 / 仪式节点：在该维度深处的异常点现场，用本地材料 + 远征进度证明（星图科研、锤级、前序首杀记录等）激活或合成召唤物，既是解锁钥匙也是战斗准备的一部分。
- **Boss 召唤物可以用 Tetra 遗迹翻出来的物品制作**：遗迹出土物（考古收获、残片、遗物类材料）是召唤配方的核心输入，把「探索遗迹 → 拼出召唤物 → 讨伐异常点」接成同一条考古远征链，也解释了为什么挑战线要在 Tetra 遗迹之后开启。
- 进度条件表达的是「远征到了这里」，而不是「上一个 Boss 与这一个有剧情关系」。

## 设计要点

### 1. 挑战线串联维度旅行

- 每个主要维度（或星球）对应一个灾变 Boss，Boss 是该阶段的战斗门槛和「毕业证明」。
- 挑战线顺序与 `adventure-progression-overhaul-plan.md` 的阶段流程一致：主世界基础（斯库拉）→ 末地支线 → 月球（先驱者）→ 火星（下界合金巨兽）→ 水星（炎魔）→ 金星（远古遗魂）→ 土卫二（咒翼灵骸 / 利维坦）→ 星系终局（末影守卫）。
- 维度旅行不只是「去过」，而是「打过该维度 Boss 并拿到改装材料」才算完成该阶段的战斗成长节点。
- 任务书可按挑战线组织：每个 Boss 一个挑战节点，展示前置装备建议、召唤/触发方式、掉落改装材料和改装后的效果预览。

### 2. Boss 掉落 → Tetra 改装材料

每个 Boss 的核心掉落（如 `cataclysm:essence_of_the_storm`、`cataclysm:void_core`、`cataclysm:monstrous_horn` 等）用于合成「对应主题的 Tetra 改装材料」，而不是只作为配方门槛消耗品。

- 改装材料是合成产物，不是 Boss 直接掉落的成品；配方消耗 Boss 战利品 + 对应阶段的加工材料（星球矿物、锻造钢、Tetra 无瑕宝石等），与现有阶段材料原则一致。
- 同一 Boss 的材料可细分出武器向、盔甲向两条合成分支（也可再留第三条饰品/工具向，后续再定）。
- Boss 战利品仍可重复获取（重复召唤/重复挑战），改装材料不做成一次性唯一物，避免玩家在「永久能力」和「装备改装」之间做无关取舍（参见 `docs/lessons-learned.md` 中 MMT 阶段卷轴的教训）。

### 3. 武器改装：削弱版 Boss 攻击

- 武器上的改装提供「削弱版本」或「类似 Boss」的攻击效果：例如雷暴落雷、虚空冲击、火焰吐息、深渊水流、诅咒脉冲等，主题与对应 Boss 一致。
- 单个改装效果定位为削弱版（参考黑骑士护甲 Tetra 改良的 25%～40% 削减幅度），完整强度仍属于 Boss 本身，避免玩家直接复制 Boss 全部能力。
- 效果实现优先走 Tetra improvement / schematic 体系（参考 MMT 权能铭刻、黑骑士削弱改良），而不是材料根级直接堆属性；材料只承载一级身份和少量基础属性。
- 可考虑多档：低档为触发式小技能，高档需要多部位/多槽位组合或更高完整度投入。

### 4. 盔甲改装：特殊免疫或主题 Buff

- 盔甲上的改装围绕「防护」和「应对环境」：对某类特殊效果免疫或高抗性（如高温、辐射、冰寒、诅咒、缺氧、虚空减益等），或提供主题 Buff（雷系移速、火系抗性光环、深渊水下呼吸等）。
- 与维度环境威胁挂钩：进入下一维度前，上一阶段 Boss 的盔甲改装正好帮助应对新环境，形成「打 Boss → 获得抗性 → 适应下一维度」的推进感。
- 护甲效果汇总走 Tetrawear 的 `EffectData` / `TetraUtil.getArmorEffectLevel` 路径（见 `docs/dev-knowledge/tetrawear/README.md`），不要复活 Geo 上下文模拟；Cursium / Ignitium 等历史护甲专属效果若要回归，应以 Tetrawear 原生能力或明确的 improvement 方式重做。
- 免疫类效果要设上限或代价（完整度、能量、槽位占用），避免「叠满即完全免疫」的旧问题（参考终结龙套龙息减伤教训）。

### 5. 成长驱动：以变强吸引玩家推进

- 挑战线的主要奖励是「能力」而非纯数值堆叠：玩家能明显感觉到打过某个 Boss 后，自己多了一种攻击手段或一种环境适应能力。
- 改装能力对下一阶段 Boss/维度有实用价值（输出手段克制、环境抗性、机动或续航），让「为变强而打 Boss」形成正反馈。
- 可选：改装材料同时服务现有泰坦卷轴、核心、镶嵌门槛，避免两条线材料完全割裂；但挑战线奖励的主体仍是改装能力本身。

### 6. 食物线奖励改装（局外成长接口）

已定方向：部分 Tetra 改装能力放进**食物订单线的高等级凭证委托奖励**（供货委托/高声望订单的主题回礼、稀有奖励池），作为局外成长的一部分——不推冒险也能在食物经济里攒出横向趣味改装。

- **定位分工**：挑战线发纵向战斗改装（Boss 主题技、环境免疫）；食物线发横向生存/趣味改装（饱食、续航、资源转换）。超模件（如纯白容器这类持续给 Buff 的饰品）只出现在高声望 + 高成本奖励池，属于毕业级 QoL，不进主线战力门槛，避免「刷订单跳过冒险」。
- **主题方向（食物相关改装）**：
  - 纯白容器类超模饰品：持续 Buff 载体，作为食物线顶级奖励。
  - 伤害优先消耗饱食度（饱食度当缓冲资源）。
  - 背包内食物转化属性：按持有食物种类/数量增加攻击或生命（脆骨症式共鸣）。
- **候选改装（待定稿）**：
  1. **宴血回环**（盔甲）：击杀回复少量饱食度与生命；击杀精英/Boss 额外获得短时「餍足」（攻击吸血），把讨伐节奏接进食物线。
  2. **镬气**（武器）：攻击积层「镬气」，满层重击释放近距热浪 AOE（火伤 + 轻击退，对冰寒/水生目标加成），层随时间衰减。
- 实现载体：Tetra improvement / schematic 与 Tetrawear 效果汇总路径同第 3、4 节；奖励投放走订单主题回礼/供货委托奖励池（见 `docs/order-system-design.md`），配方或兑换挂在高声望委托侧。
- 与食物订单线定位（局外成长、目录首见解锁）对齐，见 `docs/plan/line-integration-and-finale-plan.md`。

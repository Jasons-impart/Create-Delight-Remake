# 玩家独立世界等级与晋阶试炼设计

## 文档状态

本文记录 CDR 对类似 Apotheosis 1.21 World Tiers 的玩家独立世界等级设计。当前处于前瞻规划阶段，尚未代表已实现行为；实际任务 ID、Boss 判定和界面形式需要在实施前对照实时任务树与模组数据确认。

相关规划：

- `docs/plan/adventure-progression-overhaul-plan.md`：冒险、星球和 Boss 阶段总表。
- `docs/plan/apotheosis-fallen-gems-affixes-integration-plan.md`：Apotheosis、Fallen Gems & Affixes 与难度品质轴的接入边界。

## 设计目标

- 世界等级保持玩家之间相互独立，不设置全服共享的强制等级。
- 玩家只能选择已经永久解锁的等级，不能通过任意加减数值提前进入下一等级。
- 解锁新等级需要完成明确的流程里程碑和晋阶试炼，而不是单纯刷取难度点数。
- 玩家解锁后可以主动切回较低等级，用于建设、探索、带新人或降低战斗压力。
- 保留现有难度数值，让喜欢战斗的玩家获得更高压力和更快刷取效率，同时保证不喜欢高强度战斗的玩家也能完成主线并取得完整构筑。
- 世界等级负责内容阶段与奖励范围；难度数值负责同一阶段内的战斗强度、精英概率和额外收益，两者不能互相替代。
- 晋阶条件优先采用 Boss、星球、洞穴、遗物等冒险证明，并提供多选路线，避免强制收集所有支线内容。

## 核心体验原则

本系统的初衷是让喜欢战斗和不喜欢高强度战斗的玩家都能游玩同一套整合包内容，并避免后期难度被装备、词缀和多个强化模组叠加到无法承受。

因此：

- 世界等级表示“玩家已经推进到什么内容阶段”，不是强制难度档。
- 难度数值表示“玩家希望当前战斗有多大压力”，允许上下调整并保留死亡惩罚等现有机制。
- 世界等级晋阶不得要求最低难度数值；玩家可以在较低难度下完成同一 Boss 和主线。
- 低难度不能封锁主线材料、Boss 首杀物、核心图纸、宝石种类或完整流派。
- 高难度主要提高精英怪概率、额外掉落、经验、重复刷取效率和可选挑战奖励。
- 高难度专属奖励只能是非必需的荣誉、外观、刷取加速或可替代侧向奖励，不能成为唯一毕业入口。

## 与现有难度系统的区别

现有 Improved Mobs 难度值属于玩家可增减的连续数值，并被任务奖励、死亡惩罚和玩家选择影响。该数值明确保留，继续承担玩家自主战斗强度轴，但不能作为世界等级解锁的唯一依据。

完整系统由四个独立状态组成：

| 状态 | 含义 | 变化规则 |
|---|---|---|
| `unlockedTier` | 玩家永久解锁的最高世界等级 | 只能通过晋阶条件提升，不因死亡或切换等级下降 |
| `activeTier` | 当前实际生效的世界等级 | 玩家可在 `0..unlockedTier` 内选择 |
| `tierProofs` | 已完成的晋阶证明 | 记录 Boss、星球、洞穴、遗物和终局挑战，防止重复结算 |
| `difficultyValue` | 现有玩家难度数值 | 允许任务增减、死亡惩罚和玩家自主调整，只影响战斗强度与额外收益 |

现有 `rank_*`、`unrank_*` 和死亡惩罚继续改变 `difficultyValue`。它们不能直接提升 `unlockedTier`，也不能代替晋阶里程碑与冒险证明。

两条轴的职责固定为：

| 轴 | 决定内容 | 不决定内容 |
|---|---|---|
| 世界等级 | 可出现的内容种类、星球主题奖励、Apotheosis 品质上限、宝石池、精英/Boss 候选、晋阶条件 | 玩家必须承受的最终血攻倍率、是否有资格完成主线 |
| 难度数值 | 怪物血攻倍率、装备概率、精英概率、额外掉落、经验和重复刷取效率 | 主线解锁、Boss 必掉物、完整构筑、世界等级上限 |

## 核心晋阶规则

解锁下一世界等级时同时检查：

1. 玩家正在使用自己当前已解锁的最高世界等级。
2. 玩家已完成该阶段的必要流程里程碑。
3. 玩家从对应冒险证明池中完成规定数量的不同证明。
4. 同一个证明不能跨多个阶段重复充数，除非阶段表明确允许。
5. 解锁永久保留；玩家之后切回低等级不会撤销已解锁内容。
6. 不检查最低 `difficultyValue`；低难度玩家与高难度玩家使用相同的晋阶资格。

例如：玩家已经解锁“危机四伏”，必须启用“危机四伏”完成火星或水星阶段的晋阶试炼，才能解锁“险象环生”。切换到“风平浪静”击杀对应 Boss 不计入晋阶证明。

## 第一版晋阶条件

| 晋阶 | 必要流程里程碑 | 冒险证明要求 | 主要解锁定位 |
|---|---|---|---|
| 风平浪静 → 暗流涌动 | 击败末影龙 | 无；末影龙首杀作为进阶世界等级系统的开启点 | common/uncommon Apotheosis 内容、基础精英怪与进阶掉落 |
| 暗流涌动 → 危机四伏 | 登陆月球 | 在先驱者、月球大型遗迹、月背异常区中完成任意一项 | rare 品质、月球/虚空/机械主题奖励 |
| 危机四伏 → 险象环生 | 完成火星或水星科研 | 在登陆火星、下界合金巨兽、登陆水星、炎魔、磁场洞穴遗物中完成任意两项 | epic 品质、中期精英怪和星球地牢收益 |
| 险象环生 → 生灵涂炭 | 登陆金星 | 在远古遗魂、辐射洞穴、原始洞穴、指定高阶遗物中完成任意两项 | mythic 入门、金星与远古主题内容 |
| 生灵涂炭 → 末日降临 | 登陆土卫二 | 在咒翼灵骸、利维坦、渊海深窟、深渊遗物中完成任意两项 | mythic 稳定产出、后期精英与深渊内容 |
| 末日降临 → 诸神黄昏 | 完成星系终局主线 | 在末影守卫、利维坦、十二泰坦卷轴、终局遗迹、最高阶神化试炼中完成任意三项 | ancient/Fabled 候选内容与终局高风险奖励 |

表中的“完成洞穴”不能只按进入群系判定。正式实现时应绑定结构任务、关键遗物、Boss 或一次性探索记录，避免玩家短暂进入群系就获得完整晋阶证明。

## 世界等级效果边界

### 应由当前世界等级控制

- 玩家附近可以出现的怪物类型、特殊能力池和阶段事件。
- 普通精英、Apothic Invader 类首领和 Fallen 通用首领是否进入候选池。
- Apotheosis 词缀装备与宝石的品质上限、种类和主题池。
- 宝石种类、最高品质、纯度范围和阶段晶洞奖励。
- 当前阶段允许出现的额外掉落、地牢奖励和 Gateways 挑战规模。
- 高世界等级开放的新奖励种类和侧向构筑内容。

### 应由难度数值控制

- 已经由当前世界等级允许生成的怪物，其生命、攻击、装备强度和部分 AI 强化概率。
- 已进入候选池的精英怪、Invader 和通用首领的实际生成概率。
- 当前世界等级品质上限以内，各品质的抽取权重。
- 普通额外掉落、经验、材料数量和重复刷取效率。
- 可选高难挑战的附加奖励，但不改变主线首杀保底。

### 不应由当前世界等级单独决定

- 主线星球、Boss 和维度是否已经解锁；这些仍由流程阶段控制。
- Boss 首杀必需的关键推进物；必须保留任务、结构或首杀保底来源。
- Tetra 材料、模块和卷轴的流程分类；世界等级只控制品质和风险收益，不能绕过阶段图纸。
- 已经生成并保存到世界中的旧怪物；切换等级不追溯重算，避免属性重复叠加。
- 玩家是否有资格完成晋阶；晋阶不设置最低难度值。

有效内容、品质和收益遵循三步判定：

```text
内容与品质上限 = 流程阶段允许范围 ∩ 当前世界等级允许范围
品质抽取权重 = 内容与品质上限内按难度数值调整
额外数量与效率 = 基础保底 + 难度数值奖励
```

即使难度值最低，已经解锁的世界等级仍应提供非零概率或稳定加工路线取得该阶段的全部必要品质；提高难度只让战斗掉落更快、更丰富，而不是把低难度玩家挡在构筑之外。

## 多人环境规则

- 怪物生成时读取最近一名有效玩家的 `activeTier`，并把生成等级永久写入怪物数据。
- 击杀奖励使用“怪物生成等级”和“击杀者当前等级”中的较低值，避免高等级玩家生成怪物后由低等级玩家取得越级奖励。
- Boss 晋阶证明只授予满足当前最高等级要求且实际参与战斗的玩家；正式实现需要定义伤害、仇恨、距离或任务参与条件。
- 队伍可以共享主线任务进度，但 `unlockedTier`、`activeTier` 和个人晋阶证明仍按玩家保存。

## 等级切换限制

为避免在战斗和开箱前即时切换等级套利，第一版至少采用以下限制：

- 不能在 Boss 战、受伤后的短暂战斗状态或敌对怪物近距离锁定时切换。
- 切换后存在短冷却；冷却时长在实装测试后确定。
- 已生成怪物、已生成战利品容器和已经开始的 Gateway 不随切换变化。
- 晋阶试炼开始后锁定本次试炼使用的世界等级，直到完成、失败或离开挑战区域。

## 界面信息

玩家界面至少同时显示：

```text
当前世界等级：危机四伏
已解锁上限：险象环生
下一等级：生灵涂炭
晋阶证明：1 / 2
当前难度值：186
```

第一版可以使用 FTB Quests 世界等级页面提供条件说明、证明进度和等级选择；正式版本再考虑由 CDC 提供独立选择界面、网络同步和服务端权威校验。

## 实施方向

### 第一阶段：任务与数据原型

- 审计 `Difficulty_System.snbt` 中现有 `rank_*`、`unrank_*`、死亡惩罚和重复奖励，保留其难度数值用途。
- 使用玩家持久数据保存 `unlockedTier`、`activeTier` 和 `tierProofs`。
- 通过 FTB Quests 自定义奖励或 KubeJS 事件记录必要里程碑和证明。
- 复用现有难度 HUD，同时显示世界等级、解锁上限、晋阶证明和难度数值。

### 第二阶段：难度与奖励接入

- 保留 Improved Mobs 玩家难度能力作为 `difficultyValue`，世界等级另行保存，避免两个概念共用同一个数值字段。
- 先按 `activeTier` 决定内容池，再按 `difficultyValue` 调整怪物属性、生成概率和额外收益。
- 迁移 `kubejs/server_scripts/Improved Mobs/loot.js` 与 `loot_data.js` 的档位判定。
- 按世界等级控制 Apotheosis/Fallen 候选内容与品质上限，按难度数值控制上限内的权重和额外收益。
- 为怪物记录生成世界等级，完成多人奖励下限校验。

### 第三阶段：CDC 正式系统

- 使用 CDC 玩家能力替代脚本持久数据，并实现服务端权威校验和网络同步。
- 提供正式世界等级选择界面、晋阶条件详情、切换冷却和战斗锁定。
- 为 Apotheosis 7.4.8、Improved Mobs、Champions、Gateways 和 Fallen Gems & Affixes 提供受控兼容层。

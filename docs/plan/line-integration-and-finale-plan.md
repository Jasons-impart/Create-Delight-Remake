# 食物线 / 魔法线结合与终章主线规划

状态：前瞻想法阶段，问题意识大于方案；后续可按问题拆分子规划。相关总流程见 `docs/plan/adventure-progression-overhaul-plan.md`，终局与料理复产见 `docs/plan/chromatic-compound-endgame-plan.md`，铁魔法平衡见 `docs/plan/irons-spellbooks-player-enhancement-balance-plan.md`，品质与生命质见 `docs/plan/quality-harvest-life-matter-plan.md`。

## 核心问题

食物线、冒险线、科技线、魔法线目前各自都有内容，但它们怎么改、怎么互相咬合、最终怎么汇入终章主线，仍是很大的未决问题。需要记录问题本身，避免后续只在单条线里打转。

1. **食物线怎么更改**：现有 Mouse_Chef、Feast_Afoot、Ingredient_Escape 等章节和料理内容的定位、节奏与产量是否还成立。
2. **食物线怎么跟冒险线、科技线结合**：食材来源、料理消耗、品质/生命质、与 Create 加工和冒险战利品的关系。
3. **魔法线怎么结合**：铁魔法（Iron's Spellbooks）与神话（Apotheosis 神化词缀/宝石等神话向成长）如何共存、如何接入流程门槛。
4. **怎么进入最终章节的主线**：各条线的终点如何汇入终章，而不是四条互不相关的支线。

## 线条定位（已定）

| 线 | 定位 |
|---|---|
| **科技线** | **前期发展主轴，也是所有其余线的基础**：深度耦合在冒险线里（加工、量产、召唤物/改装材料制作、Northstar 远征设备都长在科技上），是发展的地基。 |
| **冒险挑战线** | 战斗与远征主轴：Tetra 哨站 → 灾变异常点 → 故都 → 星系终局；整条线建在科技线的加工与远征能力之上。 |
| **食物订单线** | 独立于冒险线的局外成长（经济/声望/财富），但**部分跟随冒险**：目录物品首见解锁对应供货委托，远征越远订单池越宽；科技自动化放大其量产与履约。 |
| **魔法线** | 流派打法层：铁魔法法术 + 神化词缀宝石，服务「怎么打」；生命质（品质食物精华）作为跨线耦合材料进入墨水/施法耗材与宝石修复强化，高阶门槛仍靠 Boss/维度材料。 |

关系一句话：科技是地基与前期主轴，冒险挑战是压在上面的战斗远征主线，食物订单与魔法是并行成长层，终局再硬汇合。

## 问题拆解

### 1. 食物线怎么更改

- 章节覆盖：Mouse_Chef（鼠鼠大厨）、Feast_Afoot、Ingredient_Essence、Youkais_Homecoming 等承担烹饪、食材、异界风味；需要统一「食物线」的范围边界。
- 需要回答：食物线是纯休闲支线，还是承载 Buff、品质经济、异彩化合物复产等硬功能的主线支柱？（终局规划里料理已是异彩复产的消耗侧，见 `chromatic-compound-endgame-plan.md`。）
- 需要回答：改动是重写任务线、调整配方与产量，还是新增机制（如更清晰的食材获取 → 加工 → 料理 → Buff 链条）？
- 与 `docs/plan/quality-harvest-life-matter-plan.md` 的品质收割/生命质自动化衔接，避免食物线与品质系统两张皮。

### 2. 食物线 × 冒险线 × 科技线

已定方向：食物线**不作为冒险挑战线的战斗后勤硬绑定**，而是通过订单系统作为**独立于冒险线的局外成长系统**——经济、声望、供货目录、财富积累自成一条并行进度（见 `docs/order-system-design.md`、`docs/plan/order-*.md`）。

- 局外成长：订单按 I-VI 级承接，声望解锁公告板/委托台/请求器/提交口，按蛋糕、曲奇、茶等小类定向供货；玩家即使不推灾变挑战线，也能在食物经济里持续成长。
- **部分跟随冒险**：供货委托按「目录物品首次进入玩家物品栏后永久解锁」开放——维度食材、异界风味、Boss/遗迹相关食物会随远征进度进入菜单和订单池，冒险推得越远，订单线的内容面越宽。食物线因此是「跑在冒险外侧、但被冒险不断开图」的局外成长。
- 与冒险线的软咬合（可选收益，不设硬门槛）：稀有食材可来自维度与 Boss 掉落，丰富菜单与订单价值；高品质料理提供战前 Buff，帮玩家打赢越级挑战，但「没吃这道菜不能开怪」不成立。高等级凭证委托奖励可开出横向 Tetra 改装件与超模饰品（饱食度缓冲、食物共鸣属性、纯白容器类持续 Buff 等），详见 `docs/plan/cataclysm-boss-challenge-line-tetra-mod-plan.md` 第 6 节。
- 与科技线：科技是食物经济的基础与放大器——Create 加工、自动化、品质/生命质收割（见 `quality-harvest-life-matter-plan.md`）支撑厨房量产和订单履约；同时科技线本身就是前期发展主轴，食物订单是长在这个地基上的局外成长层。
- 终局汇合：异彩化合物复产按 `chromatic-compound-endgame-plan.md` 消耗料理，作为食物线对终章的贡献点；毕业级能力仍要求多线完成。

### 3. 魔法线（铁魔法 + 神话）怎么结合

- 铁魔法作为流派化魔法成长线：究极魔法、强法杖卷轴绑定 Boss/星球材料（见 `adventure-progression-overhaul-plan.md`），增强/保命法术已有平衡约束（见 `irons-spellbooks-player-enhancement-balance-plan.md`）。
- 神话（Apotheosis 神化词缀、宝石、书架调谐等）提供装备侧成长：词缀、宝石镶嵌、掉落品质与难度双轴。
- 需要回答：两者是并行流派（法术流 vs 装备流），还是互相供能（法强吃宝石/词缀、宝石吃魔法材料）？与 T.O Magic、Fallen Gems、MMT 泰坦权能的边界在哪里？
- 需要回答：魔法线如何进入冒险门槛（法术解锁绑定维度/Boss）和食物/科技门槛（附魔台、书架、油与能量），避免魔法成为可以单通的孤立线。
- 与 Tetra 改装成长（`docs/plan/cataclysm-boss-challenge-line-tetra-mod-plan.md`）的关系：Boss 改装材料是否服务魔法构筑（法杖模块、法强、冷却）。

**已定方向：生命质进入魔法与神话线。** 品质食物提取的生命质（`createdelight:life_matter`，见 `docs/plan/quality-harvest-life-matter-plan.md`）作为食物线的「精华产物」，耦合进魔法与神话的配方与强化，不必局限于铁魔法与 Apotheosis 的原有设计：

- 铁魔法：生命质可进入墨水/卷轴材料等施法耗材配方（如高阶墨水、流派专属书写材料），把「吃什么」接到「能施什么法」。
- 神话：生命质可用于宝石修复、升阶或词缀重铸类加工（在 Apotheosis 现有切割/升级体系外扩展），作为宝石侧的再生资源。
- 边界：生命质是**跨线耦合材料**而非万能钥匙——魔法/神话的高阶内容仍以 Boss/维度材料为主门槛，生命质承担「食物线供养魔法神话」的润滑与再生层；具体配方与力度后续逐条定。

### 4. 汇入最终章节主线

- 终章主线需要一个「各条线汇聚」的结构：冒险拿到资格与主题材料，科技提供复产与高能加工，魔法提供法术/神话装备保障，食物提供料理消耗与维持型收益（方向参考 `chromatic-compound-endgame-plan.md` 的「先取得资格，再选择料理成本」）。
- 需要回答：终章主线的触发与里程碑（任务总线、终局任务章节）如何引用各线完成度，而不是简单堆材料。
- 需要回答：四条线是否允许偏科进入终章，还是终章本身要求多线交汇；万能复制、星间物流等终局能力与四条线的完成度如何挂钩（终局规划已要求万能复制必须科技、食物、冒险、星系全完成）。
- 与灾变 Boss 挑战线的终点（末影守卫、星系终局）对齐，形成「挑战线打底 → 各线成长 → 终章汇合」的叙事。

# 野外探索体验与仿造玩家遗迹计划

本文记录提升野外探索性价比、增加仿造玩家遗迹的前瞻设计想法。目标是让星球与异界环境中的探索更有叙事感和拾取价值，而不是把结构随机扔进主世界。

本文仅记录前瞻设计。遗迹主题清单、战利品数值、生成密度和放置维度仍可调整，不代表相关内容已经实现。

## 设计目标

- 提升野外探索的性价比：探索途中能稳定捡到有用物资，而不是只走图看风景。
- 增加「仿造玩家遗迹」：看起来像以前的玩家建过、废弃或炸毁的设施，自带叙事感和梗。
- 遗迹放到对应的星球和环境中，不直接堆进主世界地表。
- 战利品与阶段主题匹配，能衔接现有科技线、核电内容和冒险进度，但不跳过阶段门槛。

## 非目标

- 不把遗迹做成新的主线资源垄断点：关键材料仍应有常规合成或产线来源。
- 不在主世界大量生成大型废墟，避免与 Tetra 遗迹、灾变结构和出生点体验冲突。
- 不让遗迹战利品直接送出成品多方块控制器或整机，主要给零件、耗材和趣味件。

## 探索物资投放

探索拾取应覆盖几类「这趟值得来」的物资：

| 类型 | 作用 | 示例方向 |
|---|---|---|
| 产线耗材 | 减少回家补货的次数 | 燃料、食品、基础零件、电路耗材 |
| 阶段对应零件 | 补齐当前阶段的昂贵小件 | 核电零件、航天耗材、机器外壳、线圈 |
| 趣味与叙事件 | 支撑梗和世界观 | 告示牌、留言、图纸、半成品、纪念品 |
| 一次性便利 | 提升探索续航 | 氧气/温度补给、医疗、传送锚、照明 |

投放原则：

- 数量和品质与星球阶段挂钩，早期星球给基础补给，中后期星球给对应工业零件。
- 零件类掉落允许降低某条支线的「纯刷」成本，但不应替代整条合成链。
- 同一遗迹内部分层：外圈给普通物资，核心区给主题零件，避免所有价值都堵在最难的点。

## 仿造玩家遗迹

### 概念

遗迹按「以前有人来过」的风格搭建：半完工的机器阵列、被拆走关键件的产线、手写告示牌、简陋睡袋和箱子残骸。玩家看到的第一反应是「这是别的玩家留下的」，而不是原生神殿或模组 Boss 本。

可以统一称为「先行者遗迹」或「玩家遗迹」，避免与 Tetra 遗迹、灾变结构混名。

### 核电站废墟（首个示例）

- 主题：已经炸开的核电站，外壳撕裂、管道外露、部分结构仍在冒烟或发出粒子效果。
- 拾取：核电站相关零件，例如反应堆外壳残片、线圈、控制棒、冷却管件、仪表盘等，可对接现有核电/裂变反应堆合成链的低阶耗材。
- 梗与叙事：入口立一块牌子，写「核电轻而易举」；附近可再放一两块翻倒的告示牌或留言，暗示出事前的盲目乐观。
- 氛围：轻微的战损建筑感，不需要做成跳跳乐或战斗地牢；核心奖励放在建筑内部的补给箱和零件堆。

### 后续候选主题

以下主题可按星球环境逐步扩展，不必一次做全：

| 候选 | 可能环境 | 拾取方向 |
|---|---|---|
| 废弃火箭发射台 | 月球、火星 | 航天耗材、燃料残渣、导航件 |
| 炸毁的化工厂 | 火星、金星、毒化环境 | 管道、泵、密封件、危险品容器 |
| 半完工的多方块地基 | 各工业阶段星球 | 机壳、总线残件、钢构件 |
| 玩家风格避难所 | 各星球地表 | 食品、睡袋、工具、留言 |
| 冷却的钻井营地 | 矿区、小天体 | 钻头、支架、矿物样本 |
| 空置的轨道舱残骸 | 月背、高轨 | 电路、氧气件、宇航服修补件 |

## 放置原则

- 每个遗迹主题绑定具体星球、群系或环境类型，通过世界生成或脚本化站点放置，不使用「全维度通用结构」的粗暴注册。
- 主世界最多保留极少数低价值先行者痕迹（如简陋营地），大型废墟一律放对应星球。
- 与现有内容错位：不占用 Tetra 遗迹生成点，不伪装成灾变 Boss 建筑，不干扰 Northstar 航点、龙穴和磁场洞穴入口。
- 生成密度宁少勿滥；探索性价比靠「遇到就有收获」，不靠满地都是废墟。

## 与现有系统的关系

| 系统 | 关系 |
|---|---|
| `adventure-progression-overhaul-plan.md` | 遗迹物资按星球阶段投放，作为探索收益补充，不改变 Boss 与阶段门槛 |
| 核电站 / 裂变反应堆（`Super_Multiblock` 章节） | 核电零件作为低阶耗材来源，不赠送反应堆控制器 |
| `create-processing-multiblock-plan.md` | 地基残件可与多方块机壳、通用单元的造价思路呼应 |
| `satellite-navigation-system-plan.md` / 月背空间站 | 轨道类残骸可复用空间站叙事，不与已建空间站站点重复 |
| `water-moon-boundary-space-magic-plan.md` | 魔法路线到达的星球同样应有探索遗迹收益，不只服务科技玩家 |

## 待决定事项

- 首批只做核电站废墟一种，还是同时做两三种小营地类遗迹验证生成手感。
- 核电零件的具体物品 ID：新建 `createdelight:*` 残件，还是复用核电/多方块模组的现有中间品。
- 遗迹用数据包结构、KubeJS 脚本站点还是 MBD2 静态建筑生成，以及是否需要防重、防重叠生成。
- 战利品箱的刷新与一次性规则：一次性拾取还是可再生补给。
- 「核电轻而易举」告示牌是固定文案，还是随机抽取一组先行者留言。
- 轻度战损氛围（粒子、烟雾、残骸）的实现成本与客户端性能预算。

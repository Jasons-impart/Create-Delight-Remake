# 铁魔法与 T.O 玩家增强法术平衡规划

本文规划 Iron's Spells 'n Spellbooks（下称“铁魔法”）与 T.O Magic 'n Extras（下称“T.O”）中直接增强玩家、提供保命或强化机动能力的法术。目标不是把增强法术统一削弱，而是保留流派构筑与操作价值，同时阻止常驻输出叠加、连续无敌和多套复活机制绕过整合包战斗进度。

本文是前瞻设计，不表示相关配置、CDC 机制、任务投放或中文资源已经实施。首轮数值用于制作测试版本，正式值以实机回归结果为准。

## 一、审计范围与基线

静态审计基于当前整合包中的以下版本：

- 铁魔法：`irons_spellbooks-1.20.1-3.15.6.jar`
- T.O：`traveloptics-6.3.0-1.20.1.jar`
- CDC：当前 `CDC-mod-src/` 源码，用于确认已存在的伤害兼容修正

铁魔法与 T.O 的法术威力不能只按“基础值 × 法强”估算。首轮核算统一使用：

```text
法术威力 =（基础威力 + 每级威力 ×（等级 - 1））
         × 通用法强 × 学派法强 × 配置倍率
```

因此，持续时间、属性增幅、治疗比例或反伤倍率如果引用法术威力，也会继续受到通用法强和学派法强放大。平衡时应先控制法术自身上限与配置倍率，再评估高法强装备下的最终结果。

已确认的重点基线如下：

| 法术 | 当前静态基线 | 主要风险 |
|---|---|---|
| 超负荷 | 三级约持续 46 秒，冷却 40 秒；攻击约 +30%、移速约 +60%、法强约 +15% | 基础状态已接近常驻，还会同时放大物理与魔法输出 |
| 急迫 | 四级约持续 45 秒，冷却 80 秒；五类能力约 +40% | 单个法术覆盖属性过多，容易成为所有流派的固定前置动作 |
| 深渊庇佑 | 三级基础约 18 秒完全闪避，冷却 200 秒 | 法强会继续延长完全闪避时间，并可与其他保命法术轮换 |
| 防洪之闸 | 单次伤害封顶为最大生命的 30%；一级 12 秒、三级 16 秒、八级 26 秒 | 高等级持续时间过长，可把多数首领重击压平为固定比例 |
| 逆转 | 格挡窗口约 0.4 秒，冷却 3 秒；反伤倍率为 `1 + 0.25 × 法术威力` | 当前反伤绕过护甲与无敌，可能穿透首领阶段保护或被极端伤害放大 |
| 生机虹吸 | 持续 30/60/90 秒，约每 2.5 秒按最大生命百分比治疗；可献祭召唤物并以 8 点生命复活 | 同时提供长时百分比治疗与复活，且可和其他复活来源轮换 |
| 浴火重生 | 取消死亡，并恢复至施法时的位置与生命状态 | 等同于预存一次死亡回滚；当前中文翻译仍缺失 |
| 绵绵伤痛 | 将一次伤害拆成四段延后结算 | 待结算数据只存在静态内存时，可被重登、换维度或异常卸载清除 |

CDC 当前已经做了两项相关兼容修正：回响打击使用事件构造时的原始伤害快照，避免事件倍率被本体与回响重复采样；暗影瘴气对高法强采用收益递减。后续平衡应在这两个修正之上测试，不重复加入第二套同类重砍。

## 二、总体设计原则

### 2.1 按功能分组，不按模组统一处理

玩家增强法术分为五组：

1. **普通增强**：提供护甲、净化、一次性护盾或短时规避，可以与流派正常组合。
2. **输出姿态**：直接提高攻击、法强、攻速或追加伤害，同一时间只保留一种。
3. **大型防御**：显著改写承伤结果，共享“护盾疲劳”，不能连续轮换。
4. **魔法复活**：允许取消死亡或以特殊代价复活，共享“灵魂创伤”。
5. **机动探索**：改变位移、飞行、游泳或侦测体验，原则上保留其功能完整性。

分组只限制会形成明显闭环的组合，不禁止“普通增强 + 一种输出姿态 + 机动法术”的正常构筑。

### 2.2 优先限制常驻率和叠加方式

- 输出法术的目标是形成爆发窗口，而不是成为战斗前必须逐个施放的常驻清单。
- 大型防御的目标是解决一次危险阶段，而不是靠四个法术轮换覆盖整场战斗。
- 复活法术的代价应在真正触发复活时结算，不能因提前施法但未死亡而白白进入共同锁定。
- 高阶法术可以强，但应通过稀有度、制作权限、任务或首领投放限制获取，而不是只提高法力消耗。

### 2.3 不用净化绕过系统规则

“护盾疲劳”“灵魂创伤”和首领脚本使用的特殊状态均属于系统状态，不应被净化、T.O 的雨落或普通移除负面效果能力清除。实现时应使用独立标记或白名单机制，不要把所有负面效果一概设为不可净化。

## 三、法术分类与处理方案

### 3.1 普通增强：保留功能

| 法术 | 内部 ID | 首轮处理 |
|---|---|---|
| 橡肤 | `irons_spellbooks:oakskin` | 保留；作为稳定的基础护甲增强 |
| 神圣守护 | `irons_spellbooks:fortify` | 保留；与大型完全免伤法术分开处理 |
| 冰霜之墓 | `irons_spellbooks:ice_tomb` | 保留；维持主动进入、可主动退出和抵挡一次攻击的玩法 |
| 末影闪避 | `irons_spellbooks:evasion` | 保留；若实机发现高法强下覆盖率过高，再单独调整冷却 |
| 净化 | `irons_spellbooks:cleanse` | 保留；不能移除系统状态与首领特殊状态 |

普通增强不进入输出姿态互斥，也不触发护盾疲劳。首轮不为追求整齐而改动所有法术，避免削弱早中期法师的基础生存体验。

### 3.2 输出姿态：禁止常驻叠加

以下法术组成“输出姿态”组：

| 法术 | 内部 ID | 首轮处理 |
|---|---|---|
| 超负荷 | `irons_spellbooks:charge` | 冷却改为 75 秒，`power_multiplier` 改为 0.75 |
| 急迫 | `irons_spellbooks:haste` | 最高三级，冷却改为 120 秒，`power_multiplier` 改为 0.75 |
| 回响打击 | `irons_spellbooks:echoing_strikes` | 保留 CDC 原始伤害快照修正，不追加重复伤害倍率修正 |
| 蛛毒之相 | `irons_spellbooks:spider_aspect` | 首轮保留单法术数值，纳入输出姿态互斥 |
| 暗影瘴气 | `traveloptics:shadowed_miasma` | 保留 CDC 高法强收益递减，纳入输出姿态互斥 |

输出姿态采用以下规则：

- 玩家同一时间只能拥有一种输出姿态。
- 成功施放新的输出姿态时，结束旧姿态；新法术照常消耗法力并进入冷却。
- 普通药水、食物增益和装备被动不进入此组，防止机制范围无限扩大。
- 若实机中频繁切换仍能制造异常爆发，再增加 5 秒“姿态转换”锁；首轮不预设额外惩罚。

目标是让玩家按战斗和流派选择增幅方向：超负荷偏混合爆发、急迫偏泛用属性、回响打击偏单次高伤、蛛毒之相偏持续压制、暗影瘴气偏法强成长，而不是全部叠在同一个输出窗口。

### 3.3 大型防御：共享护盾疲劳

以下法术组成“大型防御”组：

| 法术 | 内部 ID | 首轮处理 |
|---|---|---|
| 止心术 | `irons_spellbooks:heartstop` | 保留法术特色，纳入共同疲劳 |
| 深渊庇佑 | `irons_spellbooks:abyssal_shroud` | 最高二级、冷却 300 秒、`power_multiplier` 0.65 |
| 防洪之闸 | `traveloptics:floodgate` | 最低传奇、最高三级、冷却 240 秒、禁止普通制作 |
| 绵绵伤痛 | `traveloptics:lingering_strain` | 保留分段承伤特色，纳入共同疲劳并修复跨会话结算 |

共同机制暂定如下：

- 任一大型防御成功施放后，玩家获得 90 秒“护盾疲劳”。
- 护盾疲劳期间不能再次施放大型防御，但不移除当前已经生效的防御。
- 护盾疲劳跨维度、重登和死亡保留，不能用净化或雨落移除。
- 每个法术仍保留自身冷却；共同疲劳只负责阻止法术之间的轮换覆盖。

绵绵伤痛的四段待结算伤害需要写入可持久化玩家数据。换维度或重登后继续结算，玩家真正死亡后清除该次剩余债务，避免静态 Map 丢失形成无成本免伤，也避免死亡后继续追杀新生命。

### 3.4 魔法复活：共享灵魂创伤

| 法术 | 内部 ID | 首轮处理 |
|---|---|---|
| 浴火重生 | `traveloptics:flames_reborn` | 最低传奇、最高一级、冷却 600 秒、法力消耗倍率 2.0、禁止普通制作 |
| 生机虹吸 | `traveloptics:vigor_siphon` | 最高二级、冷却 360 秒、`power_multiplier` 0.65、禁止普通制作 |

共同机制暂定如下：

- 只有真正取消死亡或完成复活时，才施加 600 秒“灵魂创伤”。
- 灵魂创伤期间，其他魔法复活不能触发；普通重生流程不受影响。
- 灵魂创伤跨维度、重登和死亡保留，不能被净化、雨落或喝奶清除。
- 浴火重生与生机虹吸的自身冷却照常存在，共同锁定不替代法术冷却。
- 生机虹吸仍可保留献祭召唤物的身份，但复活后的 8 点生命必须参与后续实机生存性测试。

这套规则限制的是“连续复活”，不是删除召唤献祭或死亡回滚的法术特色。

### 3.5 机动与探索：原则上保留

| 法术 | 内部 ID | 首轮处理 |
|---|---|---|
| 天使之翼 | `irons_spellbooks:angel_wing` | 保留；重点检查与鞘翅、飞行饰品和位面规则的交互 |
| 疾闪 | `traveloptics:blink` | 保留低消耗短距位移定位 |
| 蒸汽喷流 | `traveloptics:jet_steam` | 保留水下与鞘翅推进定位 |
| 幽影闪现 | `traveloptics:spectral_blink` | 保留锁定实体的技巧位移，测试穿墙与首领竞技场边界 |
| 星界感应 | `traveloptics:astral_sense` | 保留探索价值，检查藏宝和实体扫描对服务器性能的影响 |

机动法术只有在出现越过任务区域、首领竞技场或维度边界的明确问题时才做场景限制，不因其便利性直接提高全部冷却。

### 3.6 逆转：保留技巧格挡，修正越权反伤

`traveloptics:reversal` 保留约 0.4 秒格挡窗口和 3 秒冷却，让操作熟练度继续产生收益。首轮不把它改成长冷却防御法术，也不加入护盾疲劳。

CDC 侧应调整反伤结算：

- 可以继续无视普通护甲，但不得绕过目标无敌、首领阶段保护或整合包明确标记的不可受伤状态。
- 普通目标的单次反伤不超过施法者最大生命的 200%。
- 首领目标的单次反伤还需额外限制为目标最大生命的 2%，最终取两个上限中的较低值。
- 复制弹射物时同样检查首领保护与友军关系，避免绕过伤害上限的第二条路径。
- UI 或法术说明应明确“无法逆转首领阶段无敌”，避免玩家误判为失效。

若首轮测试发现普通高伤怪物仍能被反伤一击秒杀，可以继续降低施法者生命上限倍率；不应先扩大格挡窗口或提高冷却来掩盖伤害公式问题。

## 四、首轮数据配置

单法术参数通过数据包覆盖：

```text
kubejs/data/<模组ID>/irons_spellbooks_spell_config/<法术ID>.json
```

本规划使用的字段包括：

- `min_rarity`
- `max_level`
- `enabled`
- `cooldown_in_seconds`
- `allow_crafting`
- `power_multiplier`
- `mana_cost_multiplier`

首轮需要建立的覆盖如下：

| 命名空间/法术 ID | 最低稀有度 | 最高等级 | 冷却 | 制作 | 威力倍率 | 法力倍率 |
|---|---:|---:|---:|---:|---:|---:|
| `irons_spellbooks/charge` | 沿用 | 沿用 | 75 秒 | 沿用 | 0.75 | 沿用 |
| `irons_spellbooks/haste` | 沿用 | 3 | 120 秒 | 沿用 | 0.75 | 沿用 |
| `irons_spellbooks/abyssal_shroud` | 沿用 | 2 | 300 秒 | 沿用 | 0.65 | 沿用 |
| `traveloptics/floodgate` | 传奇 | 3 | 240 秒 | 禁止 | 沿用 | 沿用 |
| `traveloptics/flames_reborn` | 传奇 | 1 | 600 秒 | 禁止 | 沿用 | 2.0 |
| `traveloptics/vigor_siphon` | 沿用 | 2 | 360 秒 | 禁止 | 0.65 | 沿用 |

“沿用”表示首轮不主动覆盖该字段，而不是把字段写成空值。实施前应先用生成的数据包与 `/reload` 验证实际加载路径和覆盖结果，再批量补齐文件。

## 五、实现分层

### 5.1 KubeJS 数据包负责

- 单法术最低稀有度、最高等级、冷却、制作权限、威力倍率和法力倍率。
- 缺失的浴火重生中文名称、说明与必要的机制提示。
- 后续任务、战利品和制作渠道调整所需的数据资源。

### 5.2 CDC 负责

- 输出姿态互斥与可选的姿态转换锁。
- 大型防御的护盾疲劳，以及跨死亡、维度和重登持久化。
- 魔法复活的实际触发检测与灵魂创伤共同锁定。
- 逆转的反伤上限、伤害标签和首领无敌阶段检查。
- 绵绵伤痛待结算伤害的持久化与恢复。
- 首领特殊状态对白名单净化能力的抵抗。

### 5.3 不在本轮重复实现

- 回响打击的原始伤害快照：CDC 已存在对应修正，只做回归测试。
- 暗影瘴气的高法强收益递减：CDC 已存在对应修正，只做回归测试。
- 对全部药水、食物和装备增益建立统一互斥：范围过大，且会破坏非魔法流派。

## 六、获取与进度投放

法术强度控制与获取控制同时进行：

| 阶段 | 推荐投放 | 设计目的 |
|---|---|---|
| 早中期 | 橡肤、神圣守护、冰霜之墓、净化、疾闪 | 尽早建立法师的生存与机动基础，不让法术体系只剩伤害 |
| 中后期 | 超负荷、急迫、回响打击、蛛毒之相、暗影瘴气、末影闪避 | 让玩家选择一种主要输出姿态，并开始形成学派构筑 |
| 后期 | 止心术、深渊庇佑、绵绵伤痛、天使之翼、幽影闪现、星界感应 | 提供应对高压战斗和复杂探索的工具，但不形成连续无敌 |
| 终局或独立挑战 | 防洪之闸、浴火重生、生机虹吸 | 作为任务、首领或特殊战利品奖励，不进入普通抄写制作循环 |

终局法术禁止普通制作后，必须至少保留一条可预期、可重复验证的获取提示。稀有不等于不可知；任务文本、战利品说明或法术图鉴应明确来源。

## 七、实施阶段

### 阶段 A：数据参数测试版

1. 为六个首轮参数法术建立独立 JSON 覆盖。
2. 补充浴火重生中文名称和说明。
3. 用游戏内法术配置查询、卷轴显示或实际施法确认等级、冷却、制作权限与倍率均已生效。
4. 只在参数层验证通过后，再进入 CDC 共同机制实现。

### 阶段 B：CDC 共同机制

1. 建立输出姿态、大型防御和魔法复活三个明确的法术 ID 白名单。
2. 实现输出姿态替换、护盾疲劳和灵魂创伤。
3. 实现逆转反伤上限与首领保护检查。
4. 将绵绵伤痛待结算数据改为持久化玩家状态。
5. 为共同状态增加服务端日志开关或调试查询，方便实机定位。

### 阶段 C：获取与引导

1. 移除防洪之闸、浴火重生和生机虹吸的普通制作渠道。
2. 把三者接入后期任务、T.O 独立挑战或指定首领战利品。
3. 在中文法术说明中补充共同疲劳、共同复活锁和首领限制。
4. 检查 JEI、法术图鉴和任务文本是否给出一致来源。

### 阶段 D：平衡回归

根据测试数据只调整出现问题的组或法术。不要因一个高法强组合失控而统一降低所有辅助、机动和探索法术。

## 八、测试矩阵

每项测试至少覆盖法强倍率约 1.0、1.5 和 2.0 三档，并分别使用单人与多人环境：

| 场景 | 重点验证 |
|---|---|
| 普通怪群 | 输出姿态是否只能保留一种；普通增强是否仍可正常组合 |
| 精英怪与高伤怪 | 逆转反伤是否受上限约束；绵绵伤痛是否完整结算四段伤害 |
| Cataclysm 与 T.O 首领 | 逆转不能穿透阶段无敌；大型防御不能轮换覆盖整场战斗 |
| 跨维度 | 护盾疲劳、灵魂创伤和绵绵伤痛待结算数据不丢失 |
| 退出并重登 | 三类持久状态恢复正确，不重复结算、不被清空 |
| 死亡与复活 | 只有实际复活时施加灵魂创伤；两种魔法复活不能连续触发 |
| 多人支援 | 队友施加或复制增强时仍遵守接受者的输出姿态与共同锁定 |
| 净化与雨落 | 普通负面效果可以清除，系统状态和首领特殊状态不能清除 |
| 鞘翅、水下和竞技场 | 蒸汽喷流、天使之翼、疾闪和幽影闪现不越过明确场景边界 |
| 高延迟与重复按键 | 不出现双重施法、重复复活、共同状态漏加或法力重复扣除 |

## 九、验收条件

首轮方案满足以下条件后才可视为完成：

- 超负荷与急迫在无额外冷却缩减时不再接近常驻。
- 五种输出姿态不能同时存在，切换时旧姿态可靠结束。
- 四种大型防御之间至少存在 90 秒共同空档，换维度、重登或死亡不能刷新该空档。
- 浴火重生与生机虹吸在任意施放顺序下，600 秒内最多实际完成一次魔法复活。
- 逆转不能伤害处于阶段无敌或明确不可受伤状态的首领，且反伤遵守普通目标与首领双重上限。
- 绵绵伤痛不能通过重登或换维度抹除待结算伤害，死亡后也不会继续向新生命结算旧债务。
- 净化与雨落仍能处理普通负面效果，但不能移除共同锁定和首领特殊状态。
- 回响打击与暗影瘴气继续使用现有 CDC 修正，没有重复倍率或重复衰减。
- 防洪之闸、浴火重生和生机虹吸具有明确的后期获取渠道与中文引导。
- 完成专用服务器与真实客户端回归；仅通过静态 JAR 审计、编译或 `/reload` 不算完整验收。

## 十、暂不确定项

以下内容留到测试版后决定，不在规划阶段锁死：

- 输出姿态是否需要额外 5 秒转换锁。
- 生机虹吸复活后的 8 点生命是否需要随整合包生命上限体系调整。
- 防洪之闸的 30% 单次伤害封顶是否需要在首领战中单独提高或降低。
- 逆转普通目标的“施法者最大生命 200%”上限是否适合高生命构筑。
- 三个终局法术最终分别落入任务、指定首领还是 T.O 独立挑战。
- 机动法术需要限制的具体竞技场、维度和任务区域白名单。

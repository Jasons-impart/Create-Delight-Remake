# 订单草稿与修饰计划

状态：第一版已实现并完成减法收束；当前权威设计见 `docs/order-system-design.md`。

## 草稿模型

订单草稿保存等级、顾客方向、菜单方向、公告板必出小类和条款。tooltip 只显示这些已知条件；服务端在玩家开封时才生成精确顾客、条目、数量与品质。

## 方向层级

| 层级 | 示例 | 作用 |
|---|---|---|
| 顾客方向 | 人类、精灵、矮人、怪物 | 影响顾客池与主题 |
| 菜单方向 | 饮品、甜品、主食、宴席 | 影响大类权重 |
| 小类方向 | 蛋糕、曲奇、茶 | 公告板可保证的实际生产方向 |

公告板可以同时列出多个小类。适配单的所有最终条目都必须命中这些小类，不能只保证一个条目；拓展单只保证列出的小类并允许其他兼容条目；机会单保留菜单方向随机性。

## 当前条款

- 扶持：新手上路、小单试做、宽松验收。
- 菜单：专品专供、宴席拼盘。
- 规模与验收：小而精、大宗采购、品质抽检。
- 结算：口碑优先、现款结算。
- 时效：加急配送。

## 使用方式

- 玩家可用印章或条款直接修改副手草稿。
- 修改只更新草稿上的方向与条款，不提前生成精确订单。
- 玩家潜行且副手为空时右击草稿，清除顾客、菜单、小类和机会锁价方向。
- 不再提供普通重掷；如果候选不合适，应回到公告板选择或等待刷新。

## 退役内容

- 订单构筑台不再制造，只保留旧机器迁移壳。
- 订单解析器不再制造；精确结果只在开封后显示。
- 重签章物品、模型、商店和创造栏入口删除。
- 拍卖行不再追加重签、加急或特急材料批次。

## 回流

履约至多返还一枚条款。形态权重使玩家完成某类订单后更容易得到相邻的下一单选择：单品偏专品，多条目偏宴席，大货量偏大宗，高品质偏抽检；时效条款只回流加急配送。

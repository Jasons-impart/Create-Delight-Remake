# 齿轮盛宴整合包内容 FAQ

> 来源：[飞书文档](https://my.feishu.cn/docx/O6z3ddPckoCLEFxqIZqcZbz6npd)（原文显示 7 月 18 日修订）
> 整理说明：保留原有问答、命令与外部链接；原文内的截图以文字说明为准，未导出图片。

在提问前，请先确认整合包版本足够新、自己未增删或升级模组，并阅读任务书、JEI 与思索。过旧版本的问题可能已不再记录；制作组无法保证增删或升级模组后的可玩性；其他整合包或模组的配方和内容也可能已在本整合包中改动。

下载地址等其他信息见「机械动力：悠然乐事重置版 信息汇总」。

## 进入游戏前

### 客户端大小不到 100 MB，正常吗？

正常。整合包不附带可从 CurseForge 下载的模组本体，而由启动器下载，以保障模组作者收益。

### 启动器不识别整合包／无法确定拖拽操作

确认下载的是以 `[Client]` 开头的压缩包，详见信息汇总文档。

### 网络不佳导致安装失败、依赖未下载或 TimeOut

若使用 PCL2，先更新后重试。通常可使用加速器或代理、切换手机热点，或多次尝试下载。也可请可信的群友提供已安装的副本；制作组受 Minecraft 用户协议限制，不能合法提供已安装的整合包。

### 整合包所在路径过长

如 PCL 报路径过长，可先将整合包移至桌面或某个盘符根目录再安装；仍不理解可向 AI 求助。

### 网络不佳，难以连接服务器

可能是网络问题或 Mojang 账号服务器异常。尝试使用代理，或离线登录。

### PCL：部分模组版本已被作者删除

这是 PCL 镜像源缺失版本导致。使用加速器加速 CurseForge，并将 PCL 下载设置为「尽量使用官方源」。

### 启动时报错 `KubeJS alexscaves`

属于偶发且制作组无法复现的错误。可在游戏根目录找到 `startup_scripts/custom/register_metal_dust.js`，删除原文截图中标红的部分。

### 启动时报错 `Error loading mods`，提示未安装模组

说明模组未完整安装。按信息汇总文档中的正确安装方法重新安装后再启动。

## 创建／进入世界

### 创建新世界长时间卡住，日志显示 `Registering recipes: ali:jei_plugin`

尝试升级 ALI；若仍卡住，可尝试移除 ALI。

### 更新后无法进入老存档

模组与魔改兼容更新不可避免，制作组不保证老存档可跨版本运行。跨版本迁移存档或直接使用升级补丁前，务必备份存档。

可尝试：

- 清空对应世界文件夹 `serverconfig` 目录中的内容。
- 删除整合包版本目录中的 `oei\global_replacement_cache.dat`，清空 OEI 缓存。
- 以新存档的 `level.dat` 替换老存档：
  1. 用老版本整合包打开存档，清空所有玩家物品栏和背包，将物品放入箱子。
  2. 备份存档并记录世界种子。
  3. 新建世界时使用该种子；服务端则在 `server.properties` 设置世界种子。
  4. 用新世界的 `level.dat` 替换备份存档中的同名文件。

### 放下烤箱并使用鼓风机后崩溃，且无法进入世界

关闭光影后进入；再检查崩溃前使用的光影是否为已打 Colorwheel 补丁的正确版本，详见下文「整合包内的光影」。

## 联机与连接服务器

### 连接前检查

先确认以下三项，通常可解决 80% 以上问题：

- 客户端与服务器的整合包版本一致。
- 未手动更新客户端中的模组。
- 服主未改动整合包模组。

### 如何和朋友联机？

- 使用内置局域网联机模组：<https://www.mcmod.cn/class/4498.html>；参考视频：<https://www.bilibili.com/video/BV18nDLBQENQ>。
- 使用交流群内官服，群信息见信息汇总。
- 联机报错也可参考：<https://www.bilibili.com/video/BV1YL41167eJ>；此类问题与整合包内容关系不大，建议自行搜索攻略。

### `Connection time out`／`Connection reset`

玩家与服务器网络连接不佳。更换网络（如手机热点）、服务器线路或服务器。

### 无法连接服务器，连接中断

先将 `zstdnet` 更新至最新版。若仍无法连接：

1. 启动游戏并进入存档，点击「开放局域网」。
2. 在新增的 zstd 端口设置中填写用于 FRP／公网的端口，例如 `25565`。
3. 樱花／公网配置中的本地端口也使用该端口；复制日志中分配的远程端口给朋友。

仍不行时：

- 带宽或流量不足（国内通常仅付费服务器足够）：禁用 `zstdnet`，改用 BandwidthOptimizer（作者 Pink_Cats）。
- 带宽与流量充足：直接禁用 `zstdnet`。

### `mod mismatched`、`error loading mods` 或缺少必需数据包注册表

服务端和客户端整合包版本不一致。双方使用同一个版本，且不要使用原版 Minecraft 连接齿轮盛宴服务器。v0.4.5.6 以后的服务端可在加入前检查版本。

### 登录失败：无效会话

先重启游戏。若仍失败，确认自己没有以离线登录方式进入开启正版验证的服务器。

### `invalid characters in username`

用户名使用英文。

### `Non character in path`

检查服务端与客户端整合包版本是否一致。

### 连接服务器时崩溃，含 `Registry minecraft:block: Object did not get ID...`

检查整合包根目录是否缺少 `ldlib` 文件夹。此问题通常来自 PCL 导出整合包造成的文件缺失；不要用 PCL 导出的包分享齿轮盛宴。

### 连接服务器时崩溃，含 `ModMismatchDisconnectedScreen`

检查服务端和客户端整合包版本是否一致。

### 无法连接服务器，提示 `OutOfMemoryError`

一般重启游戏即可；有条件可在启动器设置中增加内存分配。

### 无法通过小地图传送、无法使用 `/tp`

服务器直接传送需要 OP 权限，可看聊天名称是否为绿色判断。可使用 FTB Essentials 提供的无需权限指令：`tpa`、`tpahere`、`home`、`back` 等。

## 进入游戏后的异常

### 合成配方缺失，原木不能合成木板，JEI 木板配方异常

- 使用 Java 17 启动游戏。
- 检查安装是否异常，按信息汇总文档重新安装。

### 服务器内部分机械动力配方（如电子管）查不到，但实际有配方

退出服务器，开启一个本地存档，再重新进入服务器。

### 老存档充电板配方缺失，新存档正常

在聊天框执行并等待 `reloaded` 提示：

```mcfunction
/datapack disable "create_new_age:create_new_age_monkey_edition"
```

推测是存档迁移让不应生效的「机械动力电气时代 [monkey edition]」数据包生效，进而移除了充电板配方。

### 任务书无法打开，显示 `Quest locked`

退出世界后重进；若仍不行，重新安装整合包。

### 任务书为空

安装有问题。本地请重新安装；联机请服主按正确步骤重装服务端。

### 精妙背包打不开，日志含 `Failed to create screen for menu type: sophisticatedbackpacks:backpack`

使用 Java 17，而不是 Java 21。

### 放下烤箱并使用鼓风机后崩溃

关闭光影后进入，再检查使用的光影是否已正确打 Colorwheel 补丁。

### 方块和物品名称变为空气、材质错误、二次进入单人世界显示数据包错误、联机非主机放置方块崩溃

推测是跨版本迁移存档后，新版 `mbd2` 与旧存档 `level.dat` 中的记录不兼容，也可能和整合包新增机器有关。每次跨版本迁移都可能发生；另一表现是退出后再次进入世界显示「数据包错误」。

解决方法：

- 使用 NBT 编辑器删除原 `level.dat` 的 `fml` 子项全部内容；下次进入会自动生成新的 `fml` 数据。参考：<https://www.bilibili.com/opus/765137098159161348>。
- 若不会用 NBT 编辑器，新建存档并用新存档的 `level.dat` 替换要修复的存档。注意种子不同会造成区块边界不平滑，可在新建存档时指定相同种子；非服务器环境会丢失玩家数据，先将物品放入箱子以减少损失。

### 使用喷气背包飞行时卡顿，无法放置方块／物品移入快捷栏后又返回

将 Create Jetpack 回退至 4.4.1（`create_jetpack-forge-4.4.2.jar`）。参考：<https://www.mcmod.cn/class/21774.html>。

### 单人存档退出世界卡住或耗时过长

- 整合包曾加入 `c2mef` 提升区块加载性能，其机制会拉长退出保存和创建世界初始化时间。
- `c2mef` 与夸克板条箱存在冲突，可能造成板条箱内容消失。
- 不在意跑图生成区块变慢时可禁用 `c2mef`；其已于 v0.4.7.11 移除。

## 显示与渲染

遇到渲染显示问题可尝试禁用以下模组，但性能可能下降：

- Accelerated Rendering
- Entity Culling

其他渲染优化模组包括 Vanillin、Colorwheel、Create Better FPS、CullLessLeaves Reforged、Flerovium、Embeddium、Sodium/Embeddium Extras。

### 箱子顶部发黑、工具箱变白等

通常为 AMD／Intel 显卡问题，参考：<https://bbs.mcmod.cn/thread-16131-1-1.html>。可关闭飞轮优化：`/flywheel backend off`，但可能导致机械动力实体渲染卡顿。

### 机械动力移动实体变透明

先按 `F3+A` 重载材质；无效时禁用 Entity Culling（可能轻微掉帧），并将 Colorwheel 更新至最新版。

### 风车／水车持续「鬼畜」

机械动力常见问题，按 `F3+A` 重载所有区块。

### 隼巢胸甲渲染 Bug（机素防护）

该模组已于 0.4.8 以上移除；问题为模组本身材质缺失。

### 看向机械动力装甲（机素防护）时 FPS 严重下降

尝试禁用 Accelerated Rendering。机素防护本身 Bug 较多，且已于 0.4.8 以上移除。

### 光影／Colorwheel 报 `not compatible`（v0.4 及以后）

Colorwheel 用于让机械动力飞轮兼容光影。它要求光影打补丁；整合包借助启动器下载光影，并由 Colorwheel Patcher 自动打补丁。因此光影列表会同时出现已补丁和未补丁版本，请选择**未被删除线划掉**的光影。

选错可能导致烤箱配鼓风机崩溃等问题。并非所有光影支持 Colorwheel，支持列表见 Colorwheel CurseForge。其他光影产生的渲染问题请反馈给 Colorwheel 或光影开发者。低配电脑推荐 Complementary + Euphoria Colorwheel，并把光影配置调至极低。

## 进入游戏后的功能性问题

### 有连锁采集吗？

有，按住 `~` 触发。

### 材质变成原版／想换回原版／栅栏门有绿色边框

整合包默认使用 XK 材质包（作者动态：<https://space.bilibili.com/5930630>）。资源包界面中让两个 XK 材质包处于高亮且置顶状态。若要使用其他材质，将右侧圈选的两个材质包移至左侧；实际还需禁用 `squarefulcolorfulheart`。若只想消除栅栏门绿色边框，将右侧的 XK 高亮移至左侧。

### 中文翻译缺失

在资源包界面拉到最底部，确认原文截图标出的四个资源包均已添加，且顺序正确。

### 皮肤未生效／如何设置皮肤

整合包带有通用皮肤补丁，未改动皮肤内容。参考 LittleSkin：<https://manual.littlesk.in/faq/in-game>。

### FPS 太低

笔记本检查独显是否开启；RTX 50 系检查驱动是否最新。检查最高帧率是否限制在 60，降低渲染距离和光影配置。GPU 占用低时可用 Lossless Scaling（基础帧率 40+ 才有较好体验）。

本整合包包含 350+ 模组和机械动力，对配置有基础要求；附近有大量机械动力机器时，卡顿是其固有成本，极端情况下只能移除机械动力。

### 如何创建超平坦？

- Terralith 与 Tectonic 会导致超平坦无法生成，禁用两者即可；注意禁用 Terralith 后，原本使用它生成的世界无法进入。
- 可使用整合包内「应急工业平台」快速平整一块区块大小的区域。

### 每游玩 5 分钟渲染距离被改动

ServerCore 会按 MSPT 动态调整渲染距离和模拟距离。若不希望改变，修改 `config/servercore/config.yml`，将对应配置的 `max` 与 `min` 都设为目标值。参考：<https://www.mcmod.cn/class/6542.html>。

### FTB 组队提示未接收到队伍数据

未开启正版验证的服务器不能使用图形界面，需要使用指令；可在 MC 百科查询：<https://www.mcmod.cn/class/3179.html>。

### 配方书看不了／如何查看可合成配方？

原版配方书消耗资源且与 JEI 重叠，因此已关闭。若需查看可合成物品，可额外安装 EMI，在右侧边栏切换查看。

### 抱起的东西放不下

执行：

```mcfunction
/carryon clear
```

### 鼠标移到物品上按 Shift 出现大量内容

按 `F3+H` 关闭高级提示框。

### 右侧出现大量透明文字／`0/x`

进入任务书，关闭「固定任务」（右上角图标按钮）。

### AE 内物品多倍显示

单个容器（如保险库）只贴一个存储总线。例如 `2×2×3` 保险库也只需一个。

### 为什么小地图不能传送？

这是原版特性，与整合包无关。单人创建世界或开启局域网时开启作弊；服务器则给需要传送的玩家 OP 权限。

### MineMenu 文字乱码

在启动器 JVM 参数中加入：

```text
-Dfile.encoding=UTF-8
```

从 v0.4.7.6 起，HMCL 与 PCL2 预期会自动加入该参数。

### HUD 季节卡在春季第一天，与实际不一致

已知修改游戏内时间会触发此节气模组特性，目前无确定解法；可尝试：

```mcfunction
/ecliptic solar
```

以设置节气天数。

## 游戏内容相关问题

### 找不到 TACZ 原版枪械

整合包删除了 TACZ 原版枪械，只保留机械动力风格枪械包。

### 商店无法购买矿物，显示不在白名单

任务书拉到最底部的「交易解锁」章节。

### 找不到安山岩

地形模组调整了安山岩生成群系，请找「安山岩洞穴」。可用探险家指南针，或有权限时使用 `/locate terralith:cave/andesite_caves`。

### 铜锭和锌锭搅拌不产黄铜

原版配方已改动：熔融铜与熔融锌搅拌为熔融黄铜，再冷却。详见 JEI 和任务书。v0.3.2.0 后也有锌粒与铜粒加热搅拌、4 倍慢速合成黄铜粒的配方。

### 无限岩浆无效

已修复流动岩浆也计入数量的 Bug；现在需 2,500 格岩浆源方块才算无限。

### 作物／植物长得很慢

整合包包含节气模组；反季节或湿度不适宜会生长很慢。见任务书「四时行焉」章节。

### 某些地面上种不了小麦

Java 版中，亮度等级不高于 7 时不能对耕地使用小麦种子；已种小麦接收方块更新也会掉落。

### 带箱子的动态结构不能工作／不能从箱子取物品

不要使用夸克添加的变种箱子，使用原版箱子或木桶。v0.4.6.1（测试中）及以后加入了兼容模组，支持夸克变种箱子或精妙背包。

### 如何制作某等级锤子？

龙钢锤为 7 级，悚怖钢／末影钢锤为 8 级；镶嵌下界之星加 1 级，镶嵌纯粹黑暗加 2 级，锤头速度打磨满也可加 1 级。详见 Tetra 任务。

### 流体管道不工作

- 先用扳手切换相关动力泵方向两次。
- 检查是否把护甲装配台接到管道上；参考：<https://pd.qq.com/s/hho29um5j>。

### 冰与火小精灵偷物品

在 `config` 的冰与火配置中，将 `Pixies Steal Items` 改为 `false`。参考：<https://www.mcmod.cn/post/3482.html>。

### 蟑螂／苍蝇很多

先杀死所有蟑螂：

```mcfunction
/kill @e[type=alexsmobs:cockroach]
```

服主可在 `config/alexsmobs.toml` 中把 `cockroachSpawnWeight`、`cockroachSpawnRolls` 设为 `0`，然后重启服务器；苍蝇同理。

### 陈酿桶 GUI 打不开

所有酿酒配方已统一至饮酒作乐的发酵桶，因此禁用陈酿桶 GUI 以免误导；未完全删除是因为村民职业仍需绑定此工作方块。

### 熔铸盆熔化金属后没有出液口

下方接好容器时，用扳手右键熔融盆。

### 熔融铁和煤不能在熔铸搅拌器制作熔融钢

确认熔融铁是否在同一个熔融盆中融化；若是，先把熔融铁取出再输回。单个熔融盆／工作盆不能把上一配方输出直接作为下一配方输入，需取出再放回或输出至另一盆；此 Bug 已在冶金学 0.0.7（整合包 v0.4.5.0 及以后）修复。

### 要塞太复杂，找不到传送门

加入 Integrated Stronghold 后要塞需要解密。若不想解密：

- 进入大厅，以旗帜为正向沿路向前拆方块，直到发现不同结构方块；以安山岩为例向下挖到 `Y=-16` 至 `-14`，落入小空间后朝西贴右墙挖，经过两组水车；在第二组水车继续贴右向地图西方挖，可到末地大厅。
- 或找其他末地传送门结构：结构指南针搜索 `createdungeonbase`，或执行 `/locate structure create_structures_arise:create_dungeon_base`。

参考：<https://www.mcmod.cn/class/9529.html>。

### 找不到某种龙

见任务书；龙在其他维度。

### 找不到某家具配方所需方块

方块名就是「工作台」，来自 MrCrayfish 模组。

### Alex 的洞穴怎么去？

见任务书。史前世界的石灰岩要用机械动力版本，使用流动蜂蜜与流动岩浆生成。

### 伊甸碎片如何获取？凋零骷髅掉率很低

难度 100 以上才可通过击杀凋零骷髅获得；掉率低时先提升难度。

### 用装燃料的安山桶喂烈焰人燃烧室，桶被吃掉

是相关模组兼容问题。按住 Shift 再右键喂食以保留安山桶。

### 机械手用桶装岩浆喂烈焰人燃烧室时重复喂同一桶

是兼容 Bug，建议将液体燃料直接泵入烈焰人燃烧室。

### 商品交易终端配置后不交易

检查右上角是否已从「始终禁止」改为「激活」。

### 商品交易终端无法使用钱包货币

终端使用银行内货币，先用 ATM 存入银行。

### 屠宰动物没有产物

动物架不要搭太高，保持 3 格高度；过高可能无产物。

### 咖啡水壶做不出咖啡／需重启后才行

农夫暇事和饮酒作乐都需要**先加入流体，再加入物品材料**。

### 蓝图大炮打印出的 LC 商店交易终端无法破坏

打印出的终端没有所属用户，只有 LC 管理员可破坏。有权限时执行 `/lcadmin toggleadmin` 进入 LC 管理模式后再拆除。

### 雪傀儡冷冻室如何使用？

通过管道输入凛冰燃料，或喂烈焰蛋糕。

### 采集作物没有品质

需手动、且不触发连锁采集才有品质。批量采集可用钻石锄右键。

### 动力锯／砂带磨床／粉碎轮的输出乱飞或反向

检查输入应力的转向是否相反；粉碎轮还要注意两个轮子是否为不同转向。

### 大坝、核电站、合金电炉等多方块不成型

使用任务书提到的 MBD 工具调试模式查看未成形原因。

### 转速齿轮箱不改变转速

按住 `W` 思索并看完说明。

### 无法合成 AE 枪械使用的电池／弹夹

需要完全充满电的电池。若直接接入 AE 网络而非使用 AE 充能器，可能会差一点未满。

### 分馏塔 3×3 仍很慢，是 Bug 吗？

柴油动力作者在某次更新后刻意取消了分馏塔效率与尺寸的关系，并非 Bug；如有需求可向作者反馈。

## 开服相关

### 面板服问题

优先联系面板服客服。制作组提供的服务端主要用于官方公益服务器，可能不完善。

### 有不用执行 `start` 脚本下载内容的完整服务端吗？

没有。Mojang 用户协议禁止二次分发 Minecraft 本体，制作组无法合法提供已安装的完整版服务端。见：<https://www.minecraft.net/zh-hant/eula>。

### 没有 `run.sh`，如何写启动脚本？

见信息汇总文档的开服部分。

### 服务端启动脚本报 `contained no existing paths: [libraries\\...`

Forge 安装时下载依赖库失败。尝试更换网络，或开启／更换加速器或代理。

### 服务器磁盘突然被占满

Simple Backups 会保留 10 份、最多 25 GB 的存档备份（v0.4.5.3 及以后改为 5 份、10 GB）。磁盘满时可删除 `simplebackup` 文件夹中的备份，并修改 `config/simplebackups-common.toml`。

## 其他

### 存档炸了，如何恢复？

游戏目录的 `simplebackup` 文件夹中有各时间点的世界备份；直接解压到 `saves` 下。

### AE 插空间锚后服务器很卡

关闭服务器并备份存档。随后在各维度的 `chunks.dat` 中，使用任意 NBT 编辑器删除 AE2 标签。可用编辑器：<https://apps.microsoft.com/detail/9nd27tzrv8hd?hl=zh-cn&gl=HK>。

### 找不到官方服务器群密码

前往官网底部查看：<https://www.齿轮盛宴.com>。

## 修改整合包

制作组无法解决修改整合包后出现的问题，请自行排查。以下是群友测试结论，制作组不保证正确性。

### 灵魂出窍

安装 Freecam。

### 自行增加时需特别注意的模组

- 遥远地平线：可能需 2.4.5b 才能正确渲染，参考 <https://github.com/TeamTeaMC/Ecliptic-Seasons/issues/155>。
- YSM：旧版可能与 Better Combat 不兼容。
- 匠魂：其熔融金属与冶金学熔融金属不完全兼容，且贴图一致难以区分。
- 瓦尔基里：稳定性差，制作组不保证加入后稳定运行。
- Tweakerge：部分功能会导致龙尸直接消失、无法获得战利品等问题。
- 森罗物语：与农场物语及附属未完全兼容，物品可能无法通用。

### 不建议增加的模组

- 加入整合包已有矿物的模组：部分魔改配方未用标签，矿物可能不通用。
- 枪包：本包 TACZ 版本为 1.1.4，暂无更换计划；仅支持其他版本的枪包可能出问题。

### 修改高度限制

修改 `config/tectonic.json` 的 `max_y` 值。

## 反馈问题前

1. v0.4.7.x 正式版有游戏内文字反馈，但描述可能不完整；严肃问题仍建议走下方反馈流程。
2. 确认版本为最新。标题界面右下角或游戏标题会显示 `v0.x.x.x`；最新版本可看三个小人下方公告。非最新先更新，避免反馈已修复问题。
3. 确认未增删模组、KubeJS 脚本或 `mbd2` 文件。整合包已有大量适配与兼容问题，制作组无力处理自行修改后的报错。
4. 服务器问题先联系服主，确认是否正确安装或改动服务端；官方服务器可在论坛反馈：<https://forum.tcs-team.cn/>。
5. 崩溃或明显异常时：
   1. 在日志文件夹收集 `latest.log`。
   2. 用 <https://mclo.gs/> 保存报错并取得分享链接。
   3. 求助时附上报错分享链接。
6. 填写问题反馈文档（也接受修改建议），并查看已知问题。
7. 有能力时可直接到齿轮盛宴 GitHub 仓库提交 Pull Request。
